01 — Składnia

for, czyli while w jednej linijce

Pętlę while już znasz. Zauważyłeś pewnie, że jej trzy elementy — start licznika, warunek i zmiana — są porozrzucane po całym kodzie: start nad pętlą, warunek w nawiasie, zmiana gdzieś w środku. for robi dokładnie to samo, ale zbiera wszystkie trzy w jednym nawiasie, oddzielone średnikami.

while.cpp
int i = 1;            // start

while (i <= 5) {      // warunek
    cout << i << " ";
    i++;              // zmiana
}
▶ Wyjście programu
1 2 3 4 5
for.cpp
// start ; warunek ; zmiana - wszystko razem
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
▶ Wyjście programu
1 2 3 4 5

Oba programy robią to samo. for jest krótszy i — co ważniejsze — od razu widać w nim, ile razy pętla się wykona. Dlatego używa się go zawsze, gdy z góry wiesz, ile ma być powtórzeń. Gdy nie wiesz („czytaj, aż dane się skończą”) — zostaje while.

1️⃣

start

Wykonuje się raz, przed pierwszym obrotem. Tu tworzysz licznik: int i = 0.

2️⃣

warunek

Sprawdzany przed każdym obrotem. Gdy zrobi się fałszywy, pętla się kończy. Np. i < 10.

3️⃣

zmiana

Wykonuje się po każdym obrocie ciała. Prawie zawsze i++, ale może być też i += 2 albo i--.

🔲

ciało w klamrach

Kod, który ma się powtarzać. W środku możesz robić wszystko — także wstawić kolejną pętlę.

🔚

średniki w nawiasie

Dwa średniki oddzielają trzy części. Za nawiasem średnika nie ma.

krok_po_kroku.cpp
#include <iostream>
using namespace std;

int main() {
    //   start   warunek  zmiana
    for (int i = 1; i <= 3; i++) {
        cout << "Obrot nr " << i << "\n";
    }

    cout << "Koniec\n";
    return 0;
}
▶ Wyjście programu
Obrot nr 1 Obrot nr 2 Obrot nr 3 Koniec

Prześledź kolejność palcem: i dostaje 1 → warunek prawdziwy → wypisz → i++ daje 2 → warunek prawdziwy → wypisz → i++ daje 3 → wypisz → i++ daje 4 → warunek fałszywy → koniec. Ciało wykonało się trzy razy, choć i doszło do czterech.

02 — Warianty

Pięć form, które wystarczą na start

Klasyczne for (int i = 0; i < n; i++) to zdecydowanie najczęstszy zapis, ale czasem potrzebujesz liczyć inaczej: od jedynki, od końca albo co drugą liczbę. Zmieniasz wtedy tylko to, co w nawiasie — reszta zostaje bez zmian.

ZapisCo robiKiedy tego użyjesz
for (int i = 0; i < n; i++) Liczy od 0 do n-1, czyli n obrotów. Domyślny wybór — zapamiętaj ten
for (int i = 1; i <= n; i++) Liczy od 1 do n, też n obrotów. Gdy liczby mają być „ludzkie”, od jedynki
for (int i = n; i >= 1; i--) Liczy w dół, od n do 1. Odliczanie, wypisywanie od końca
for (int i = 0; i < n; i += 2) Skacze co dwa: 0, 2, 4, 6… Co drugi element, liczby parzyste
for (;;) Pętla bez końca — trzeba ją przerwać break-iem. To samo co while (true)
od_zera_i_od_jedynki.cpp
int n = 4;

// od 0 do n-1  ->  0 1 2 3
for (int i = 0; i < n; i++) {
    cout << i << " ";
}
cout << "\n";

// od 1 do n    ->  1 2 3 4
for (int i = 1; i <= n; i++) {
    cout << i << " ";
}
▶ Wyjście programu
0 1 2 3 1 2 3 4
w_dol_i_co_drugi.cpp
int n = 8;

// w dol: 8 7 6 5 4 3 2 1
for (int i = n; i >= 1; i--) {
    cout << i << " ";
}
cout << "\n";

// co drugi: 0 2 4 6
for (int i = 0; i < n; i += 2) {
    cout << i << " ";
}
▶ Wyjście programu
8 7 6 5 4 3 2 1 0 2 4 6

Zwróć uwagę na parę i = 0; i < n kontra i = 1; i <= n. Obie dają n obrotów — różnią się tylko tym, od czego zaczyna licznik. Pomieszanie ich (np. i = 0; i <= n) to najsłynniejszy błąd w programowaniu: pętla robi jeden obrót za dużo.

Istnieje jeszcze jeden, bardzo wygodny wariant — for (int x : v), czyli „dla każdego elementu z v”. Wrócimy do niego przy tablicach i wektorach, bo dopiero tam jest po co go używać.

03 — break i continue

Jak przerwać pętlę w połowie

Pętla nie musi kręcić się do samego końca. Dwie instrukcje wystarczą w praktycznie każdej sytuacji: break wychodzi z pętli natychmiast, a continue pomija resztę tego jednego obrotu i przechodzi do następnego.

break.cpp
// szukamy pierwszej liczby podzielnej przez 7
for (int i = 20; i <= 100; i++) {
    if (i % 7 == 0) {
        cout << "Znalazlem: " << i << "\n";
        break;            // dalej nie ma po co szukac
    }
}

cout << "Koniec";
▶ Wyjście programu
Znalazlem: 21 Koniec
continue.cpp
// wypisujemy liczby 1-10 z pominieciem parzystych
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;         // pomijamy ten obrot
    }
    cout << i << " ";
}
▶ Wyjście programu
1 3 5 7 9

W pętli for continue jest bezpieczne: licznik i tak zostanie zwiększony, bo zmiana siedzi w nawiasie, a nie w ciele. To jedna z niewielu rzeczy, w których for jest wyraźnie wygodniejszy od while.

Jedna rzecz, o której trzeba wiedzieć z góry: break przerywa tylko tę pętlę, w której stoi. Jeśli masz pętlę w pętli, wyjdziesz jedynie z wewnętrznej — zewnętrzna będzie się kręcić dalej.

04 — Pętla w pętli

Wiersze i kolumny

W ciele pętli można postawić kolejną pętlę. Brzmi groźnie, ale zasada jest prosta: przy każdym obrocie zewnętrznej pętli wewnętrzna przelatuje cała od początku do końca. Zewnętrzna odpowiada wtedy za wiersze, a wewnętrzna za kolumny.

gwiazdki.cpp
#include <iostream>
using namespace std;

int main() {
    // w - numer wiersza, k - numer kolumny
    for (int w = 1; w <= 4; w++) {

        for (int k = 1; k <= w; k++) {
            cout << "*";          // gwiazdka w tym wierszu
        }

        cout << "\n";             // koniec wiersza
    }

    return 0;
}
▶ Wyjście programu
* ** *** ****

Zwróć uwagę, gdzie stoi cout << "\n": poza wewnętrzną pętlą, ale w środku zewnętrznej. Dzięki temu wykonuje się raz na wiersz, a nie po każdej gwiazdce. Przesunięcie tej jednej linijki to najczęstszy błąd przy pętlach zagnieżdżonych.

tabliczka.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    for (int w = 1; w <= 5; w++) {
        for (int k = 1; k <= 5; k++) {
            cout << setw(4) << w * k;
        }
        cout << "\n";
    }
    return 0;
}
▶ Wyjście programu
1 2 3 4 5 2 4 6 8 10 3 6 9 12 15 4 8 12 16 20 5 10 15 20 25

Warto mieć w głowie, ile obrotów naprawdę robi Twój kod. Jedna pętla po n elementach to n obrotów. Dwie zagnieżdżone to już n × n — dla n = 1000 to milion. Nie jest to jeszcze nic strasznego, ale dobrze wiedzieć, że każde zagnieżdżenie mnoży pracę, a nie ją dodaje.

jedna pętla po n n 100 obrotów
dwie zagnieżdżone po n n × n 10 000 obrotów
pętla po n, w środku po m n × m zależy od m
trzy zagnieżdżone po n n × n × n milion obrotów

06 — Porady

Częste błędy i dobre praktyki

⚠️
Błąd o jeden
Najsłynniejszy błąd w programowaniu: pomylenie < z <=. Zanim uruchomisz, policz pierwszy i ostatni obrót. i = 0; i < n daje 0…n-1, a i = 1; i <= n daje 1…n — obie po n obrotów.
🔢
Suma może nie zmieścić się w int
W pętli suma rośnie z każdym obrotem. int kończy się na 2 miliardach, więc na sumę bierz od razu long long — nic na tym nie tracisz.
🔄
Program „wisi”
Sprawdź trzecią część nawiasu. Brak i++ albo warunek, który nigdy nie stanie się fałszywy, zawieszają program na zawsze. Przerywasz go klawiszami Ctrl + C.
✋
Nie zmieniaj licznika w ciele
Licznik zmienia się sam, w nawiasie. Dodatkowe i++ w środku ciała sprawia, że pętla przeskakuje co drugi obrót — i prawie zawsze jest to pomyłka, nie zamiar.
🚀
break i continue
break natychmiast wychodzi z pętli, continue przeskakuje do następnego obrotu. Pamiętaj: przy pętli w pętli break wychodzi tylko z tej bliższej.
🎯
Licznik żyje tylko w pętli
Zmienna utworzona w nawiasie — for (int i = 0; ...) — znika po zakończeniu pętli. Jeśli potrzebujesz jej wartości później, utwórz ją przed pętlą.
🧮
for czy while?
Znasz z góry liczbę powtórzeń — for. Kręcisz „aż do skutku”, np. czytasz dane do końca — while. Obie robią to samo, chodzi wyłącznie o czytelność.
📐
Nowa linia we właściwym miejscu
Przy pętli w pętli cout << "\n" musi stać poza wewnętrzną pętlą, ale w środku zewnętrznej. Inaczej cała tabelka rozjedzie się do jednej kolumny.
