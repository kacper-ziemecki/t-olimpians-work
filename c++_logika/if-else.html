01 — Podstawy

Jak program podejmuje decyzję

Wszystkie programy, które pisałeś do tej pory, robiły dokładnie to samo za każdym razem. if to pierwsza instrukcja, która to zmienia: pozwala powiedzieć „zrób to tylko wtedy, gdy…”. W życiu mówisz tak bez przerwy — „jeśli pada, weź parasol”. W C++ wygląda to prawie tak samo.

W nawiasie po if wpisujesz warunek, czyli coś, co jest prawdą albo fałszem — dokładnie to, o czym była mowa przy typie bool. Jeśli wyjdzie true, program wykona kod w klamrach. Jeśli false — przeskoczy go tak, jakby go tam nie było.

❓

warunek w nawiasie

To, co sprawdzasz, np. wiek >= 18. Musi dać odpowiedź true albo false.

🔲

klamry { }

Zamykają kod, który ma się wykonać. Przy jednej linijce można je pominąć, ale na początku zawsze je pisz — oszczędzisz sobie błędów.

🔀

else

Opcjonalny. Mówi, co zrobić, gdy warunek nie jest spełniony. Bez niego program po prostu leci dalej.

🚫

żadnego średnika

Po if (warunek) nie ma średnika. Postawiony tam kończy if i psuje wszystko.

pierwszy_if.cpp
#include <iostream>
using namespace std;

int main() {
    int wiek;
    cout << "Podaj wiek: ";
    cin >> wiek;

    if (wiek >= 18) {
        cout << "Jestes pelnoletni.\n";
    } else {
        cout << "Jestes niepelnoletni.\n";
    }

    cout << "Koniec programu.\n";   // to wykona sie ZAWSZE
    return 0;
}
▶ Przykładowa rozmowa z programem
Podaj wiek: 17 Jestes niepelnoletni. Koniec programu.

Zauważ ostatnią linijkę: napis „Koniec programu” jest poza klamrami, więc pokaże się niezależnie od wieku. To, co jest w środku klamer, zależy od warunku — to, co poza nimi, wykonuje się zawsze.

Samo else jest opcjonalne. Czasem chcesz tylko coś dorzucić, gdy warunek zajdzie, i nie masz żadnego planu B:

sam_if.cpp
int punkty = 95;

cout << "Punkty: " << punkty << "\n";

// bez else - dodatkowa linijka tylko czasem
if (punkty > 90) {
    cout << "Brawo, rekord!\n";
}

cout << "Do zobaczenia\n";
▶ Wyjście programu
Punkty: 95 Brawo, rekord! Do zobaczenia
if_else.cpp
int punkty = 42;

cout << "Punkty: " << punkty << "\n";

if (punkty >= 50) {
    cout << "Zaliczone\n";
} else {
    cout << "Poprawka\n";
}

cout << "Do zobaczenia\n";
▶ Wyjście programu
Punkty: 42 Poprawka Do zobaczenia
02 — Operatory porównania

Z czego zbudować warunek

Warunek prawie zawsze polega na porównaniu dwóch rzeczy. Operatorów porównania jest dokładnie sześć i wszystkie działają tak samo: biorą dwie wartości i zwracają true albo false.

OperatorCzyta sięDaje true, gdy…Przykład
a == b a równe b obie wartości są identyczne 5 == 5 → true
a != b a różne od b wartości się różnią 5 != 3 → true
a > b a większe od b a jest ściśle większe 5 > 3 → true
a < b a mniejsze od b a jest ściśle mniejsze 5 < 3 → false
a >= b a większe lub równe b a jest większe albo takie samo 5 >= 5 → true
a <= b a mniejsze lub równe b a jest mniejsze albo takie samo 3 <= 5 → true

Zanim pójdziesz dalej — najczęstszy błąd w całym C++. Jeden znak = to przypisanie: „włóż tę wartość do zmiennej”. Dwa znaki == to porównanie: „czy te dwie rzeczy są równe?”. W if zawsze chodzi o ==. Co gorsza, kompilator przepuści pomyłkę bez słowa — program po prostu będzie działał źle.

blad.cpp
int x = 3;

// UWAGA: jedno = to przypisanie!
if (x = 5) {
    cout << "x rowne 5?\n";
}

cout << "x wynosi " << x;
▶ Co wypisze program
x rowne 5? x wynosi 5 <- x zostalo NADPISANE
poprawnie.cpp
int x = 3;

// dwa == to porownanie
if (x == 5) {
    cout << "x rowne 5?\n";
} else {
    cout << "x to nie 5\n";
}

cout << "x wynosi " << x;
▶ Co wypisze program
x to nie 5 x wynosi 3

Porównywać można też znaki i teksty: if (znak == 'a') albo if (imie == "Ala") działa dokładnie tak, jak się spodziewasz. Jedyny typ, którego nie porównuj przez ==, to double — o tym w ściądze na dole strony.

03 — else if

Kilka możliwości zamiast dwóch

if / else dzieli świat na dwie części. A gdy przypadków jest pięć? Wtedy między if a else wstawiasz dowolnie wiele else if. Program sprawdza je po kolei, z góry na dół, wykonuje kod pierwszego pasującego — i natychmiast przestaje sprawdzać resztę.

oceny.cpp
#include <iostream>
using namespace std;

int main() {
    int punkty;
    cout << "Ile punktow? ";
    cin >> punkty;

    if (punkty >= 90) {
        cout << "Ocena: 5\n";
    } else if (punkty >= 75) {
        cout << "Ocena: 4\n";
    } else if (punkty >= 60) {
        cout << "Ocena: 3\n";
    } else if (punkty >= 50) {
        cout << "Ocena: 2\n";
    } else {
        cout << "Ocena: 1\n";      // wszystko ponizej 50
    }

    return 0;
}
▶ Wyjście programu
Ile punktow? 78 Ocena: 4

Dlaczego w warunku dla czwórki wystarczy punkty >= 75, a nie trzeba pisać punkty >= 75 && punkty < 90? Bo gdyby punktów było 90 lub więcej, program zatrzymałby się już na pierwszym warunku i tutaj by nie dotarł. Każdy kolejny warunek „wie”, że wszystkie poprzednie były fałszywe.

Z tego wynika też najczęstsza pułapka: kolejność ma znaczenie. Gdy zaczniesz od najluźniejszego warunku, wszystko wpadnie do niego i reszta nigdy się nie wykona.

zla_kolejnosc.cpp
int punkty = 95;

// najlzejszy warunek na gorze - blad!
if (punkty >= 50) {
    cout << "Ocena: 2\n";
} else if (punkty >= 90) {
    cout << "Ocena: 5\n";      // nigdy!
}
▶ Co wypisze program
Ocena: 2 <- a powinno byc 5
dobra_kolejnosc.cpp
int punkty = 95;

// od najostrzejszego warunku
if (punkty >= 90) {
    cout << "Ocena: 5\n";
} else if (punkty >= 50) {
    cout << "Ocena: 2\n";
}
▶ Co wypisze program
Ocena: 5
04 — Operatory logiczne

Łączenie kilku warunków w jeden

Czasem jeden warunek to za mało: „jeśli masz bilet i skończone 12 lat”. Do sklejania warunków służą trzy znaki. Wyglądają dziwnie, ale czyta się je jak zwykłe słowa.

🤝

&& — ORAZ

Cały warunek jest prawdą tylko wtedy, gdy oba są prawdziwe. wiek >= 12 && maBilet — musisz spełnić jedno i drugie.

🔀

|| — LUB

Wystarczy, że choć jeden jest prawdziwy. dzien == 6 || dzien == 7 — sobota albo niedziela.

🙃

! — NIE

Odwraca odpowiedź do góry nogami: z true robi false i odwrotnie. !pada znaczy „nie pada”.

laczenie.cpp
#include <iostream>
using namespace std;

int main() {
    int wiek = 14;
    bool maBilet = true;
    int dzien = 6;

    // ORAZ - musza byc spelnione oba
    if (wiek >= 12 && maBilet) {
        cout << "Mozesz wejsc\n";
    }

    // LUB - wystarczy jeden
    if (dzien == 6 || dzien == 7) {
        cout << "Weekend!\n";
    }

    // NIE - odwrocenie warunku
    if (!maBilet) {
        cout << "Kup bilet\n";
    } else {
        cout << "Bilet OK\n";
    }

    return 0;
}
▶ Wyjście programu
Mozesz wejsc Weekend! Bilet OK

Bardzo częsty błąd początkującego: zapis if (1 < x < 10) wygląda jak matematyka, ale w C++ nie działa — i co gorsza zawsze daje prawdę. Program liczy to od lewej: najpierw 1 < x daje true albo false (czyli 1 albo 0), a potem porównuje tę jedynkę z dziesiątką. Poprawnie trzeba napisać dwa osobne warunki połączone przez &&.

nie_dziala.cpp
int x = 500;

// wyglada dobrze, dziala fatalnie
if (1 < x < 10) {
    cout << "x jest miedzy 1 a 10\n";
}
▶ Co wypisze program
x jest miedzy 1 a 10 <- a x to 500!
dziala.cpp
int x = 500;

// dwa osobne warunki
if (1 < x && x < 10) {
    cout << "x jest miedzy 1 a 10\n";
} else {
    cout << "x jest poza zakresem\n";
}
▶ Co wypisze program
x jest poza zakresem

Gdy w jednym warunku mieszasz && i ||, wstaw nawiasy. C++ ma swoje zasady pierwszeństwa, ale nikt nie chce ich pamiętać, a nawiasy kosztują dwa znaki i czytają się same: if ((a && b) || c).

05 — if w środku if

Sprawdzanie krok po kroku

if można włożyć do środka innego if. Wtedy drugi warunek sprawdza się dopiero wtedy, gdy pierwszy okazał się prawdziwy. To przydaje się, gdy kolejne pytanie ma sens tylko po wcześniejszej odpowiedzi.

zagniezdzone.cpp
int liczba = 12;

if (liczba > 0) {
    cout << "Liczba dodatnia\n";

    // to pytanie ma sens dopiero teraz
    if (liczba % 2 == 0) {
        cout << "...i parzysta\n";
    } else {
        cout << "...i nieparzysta\n";
    }

} else {
    cout << "Liczba nie jest dodatnia\n";
}
▶ Wyjście programu
Liczba dodatnia ...i parzysta
to_samo_krocej.cpp
int liczba = 12;

// czesto da sie splaszczyc przez &&
if (liczba > 0 && liczba % 2 == 0) {
    cout << "Dodatnia i parzysta\n";
} else if (liczba > 0) {
    cout << "Dodatnia i nieparzysta\n";
} else {
    cout << "Nie jest dodatnia\n";
}
▶ Wyjście programu
Dodatnia i parzysta

Obie wersje robią to samo. Zasada jest prosta: gdy zagnieżdżenie sięga trzeciego poziomu, kod zaczyna uciekać w prawo i przestaje być czytelny — wtedy warto spłaszczyć go przez && albo else if.

06 — Dwa skróty

switch i operator ?:

Wszystko, co poniżej, da się napisać samym if. To tylko dwa skróty, które w pewnych sytuacjach robią kod krótszym. Nie musisz ich używać — ale warto je rozpoznać, gdy zobaczysz je w cudzym kodzie.

switch przydaje się, gdy sprawdzasz jedną zmienną wobec wielu konkretnych wartości. Zamiast dziesięciu else if piszesz dziesięć krótkich case. Działa tylko na liczbach całkowitych i znakach — na string ani double nie zadziała.

switch.cpp
int dzien = 7;

switch (dzien) {
    case 1:
        cout << "poniedzialek";
        break;              // konczy switch
    case 2:
        cout << "wtorek";
        break;
    case 6:
    case 7:                 // 6 i 7 tak samo
        cout << "weekend";
        break;
    default:                // jak else na koncu
        cout << "inny dzien";
}
▶ Wyjście programu
weekend
to_samo_na_if.cpp
int dzien = 7;

// dokladnie to samo, tylko dluzej
if (dzien == 1) {
    cout << "poniedzialek";
} else if (dzien == 2) {
    cout << "wtorek";
} else if (dzien == 6 || dzien == 7) {
    cout << "weekend";
} else {
    cout << "inny dzien";
}
▶ Wyjście programu
weekend

Najczęstszy błąd przy switch to zapomniany break. Bez niego program po wykonaniu jednego case leci dalej do następnych, zamiast wyjść. Czasem robi się tak celowo (jak przy 6 i 7 powyżej), ale zwykle to zwykła pomyłka.

Drugi skrót to operator ? :. Zastępuje if / else, gdy chodzi wyłącznie o wybór jednej z dwóch wartości. Czyta się go jak zdanie: warunek ? wartość-gdy-prawda : wartość-gdy-fałsz.

ternary.cpp
int a = 7, b = 3;

// wybor wartosci w jednej linijce
int wiekszy = (a > b) ? a : b;
cout << wiekszy << "\n";

// dziala tez wprost w cout
cout << (a % 2 == 0 ? "parzysta" : "nieparzysta");
▶ Wyjście programu
7 nieparzysta
to_samo_na_if.cpp
int a = 7, b = 3;

int wiekszy;
if (a > b) {
    wiekszy = a;
} else {
    wiekszy = b;
}
cout << wiekszy << "\n";
▶ Wyjście programu
7

Zasada zdrowego rozsądku: ? : jest świetny dla jednej krótkiej decyzji, ale nie zagnieżdżaj go w sobie. Zapis w stylu a > b ? (a > c ? a : c) : (b > c ? b : c) działa, ale nikt — łącznie z Tobą za tydzień — go nie przeczyta.

07 — Ściąga

Wszystkie operatory warunków w jednym miejscu

Jedna tabelka do zapamiętania i jedna kolumna z pułapkami. Pułapki to nie ciekawostki — to rzeczy, na których naprawdę wykłada się większość osób w pierwszych tygodniach.

ZapisCo robiPułapka
== Sprawdza, czy dwie wartości są równe. if (x = 5) to przypisanie — zawsze prawda
!= Sprawdza, czy się różnią. —
<   >   <=   >= Porównania większe / mniejsze. 1 < x < 10 nie działa — potrzebne &&
&& ORAZ — prawda, gdy oba warunki prawdziwe. Prawa strona bywa pomijana (patrz niżej)
|| LUB — prawda, gdy choć jeden prawdziwy. Prawa strona bywa pomijana (patrz niżej)
! NIE — odwraca prawdę na fałsz. !(a && b) to to samo co !a || !b
nawiasy Grupują warunki i ustalają kolejność. Mieszasz && z ||? Dawaj nawiasy
liczba jako warunek Zero to fałsz, każda inna liczba to prawda. if (n) znaczy if (n != 0)
porównywanie double Ułamki bywają niedokładne. Nie używaj == na double

Ostatni wiersz wymaga słowa wyjaśnienia. Komputer trzyma ułamki w przybliżeniu, więc 0.1 + 0.2 nie wychodzi dokładnie 0.3, tylko odrobinę obok. Dlatego if (a == b) na double potrafi zwrócić fałsz mimo że „na oko” wartości są równe. Na razie wystarczy, żebyś o tym wiedział i porównywał przez < albo >, a nie przez ==.

pulapka_double.cpp
#include <iostream>
using namespace std;

int main() {
    double a = 0.1 + 0.2;
    double b = 0.3;

    if (a == b) {
        cout << "rowne\n";
    } else {
        cout << "rozne!\n";      // i tu wlasnie wejdzie
    }

    cout << "a = " << a << "\n";
    return 0;
}
▶ Wyjście programu
rozne! a = 0.3

A skrócone sprawdzanie warunków działa tak: jeśli lewa strona && jest fałszywa, to cały warunek i tak będzie fałszywy — więc C++ w ogóle nie czyta prawej strony. To nie jest ciekawostka, tylko przydatne zabezpieczenie: if (b != 0 && a / b > 2) nigdy nie podzieli przez zero, bo przy b równym zeru dzielenie nawet się nie wykona. Kolejność warunków ma tu znaczenie — odwrotna wersja wysypałaby program.

08 — Przykładowe zadania

Sprawdź się na zadaniach

Sześć zadań od najprostszego. Pierwsze trzy sprawdzają, czy rozumiesz sam if; kolejne łączą warunki, else if i switch. Rozwiązania są schowane — najpierw spróbuj sam, choćby miało nie wyjść.

Łatwe Parzysta czy nieparzysta
Wczytaj liczbę całkowitą i wypisz, czy jest parzysta, czy nieparzysta.
Jak to ugryźć: Liczba jest parzysta, gdy reszta z dzielenia przez 2 wynosi zero, czyli gdy liczba % 2 == 0. Znak % to reszta z dzielenia — poznasz go dokładnie w temacie Modulo.
Pokaż rozwiązanie
parzysta.cpp
#include <iostream>
using namespace std;

int main() {
    int liczba;
    cout << "Podaj liczbe: ";
    cin >> liczba;

    if (liczba % 2 == 0) {
        cout << "Parzysta\n";
    } else {
        cout << "Nieparzysta\n";
    }

    return 0;
}
Łatwe Większa z dwóch
Wczytaj dwie liczby i wypisz większą z nich. Jeśli są równe — napisz, że są równe.
Jak to ugryźć: Trzy przypadki, więc if, else if i else. Uważaj, żeby nie zapomnieć o przypadku równości — bez niego program przy dwóch piątkach wypisze bzdurę.
Pokaż rozwiązanie
wieksza.cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "Podaj dwie liczby: ";
    cin >> a >> b;

    if (a > b) {
        cout << "Wieksza: " << a << "\n";
    } else if (b > a) {
        cout << "Wieksza: " << b << "\n";
    } else {
        cout << "Liczby sa rowne\n";
    }

    return 0;
}
Łatwe Dodatnia, ujemna czy zero
Wczytaj liczbę i wypisz jedno ze słów: dodatnia, ujemna albo zero.
Jak to ugryźć: Klasyczne trzy przypadki. Zacznij od > 0, potem < 0, a zero zostaw dla else — skoro nie jest ani dodatnia, ani ujemna, to musi być zerem.
Pokaż rozwiązanie
znak_liczby.cpp
#include <iostream>
using namespace std;

int main() {
    int x;
    cout << "Podaj liczbe: ";
    cin >> x;

    if (x > 0) {
        cout << "dodatnia\n";
    } else if (x < 0) {
        cout << "ujemna\n";
    } else {
        cout << "zero\n";
    }

    return 0;
}
Średnie Ocena z przedziałów
Wczytaj liczbę punktów (0–100) i wypisz ocenę: 0–49 to 1, 50–59 to 2, 60–74 to 3, 75–89 to 4, 90–100 to 5. Wartości spoza zakresu odrzuć komunikatem o błędzie.
Jak to ugryźć: Najpierw jednym warunkiem odsiej dane spoza zakresu, a dopiero potem klasyfikuj. Przy else if nie musisz sprawdzać dolnej granicy przedziału — gwarantuje ją poprzedni warunek, który okazał się fałszywy.
Pokaż rozwiązanie
ocena.cpp
#include <iostream>
using namespace std;

int main() {
    int p;
    cout << "Ile punktow? ";
    cin >> p;

    if (p < 0 || p > 100) {
        cout << "Bledna liczba punktow\n";
    } else if (p >= 90) {
        cout << "Ocena: 5\n";
    } else if (p >= 75) {
        cout << "Ocena: 4\n";
    } else if (p >= 60) {
        cout << "Ocena: 3\n";
    } else if (p >= 50) {
        cout << "Ocena: 2\n";
    } else {
        cout << "Ocena: 1\n";
    }

    return 0;
}
Średnie Kalkulator na switchu
Wczytaj liczbę, znak działania (+ - * /) i drugą liczbę. Wypisz wynik. Obsłuż dzielenie przez zero i nieznany znak działania.
Jak to ugryźć: To wzorcowe zastosowanie switch — jedna zmienna typu char i kilka stałych wartości. Pamiętaj o break po każdym przypadku i o default na końcu. Dzielenie sprawdź osobnym if.
Pokaż rozwiązanie
kalkulator.cpp
#include <iostream>
using namespace std;

int main() {
    double a, b;
    char znak;

    cout << "Np. 7 + 2: ";
    cin >> a >> znak >> b;

    switch (znak) {
        case '+':
            cout << a + b << "\n";
            break;
        case '-':
            cout << a - b << "\n";
            break;
        case '*':
            cout << a * b << "\n";
            break;
        case '/':
            if (b == 0) {
                cout << "Nie dziele przez zero\n";
            } else {
                cout << a / b << "\n";
            }
            break;
        default:
            cout << "Nieznane dzialanie\n";
    }

    return 0;
}
Trudne Klasyfikacja trójkąta
Wczytaj trzy długości boków. Sprawdź, czy da się z nich zbudować trójkąt, a jeśli tak — napisz, czy jest równoboczny, równoramienny czy różnoboczny.
Jak to ugryźć: Trójkąt istnieje, gdy suma każdych dwóch boków przekracza trzeci — to trzy warunki połączone przez &&. Sprawdź to najpierw, a dopiero w środku klasyfikuj przez else if. Równoboczny to trzy równe boki, równoramienny — dokładnie dwa.
Pokaż rozwiązanie
trojkat.cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cout << "Podaj trzy boki: ";
    cin >> a >> b >> c;

    // czy trojkat w ogole istnieje?
    if (a + b > c && a + c > b && b + c > a) {

        if (a == b && b == c) {
            cout << "rownoboczny\n";
        } else if (a == b || b == c || a == c) {
            cout << "rownoramienny\n";
        } else {
            cout << "roznoboczny\n";
        }

    } else {
        cout << "To nie jest trojkat\n";
    }

    return 0;
}
09 — Porady

Częste błędy i dobre praktyki

🟰
= vs ==
Pojedyncze = przypisuje wartość, podwójne == porównuje. if (x = 5) to prawdopodobnie błąd, a nie warunek x == 5.
🔗
Kolejność w else if
Warunki w łańcuchu else if sprawdzane są od góry — pierwszy prawdziwy "wygrywa". Ustawiaj je od najbardziej do najmniej szczegółowego.
🧩
Nawiasy klamrowe
Nawet dla jednej instrukcji warto używać { } — chroni to przed błędami, gdy ktoś później doda drugą linię do bloku.
⚡
Krótkie zwarcie (&&, ||)
W a && b, jeśli a jest fałszywe, b nie jest już sprawdzane. Analogicznie dla ||, gdy a jest prawdziwe.
🎯
true = 1, false = 0
Wypisując wynik porównania przez cout, C++ pokaże 1 zamiast true i 0 zamiast false.
📚
Głębokie zagnieżdżanie
Zbyt wiele zagnieżdżonych if utrudnia czytanie kodu. Czasem lepiej rozbić warunek na osobne zmienne logiczne albo użyć &&.
