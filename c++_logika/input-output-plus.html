01 — Przyspieszenie

Dwie linijki, które ratują duże dane

Przy dziesięciu liczbach nie ma to żadnego znaczenia. Ale gdy danych jest milion, samo ich wczytanie potrafi zająć kilka sekund — zanim Twój program w ogóle zacznie cokolwiek liczyć.

Powód jest techniczny: domyślnie cin i cout są zsynchronizowane ze starszym sposobem wczytywania (funkcjami z języka C). Ta zgodność kosztuje, a prawie nigdy z niej nie korzystasz. Da się ją wyłączyć dwiema linijkami na początku main.

szybkie_io.cpp
#include <iostream>
using namespace std;

int main() {
    // te dwie linijki na samej gorze main
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    cin >> n;

    long long suma = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        suma += x;
    }

    cout << suma << "\n";
    return 0;
}
▶ Wyjście programu
Wejście: 4 10 20 30 40 100
⚡

sync_with_stdio(false)

Odłącza cin od starego sposobu wczytywania. To stąd bierze się cała różnica w szybkości.

🔗

cin.tie(NULL)

Odpina cout od cin, żeby wyjście nie było opróżniane przed każdym wczytaniem.

⚠️

nie mieszaj

Po tych dwóch linijkach nie używaj już scanf ani printf — wyniki mogą się pomieszać.

🐢

endl spowalnia

endl po każdej linii wymusza opróżnienie bufora. Przy milionie wierszy pisz "\n".

📋

wklej na start

Te dwie linijki wklej do każdego zadania z dużymi danymi. Nie szkodzą nigdy, a czasem ratują.

👤

nie przy rozmowie

Gdy program rozmawia z użytkownikiem (pyta i czeka), cin.tie(NULL) może opóźnić wyświetlenie pytania. Wtedy tej linijki nie dawaj.

roznica.cpp
#include <iostream>
using namespace std;

int main() {
    // BEZ tych linijek wczytanie miliona liczb
    // potrafi zajac ponad sekunde.
    // Z NIMI - okolo 0,1 sekundy.

    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n, x;
    cin >> n;

    for (int i = 0; i < n; i++) {
        cin >> x;
    }

    cout << "Wczytano " << n << " liczb\n";
    return 0;
}
▶ Wyjście programu
Wczytano 1000000 liczb

Kiedy tego używać? Zawsze, gdy w treści zadania widzisz, że danych może być dużo — dziesiątki czy setki tysięcy wartości. W zwykłych programach różnicy nie zauważysz, ale te dwie linijki nigdy nie szkodzą, więc wielu osobom wchodzą w nawyk.

02 — Wzorce wczytywania

Gdy nie wiesz, ile będzie danych

Do wzorców z podstawowego tematu dochodzi kilka sytuacji, które spotkasz przy trudniejszych zadaniach: dane kończące się umówionym słowem, wiele wierszy tekstu i liczba wierszy podana na starcie.

slowo_konca.cpp
// dane konczy slowo KONIEC
string s;

while (cin >> s && s != "KONIEC") {
    cout << "[" << s << "]\n";
}
▶ Wyjście programu
Wejście: kot pies KONIEC [kot] [pies]
linie_tekstu.cpp
// n wierszy tekstu, kazdy ze spacjami
int n;
cin >> n;
cin.ignore();            // ENTER po liczbie!

for (int i = 0; i < n; i++) {
    string linia;
    getline(cin, linia);
    cout << i + 1 << ": " << linia << "\n";
}
▶ Wyjście programu
Wejście: 2 Ala ma kota Bartek ma psa 1: Ala ma kota 2: Bartek ma psa

Prawy przykład to najczęstsza pułapka na tej stronie i warto ją zapamiętać raz na zawsze: po cin >> liczba zawsze wstaw cin.ignore(), zanim użyjesz getline. Bez tego pierwszy getline złapie porzucony ENTER i zwróci pustą linię.

Czasem trzeba przeczytać wszystkie wiersze aż do końca danych — wtedy getline sam sygnalizuje koniec, tak jak cin >> x.

wszystkie_linie.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string linia;
    int numer = 0;

    // czytamy do konca danych
    while (getline(cin, linia)) {
        numer++;

        if (linia.empty()) {
            cout << numer << ": (pusta linia)\n";
        } else {
            cout << numer << ": " << linia << "\n";
        }
    }

    cout << "Wierszy: " << numer;
    return 0;
}
▶ Wyjście programu
Wejście: Ala ma kota Bartek 1: Ala ma kota 2: (pusta linia) 3: Bartek Wierszy: 3
03 — Formatowanie wyniku

Liczby z przecinkiem i kolumny

Domyślnie cout pokazuje około sześciu cyfr znaczących. Dla liczby 1234567.89 to za mało — zobaczysz 1.23457e+06, czyli zapis wykładniczy. fixed to wyłącza, a setprecision ustawia liczbę miejsc po przecinku.

bez_fixed.cpp
#include <iomanip>

double duza = 1234567.89;
double mala = 0.000012345;

cout << duza << "\n";     // zapis wykladniczy
cout << mala << "\n";     // tez

cout << setprecision(3);
cout << duza << "\n";     // 3 cyfry ZNACZACE
▶ Wyjście programu
1.23457e+06 1.2345e-05 1.23e+06
z_fixed.cpp
#include <iomanip>

double duza = 1234567.89;
double mala = 0.000012345;

cout << fixed << setprecision(2);

cout << duza << "\n";     // 2 miejsca PO PRZECINKU
cout << mala << "\n";

cout << setprecision(6);
cout << mala << "\n";
▶ Wyjście programu
1234567.89 0.00 0.000012

Zapamiętaj różnicę: bez fixed liczba w setprecision oznacza cyfry znaczące, a z fixed — miejsca po przecinku. W zadaniach prawie zawsze chodzi o to drugie, więc te dwa ustawienia podaje się razem.

Do równych kolumn służy setw razem z left albo right. Pamiętaj, że setw dotyczy tylko najbliższej wypisywanej wartości — trzeba go powtarzać.

tabelka.cpp
#include <iostream>
#include <iomanip>
#include <string>
using namespace std;

int main() {
    string imiona[3] = {"Ala", "Bartek", "Krzysztof"};
    double wyniki[3] = {95.5, 87.25, 100.0};

    cout << fixed << setprecision(2);

    for (int i = 0; i < 3; i++) {
        cout << left  << setw(12) << imiona[i]
             << right << setw(8)  << wyniki[i] << "\n";
    }

    return 0;
}
▶ Wyjście programu
Ala 95.50 Bartek 87.25 Krzysztof 100.00
04 — Ściąga

Wzorce wczytywania i formatowania

Wszystkie wzorce z tej i z podstawowej strony o wejściu i wyjściu — w jednym miejscu, do wracania podczas rozwiązywania zadań.

ZapisCo robiKiedy tego użyjesz
ios_base::sync_with_stdio(false); Odłącza cin od starego wczytywania. Duże dane — wklejaj na start
cin.tie(NULL); Odpina cout od cin. Razem z powyższą, ale nie przy rozmowie
cin >> n; potem n razy Liczba danych podana na starcie. Najczęstszy format
while (cin >> x) Czyta do końca danych. Gdy nie wiesz ile
while (cin >> x && x != 0) Czyta do umówionej wartości. Zero kończy dane
while (cin >> s && s != "KONIEC") Czyta do umówionego słowa. —
getline(cin, s) Cała linia ze spacjami. Po cin >> najpierw ignore
while (getline(cin, s)) Wszystkie wiersze do końca. Puste linie też wracają
cin.ignore() Wyrzuca porzucony ENTER. Między cin >> a getline
fixed << setprecision(k) k miejsc po przecinku. Obie razem
left / right << setw(k) Kolumna szerokości k. setw tylko na najbliższą wartość
"\n" zamiast endl Nowa linia bez opróżniania bufora. W długich pętlach

Dziewiąty wiersz to najczęstsze źródło zagadkowych błędów. Jeśli Twój program „gubi” pierwszą linię tekstu albo wypisuje pustą — prawie na pewno brakuje cin.ignore() po wczytaniu liczby.

05 — Przykładowe zadania

Sprawdź się na zadaniach

Sześć zadań od najprostszego. Pierwsze trzy ćwiczą wzorce wczytywania, dalsze — formatowanie i pracę z dużymi danymi. Najpierw spróbuj sam.

Łatwe Suma do końca danych
Wczytuj liczby aż do końca danych i wypisz ich sumę, ile ich było oraz średnią z dwoma miejscami po przecinku.
Jak to ugryźć: Pętla while (cin >> x) zatrzyma się sama. Średnią policz jako (double)suma / ile i pamiętaj o fixed przed setprecision.
Pokaż rozwiązanie
suma.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    long long suma = 0;
    int ile = 0, x;

    while (cin >> x) {
        suma += x;
        ile++;
    }

    cout << "Liczb: " << ile << "\n";
    cout << "Suma:  " << suma << "\n";

    cout << fixed << setprecision(2);
    cout << "Srednia: " << (double)suma / ile << "\n";

    return 0;
}
Łatwe Dane do słowa KONIEC
Wczytuj słowa aż do napotkania słowa KONIEC. Wypisz, ile słów wczytałeś (nie licząc KONIEC) i które było najdłuższe.
Jak to ugryźć: Warunek pętli sprawdza dwie rzeczy naraz: czy udało się wczytać słowo i czy nie jest to KONIEC. Zapis while (cin >> s && s != "KONIEC").
Pokaż rozwiązanie
do_konca.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s, najdluzsze = "";
    int ile = 0;

    while (cin >> s && s != "KONIEC") {
        ile++;
        if (s.length() > najdluzsze.length()) najdluzsze = s;
    }

    cout << "Slow: " << ile << "\n";
    cout << "Najdluzsze: " << najdluzsze << "\n";

    return 0;
}
Łatwe Liczba, potem wiersze tekstu
Pierwszy wiersz zawiera liczbę n. Następne n wierszy to zdania ze spacjami. Wypisz je ponumerowane.
Jak to ugryźć: Klasyczna pułapka: po cin >> n koniecznie cin.ignore();, inaczej pierwszy getline zwróci pustą linię.
Pokaż rozwiązanie
wiersze.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    cin.ignore();            // bez tego nie zadziala

    for (int i = 1; i <= n; i++) {
        string linia;
        getline(cin, linia);
        cout << i << ". " << linia << "\n";
    }

    return 0;
}
Średnie Tabelka wyników
Wczytaj n zawodników: nazwisko (jedno słowo) i wynik z ułamkiem. Wypisz tabelkę z nazwiskami dosuniętymi do lewej w kolumnie szerokości 15 i wynikami do prawej w kolumnie szerokości 10, z dwoma miejscami po przecinku.
Jak to ugryźć: left i right przełączają wyrównanie, ale setw trzeba powtórzyć przed każdą wartością. fixed i setprecision ustawiasz raz, przed pętlą.
Pokaż rozwiązanie
tabelka.cpp
#include <iostream>
#include <iomanip>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;

    cout << fixed << setprecision(2);

    for (int i = 0; i < n; i++) {
        string nazwisko;
        double wynik;
        cin >> nazwisko >> wynik;

        cout << left  << setw(15) << nazwisko
             << right << setw(10) << wynik << "\n";
    }

    return 0;
}
Średnie Wszystkie wiersze do końca
Wczytuj wiersze tekstu aż do końca danych. Dla każdego wypisz jego numer, długość i liczbę słów. Puste wiersze też licz.
Jak to ugryźć: while (getline(cin, linia)) przeczyta wszystko, łącznie z pustymi wierszami. Słowa policzysz, wrzucając wiersz do stringstream — tak jak w temacie obok.
Pokaż rozwiązanie
wszystkie.cpp
#include <iostream>
#include <sstream>
#include <string>
using namespace std;

int main() {
    string linia;
    int numer = 0;

    while (getline(cin, linia)) {
        numer++;

        stringstream ss(linia);
        string slowo;
        int slow = 0;
        while (ss >> slowo) slow++;

        cout << numer << ": dlugosc " << linia.length()
             << ", slow " << slow << "\n";
    }

    return 0;
}
Trudne Milion liczb w limicie
Wczytaj n (do miliona) liczb i wypisz ich sumę, największą, najmniejszą oraz liczbę tych parzystych. Program ma zmieścić się w sekundzie.
Jak to ugryźć: Trzy rzeczy naraz. Po pierwsze — dwie linijki przyspieszające na starcie. Po drugie — nie zapisuj liczb do tablicy, przetwarzaj je od razu przy wczytywaniu. Po trzecie — suma miliona liczb nie zmieści się w int, więc weź long long.
Pokaż rozwiązanie
milion.cpp
#include <iostream>
#include <climits>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    cin >> n;

    long long suma = 0;
    int maks = INT_MIN, mini = INT_MAX;
    int parzyste = 0;

    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;                 // nie zapisujemy nigdzie

        suma += x;
        if (x > maks) maks = x;
        if (x < mini) mini = x;
        if (x % 2 == 0) parzyste++;
    }

    cout << "Suma:      " << suma << "\n";
    cout << "Najwiekszy " << maks << "\n";
    cout << "Najmniejszy " << mini << "\n";
    cout << "Parzystych " << parzyste << "\n";

    return 0;
}
06 — Porady

Częste błędy i dobre praktyki

⚡
Dwie linijki na start
ios_base::sync_with_stdio(false); i cin.tie(NULL); na początku main. Przy dużych danych potrafią skrócić czas kilkukrotnie.
🐢
endl spowalnia
endl po każdym wierszu wymusza opróżnienie bufora. W pętli po milionie wierszy pisz "\n" — efekt na ekranie ten sam.
🧹
cin.ignore przed getline
Po cin >> n w kolejce zostaje ENTER, który zje pierwszy getline. Jedna linijka cin.ignore(); to naprawia.
❌
Nie mieszaj cin ze scanf
Po wyłączeniu synchronizacji nie używaj już scanf ani printf. Wybierz jedno podejście i trzymaj się go w całym programie.
📏
setprecision wymaga fixed
Bez fixed liczba oznacza cyfry znaczące, a nie miejsca po przecinku. W zadaniach prawie zawsze chodzi o to drugie.
👤
Przy rozmowie bez tie(NULL)
Gdy program pyta użytkownika i czeka na odpowiedź, cin.tie(NULL) może opóźnić wyświetlenie pytania. W takich programach go nie dawaj.
