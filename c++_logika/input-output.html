01 — Podstawy

Co to znaczy wejście i wyjście?

Program sam z siebie jest niemy i głuchy. Żeby się z nim dogadać, potrzebne są dwa kanały. Wyjście to wszystko, co program pokazuje na ekranie. Wejście to wszystko, co Ty wpisujesz na klawiaturze. W C++ obsługują je dwie nazwy, które będziesz pisać codziennie: cout i cin.

Nazwy wyglądają dziwnie, ale są skrótami: c od character (znak), out od „na zewnątrz”, in od „do środka”. A strzałki << i >> to najprostsza ściąga, jaka istnieje: zawsze pokazują, dokąd płyną dane.

📤

cout <<

Wypisuje na ekran. Strzałki są odwrócone w stronę cout, bo dane płyną od Twojej wartości do ekranu.

📥

cin >>

Wczytuje to, co wpiszesz. Strzałki pokazują na zmienną, bo dane płyną od klawiatury do zmiennej.

📦

<iostream>

Gotowy kawałek biblioteki, w którym siedzą cin i cout. Bez linijki #include <iostream> kompilator ich nie zna.

⏸️

ENTER

Po cin program zatrzymuje się i czeka, aż coś wpiszesz i wciśniesz ENTER. Dopiero wtedy leci dalej.

pierwszy_program.cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Podaj swoj wiek: ";   // prosba na ekran

    int wiek;                      // pudelko na odpowiedz
    cin >> wiek;                   // program CZEKA na ENTER

    cout << "Masz " << wiek << " lat.\n";

    return 0;
}
▶ Przykładowa rozmowa z programem
Podaj swoj wiek: 17 Masz 17 lat.

Zwróć uwagę na kolejność: najpierw cout pyta, potem cin czeka na odpowiedź, na końcu cout wypisuje wynik. Program wykonuje linijki po kolei, z góry na dół — nigdy inaczej.

02 — Budowa programu

Z czego składa się każdy program w C++

Ten sam szkielet będziesz pisać w każdym programie, więc warto raz zrozumieć, co robi każda linijka. Nie musisz jej wymyślać za każdym razem — po prostu zaczynasz od niej i wpisujesz swój kod w środek.

📎

#include <iostream>

„Dołącz gotowy zestaw narzędzi do wejścia i wyjścia”. Bez tego cout i cin nie istnieją. Linijki z # nie kończą się średnikiem.

🏷️

using namespace std;

Pozwala pisać krótko cout zamiast std::cout. Wygoda — nic więcej.

🚀

int main()

Miejsce, od którego komputer zaczyna czytać Twój program. Każdy program ma dokładnie jedno main.

🔲

{ nawiasy klamrowe }

Wyznaczają początek i koniec. Wszystko, co ma się wykonać, piszesz między nimi.

🏁

return 0;

Ostatnia linijka w main. Mówi systemowi: „skończyłem i wszystko poszło dobrze”.

🔚

średnik ;

Kończy każdą instrukcję. Zapomniany średnik to najczęstszy błąd kompilacji na świecie.

szkielet.cpp
#include <iostream>      // 1. dolaczamy narzedzia
using namespace std;     // 2. skracamy zapis

int main() {             // 3. start programu

    cout << "Czesc!\n";  // 4. TUTAJ piszesz swoj kod

    return 0;            // 5. koniec, wszystko OK
}                        // 6. klamra zamykajaca main
▶ Wyjście programu
Czesc!

Komentarze (to, co po //) komputer całkowicie pomija — są tylko dla Ciebie. Możesz ich pisać ile chcesz, program przez to nie zwolni ani o milisekundę.

03 — Wypisywanie

cout — wszystko, co chcesz pokazać na ekranie

cout potrafi wypisać cztery rzeczy: tekst w cudzysłowie, wartość zmiennej, wynik działania matematycznego i znak nowej linii. Najlepsze jest to, że możesz je skleić w jednej linijce — wystarczy przed każdą kolejną rzeczą powtórzyć <<.

sklejanie.cpp
string imie = "Ala";
int wiek = 12;

// kazda rzecz poprzedzona <<
cout << "Czesc, " << imie << "!\n";
cout << "Masz " << wiek << " lat.\n";

// cout policzy tez dzialanie
cout << "Za rok: " << wiek + 1 << "\n";
cout << "2 + 3 = " << 2 + 3 << "\n";
▶ Wyjście programu
Czesc, Ala! Masz 12 lat. Za rok: 13 2 + 3 = 5
nowa_linia.cpp
// BEZ znaku nowej linii wszystko sie sklei
cout << "raz";
cout << "dwa";
cout << "trzy";
cout << "\n";

// "\n" przechodzi do nowej linii
cout << "raz\n";
cout << "dwa\n";

// endl robi to samo (i troche wiecej)
cout << "trzy" << endl;
▶ Wyjście programu
razdwatrzy raz dwa trzy

Znak \n wygląda jak dwa znaki, ale dla programu jest jednym: „przejdź do nowej linii”. Zawsze wpisujesz go w środku cudzysłowu, np. "gotowe\n". Możesz też użyć endl — efekt na ekranie jest ten sam, a różnicę między nimi opisuje ostatnia porada na dole strony.

Uwaga na jedną pułapkę: cudzysłów wypisuje się dosłownie. cout << "wiek" pokaże słowo wiek, a cout << wiek (bez cudzysłowu) pokaże to, co siedzi w zmiennej.

dwie_pulapki.cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7, b = 2;

    cout << "a" << "\n";          // slowo a
    cout << a << "\n";            // wartosc zmiennej

    cout << "a + b" << "\n";      // slowa, nie dzialanie
    cout << a + b << "\n";        // dopiero to liczy

    return 0;
}
▶ Wyjście programu
a 7 a + b 9
04 — Wczytywanie

cin — pobieranie danych od użytkownika

cin nie pyta, jakiego typu jest to, co wpisujesz — patrzy na typ zmiennej stojącej po prawej stronie >> i dopasowuje się do niej. Twoje jedyne zadanie: utworzyć zmienną odpowiedniego typu, zanim cokolwiek wczytasz.

🔢

liczba całkowita

int wiek; a potem cin >> wiek; — wczyta 17, ale na 17.5 się zatnie.

🌊

liczba z przecinkiem

double cena; i cin >> cena; — wpisujesz 4.75 z kropką, nie przecinkiem.

🔤

pojedynczy znak

char znak; — pobiera jeden znak i pomija spacje stojące przed nim.

📝

jedno słowo

string imie; — uwaga, cin zatrzyma się na pierwszej spacji. Na całe zdanie jest getline z następnej sekcji.

🔗

kilka naraz

cin >> x >> y; — jedna linijka wczyta dwie wartości. Możesz je wpisać po spacji albo w osobnych liniach, cin nie widzi różnicy.

wczytywanie.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string imie;
    int wiek;
    double srednia;

    cout << "Imie, wiek i srednia: ";
    cin >> imie >> wiek >> srednia;

    cout << imie << ", " << wiek << " lat\n";
    cout << "Srednia: " << srednia << "\n";

    return 0;
}
▶ Przykładowa rozmowa z programem
Imie, wiek i srednia: Ala 12 4.75 Ala, 12 lat Srednia: 4.75

Dobry nawyk na start: zanim coś wczytasz, napisz o to prośbę przez cout. Bez niej program wygląda, jakby się zawiesił — a on tylko cicho czeka na ENTER.

05 — Tekst ze spacjami

getline — wczytanie całej linii

cin >> imie zatrzymuje się na pierwszej spacji — dostaniesz tylko jedno słowo. Przy „Jan Kowalski” w zmiennej wyląduje samo „Jan”, a „Kowalski” zostanie w kolejce i trafi do następnego wczytania. Na całą linię jest getline(cin, zmienna).

jedno_slowo.cpp
string imie;

cout << "Podaj imie i nazwisko: ";
cin >> imie;             // tylko jedno slowo

cout << "[" << imie << "]";
▶ Co się stanie
Podaj imie i nazwisko: Jan Kowalski [Jan]
cala_linia.cpp
string pelneImie;

cout << "Podaj imie i nazwisko: ";
getline(cin, pelneImie); // cala linia

cout << "[" << pelneImie << "]";
▶ Co się stanie
Podaj imie i nazwisko: Jan Kowalski [Jan Kowalski]

I teraz najważniejsza pułapka całej tej strony. Gdy wpisujesz liczbę i wciskasz ENTER, cin >> n zabiera samą liczbę, a ENTER zostawia w kolejce. Kolejny getline widzi ten porzucony ENTER, uznaje, że linia właśnie się skończyła — i zwraca pusty tekst. Lekarstwo to jedna linijka: cin.ignore();, która ten ENTER wyrzuca.

zle.cpp
int n;
string nazwa;

cin >> n;                 // zabiera liczbe,
                          // ENTER zostaje!
getline(cin, nazwa);      // lapie pusty ENTER

cout << "[" << nazwa << "]";
▶ Co się stanie
Wejście: 3 Zeszyt [] <- pusto!
dobrze.cpp
int n;
string nazwa;

cin >> n;
cin.ignore();             // wyrzuca ENTER

getline(cin, nazwa);      // teraz dziala

cout << "[" << nazwa << "]";
▶ Co się stanie
Wejście: 3 Zeszyt [Zeszyt]

Zasada do zapamiętania raz na zawsze: jeśli po cin >> chcesz użyć getline, wstaw między nie cin.ignore();. Gdy używasz samych getline albo samych cin >>, problem w ogóle nie istnieje.

06 — Formatowanie wyjścia

Jak sprawić, żeby wynik ładnie wyglądał

Samo cout wypisuje liczby po swojemu i zwykle to wystarcza. Czasem jednak chcesz dokładnie dwa miejsca po przecinku (bo to złotówki i grosze) albo równe kolumny (bo robisz tabelkę). Służą do tego manipulatory — krótkie słówka, które wstawiasz do cout tak samo jak zwykły tekst. Większość z nich mieszka w nagłówku <iomanip>, więc dopisz go na górze pliku.

ManipulatorCo robiPrzykład
"\n" Przechodzi do nowej linii. Twój domyślny wybór. cout << x << "\n";
endl To samo co "\n", ale dodatkowo natychmiast opróżnia bufor — w długiej pętli trochę spowalnia. cout << x << endl;
fixed Mówi: „pisz ułamki normalnie, z ustaloną liczbą miejsc po przecinku”. cout << fixed;
setprecision(k) Razem z fixed: dokładnie k miejsc po przecinku. setprecision(2) → 3.14
setw(k) Rezerwuje k znaków szerokości na następną wypisywaną rzecz — tak robi się równe kolumny. setw(5) →    42
setfill(z) Czym wypełnić puste miejsce przy setw. Domyślnie spacja. setfill('0') → 00042
left / right Dosunięcie do lewej albo do prawej wewnątrz setw. cout << left << setw(8);
boolalpha Wypisuje true / false zamiast 1 / 0. cout << boolalpha << b;
'\t' Tabulator — najszybszy sposób na rozdzielenie dwóch kolumn. cout << a << '\t' << b;
formatowanie.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double pi = 3.14159265;

    cout << pi << "\n";                        // domyslnie
    cout << fixed << setprecision(2);          // od teraz 2 miejsca
    cout << pi << "\n";

    // rowne kolumny: setw przed KAZDA wartoscia
    cout << setw(8) << "Ala"    << setw(5) << 95 << "\n";
    cout << setw(8) << "Bartek" << setw(5) << 7  << "\n";

    // zera zamiast spacji
    cout << setfill('0') << setw(5) << 42 << "\n";

    return 0;
}
▶ Wyjście programu
3.14159 3.14 Ala 95 Bartek 7 00042

Dwie rzeczy warte zapamiętania. fixed i setprecision działają aż do odwołania — raz ustawione obowiązują do końca programu. Za to setw dotyczy tylko najbliższej wypisywanej wartości, więc trzeba go powtarzać przed każdą.

07 — Wzorce wczytywania

Skąd wiadomo, kiedy przestać czytać

Przy jednej czy dwóch liczbach sprawa jest prosta. Gorzej, gdy danych jest wiele i program musi sam wiedzieć, kiedy skończyć. W praktyce spotkasz tylko trzy sytuacje — poniżej każda z nich z gotowym kodem do przepisania.

1️⃣

Wiesz, ile będzie danych

Pierwsza liczba mówi, ile ich będzie: najpierw cin >> n;, potem pętla wykonana n razy.

2️⃣

Czytasz do samego końca

Nikt nie mówi ile — czytasz, aż dane się skończą: while (cin >> x). Pętla zatrzyma się sama.

3️⃣

Czytasz do znaku końca

Dane kończy umówiona wartość, np. zero: while (cin >> x && x != 0). Tej ostatniej wartości zwykle nie liczymy.

wiem_ile.cpp
// wariant 1: n podane na starcie
int n;
cin >> n;

long long suma = 0;
for (int i = 0; i < n; i++) {
    int x;
    cin >> x;
    suma += x;
}

cout << suma;
▶ Wejście i wyjście
Wejście: 3 10 20 30 60
do_konca.cpp
// wariant 2: czytamy az do konca danych
long long suma = 0;
int x;

while (cin >> x) {
    suma += x;
}

cout << suma;
▶ Wejście i wyjście
Wejście: 10 20 30 40 100
do_zera.cpp
// wariant 3: zero konczy dane (i samo sie nie liczy)
#include <iostream>
using namespace std;

int main() {
    long long suma = 0;
    int ile = 0;
    int x;

    while (cin >> x && x != 0) {
        suma += x;
        ile++;
    }

    cout << "Liczb: " << ile << "\n";
    cout << "Suma:  " << suma << "\n";

    return 0;
}
▶ Wyjście programu
Wejście: 5 8 2 0 Liczb: 3 Suma: 15

Skąd wiesz, który wariant wybrać? Spójrz na przykładowe dane. Jeśli zaczynają się od samotnej liczby, która pasuje do liczby kolejnych wierszy — to wariant pierwszy. Jeśli po prostu się urywają — drugi. Jeśli kończą się podejrzanym zerem albo słowem KONIEC — trzeci.

08 — Przykładowe zadania

Sprawdź się na zadaniach

Sześć zadań ułożonych od najprostszego. Pierwsze trzy powinieneś napisać po samym przeczytaniu tej strony; trzy kolejne łączą po kilka rzeczy naraz. Rozwiązania są schowane — otwórz je dopiero po własnej próbie, nawet nieudanej. Nieudana próba uczy najwięcej.

Łatwe Przywitanie
Poproś użytkownika o imię, wczytaj je i przywitaj się: Czesc, Ala!
Jak to ugryźć: Potrzebujesz zmiennej typu string i nagłówka <string>. Imię to jedno słowo, więc wystarczy zwykłe cin >>.
Pokaż rozwiązanie
przywitanie.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string imie;

    cout << "Jak masz na imie? ";
    cin >> imie;

    cout << "Czesc, " << imie << "!\n";

    return 0;
}
Łatwe Trzy działania
Wczytaj dwie liczby całkowite i wypisz ich sumę, różnicę oraz iloczyn — każde w osobnej linii.
Jak to ugryźć: Dwie wartości wczytasz jedną linijką: cin >> a >> b;. Działanie możesz policzyć wprost w cout.
Pokaż rozwiązanie
trzy_dzialania.cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;

    cout << "Podaj dwie liczby: ";
    cin >> a >> b;

    cout << "Suma:    " << a + b << "\n";
    cout << "Roznica: " << a - b << "\n";
    cout << "Iloczyn: " << a * b << "\n";

    return 0;
}
Łatwe Pole prostokąta
Wczytaj dwa boki prostokąta (mogą mieć części ułamkowe) i wypisz jego pole z dokładnością do dwóch miejsc po przecinku.
Jak to ugryźć: Boki trzymaj w double, nie w int — inaczej 2.5 zamieni się w 2. Dwa miejsca po przecinku daje cout << fixed << setprecision(2);.
Pokaż rozwiązanie
pole.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double a, b;

    cout << "Podaj dwa boki: ";
    cin >> a >> b;

    cout << fixed << setprecision(2);
    cout << "Pole: " << a * b << "\n";

    return 0;
}
Średnie Tabliczka mnożenia
Wypisz tabliczkę mnożenia od 1 do 9 w równych kolumnach, tak żeby liczby ładnie się wyrównały.
Jak to ugryźć: Bez wyrównania wyniki jedno- i dwucyfrowe się rozjadą. setw(4) przed każdą liczbą zarezerwuje stałą szerokość. Dwie pętle: jedna po wierszach, druga po kolumnach.
Pokaż rozwiązanie
tabliczka.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    for (int w = 1; w <= 9; w++) {
        for (int k = 1; k <= 9; k++) {
            cout << setw(4) << w * k;
        }
        cout << "\n";            // koniec wiersza
    }

    return 0;
}
Średnie Średnia ocen
Na wejściu jest nieznana z góry liczba ocen (od 1 do 6). Wypisz, ile ich było, ich sumę oraz średnią z dokładnością do dwóch miejsc po przecinku.
Jak to ugryźć: To wariant drugi: while (cin >> ocena) skończy się sam. Średnią licz jako (double)suma / ile — bez rzutowania dostaniesz dzielenie całkowite i ułamek przepadnie.
Pokaż rozwiązanie
srednia.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int ocena;
    int ile = 0;
    int suma = 0;

    while (cin >> ocena) {
        suma += ocena;
        ile++;
    }

    cout << "Ocen:    " << ile << "\n";
    cout << "Suma:    " << suma << "\n";

    cout << fixed << setprecision(2);
    cout << "Srednia: " << (double)suma / ile << "\n";

    return 0;
}
Trudne Tabelka z imionami
Pierwszy wiersz zawiera liczbę n. Każdy z kolejnych n wierszy to imię i nazwisko (ze spacją), a po nim w osobnym wierszu liczba punktów. Wypisz wszystko jako tabelkę wyrównaną w kolumnach.
Jak to ugryźć: Mieszasz cin >> z getline, więc po każdym wczytaniu liczby wywołaj cin.ignore(); — inaczej getline złapie porzucony ENTER i zwróci pustą linię. Do kolumn użyj left i setw.
Pokaż rozwiązanie
tabelka.cpp
#include <iostream>
#include <iomanip>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    cin.ignore();            // wyrzuca ENTER po liczbie

    for (int i = 0; i < n; i++) {
        string osoba;
        getline(cin, osoba); // cale imie i nazwisko

        int punkty;
        cin >> punkty;
        cin.ignore();        // i znowu ENTER

        cout << left << setw(18) << osoba
             << right << setw(4) << punkty << "\n";
    }

    return 0;
}
09 — Porady

Częste błędy i dobre praktyki

⌨️
cin >> a pierwsza spacja
cin >> zmienna zawsze zatrzymuje się na białym znaku (spacji, tabulacji, ENTER). Do imion i nazwisk ze spacją użyj getline.
🧹
Pamiętaj o cin.ignore()
Mieszanie cin >> i getline bez cin.ignore() to jeden z najczęstszych błędów początkujących — getline "widzi" pusty ENTER.
🔀
Kolejność wczytywania
cin >> a >> b; wczytuje wartości w kolejności, w jakiej zostały wpisane — oddzielone spacją lub ENTER-em, bez różnicy.
🔡
Zgodność typów
Jeśli wpiszesz literę tam, gdzie program oczekuje liczby, cin "się zepsuje" i kolejne wczytania mogą działać niepoprawnie.
📃
endl vs "\n"
endl przechodzi do nowej linii i dodatkowo czyści bufor wyjścia — do bardzo częstego wypisywania w pętlach czasem szybszy jest zwykły "\n".
🧾
Wiele cout w jednej linii
Każde kolejne << dokleja kolejną wartość do tej samej linii wyjścia — można łączyć tekst i zmienne dowolnie.
