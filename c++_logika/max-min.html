01 — Dwie liczby

max i min — większa i mniejsza z dwóch

Zaczynamy od najprostszej sytuacji: masz dwie liczby i chcesz wiedzieć, która jest większa. Umiesz to już zrobić instrukcją if, ale C++ ma na to dwie gotowe funkcje, które będziesz pisać tysiące razy: max i min. W tej części zobaczysz, jak działają, co dokładnie „oddają”, jak zachowują się dla liczb ujemnych, liter i napisów, oraz poznasz jedyną pułapkę, na którą trzeba uważać — typy.

Pierwszy program

max(a, b) to większa z liczb a i b, a min(a, b) to mniejsza. Nazwy pochodzą od łacińskich słów maximum (największy) i minimum (najmniejszy). Obie funkcje mieszkają w bibliotece <algorithm>, ale <bits/stdc++.h> ma ją w środku, więc niczego nie dopisujesz.

pierwszy.cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << max(a, b) << "\n";   // większa
    cout << min(a, b) << "\n";   // mniejsza
    return 0;
}

Ten sam program uruchomiliśmy trzy razy, z różnymi danymi.

Za pierwszym razem wszystko jest oczywiste: 7 jest większe od 3.

Za drugim razem liczby są ujemne. Która jest większa: −4 czy −9? Większa jest ta, która leży bardziej na prawo na osi liczbowej, czyli bliżej zera: −4. Program to wie — nie musisz się o to martwić.

Za trzecim razem liczby są równe. Wtedy i większa, i mniejsza to po prostu 5. Nie ma tu żadnego błędu ani wyjątku.

max oddaje wartość — możesz jej użyć, jak chcesz

Pomyśl o max(a, b) jak o działaniu, tak jak o a + b. Komputer je wylicza i w tym miejscu programu pojawia się wynik. Taki wynik możesz wypisać, zapisać do zmiennej, pomnożyć, dodać do czegoś albo porównać — wszystko, co robisz ze zwykłą liczbą.

wartosc.cpp
int a = 12, b = 30;
int w = max(a, b);                       // w = 30
cout << w << "\n";
cout << max(a, b) * 2 << "\n";           // 30 * 2
cout << max(a, b) - min(a, b) << "\n";   // 30 - 12
cout << max(a, 20) << "\n";              // a z liczbą
cout << a << " " << b << "\n";           // a i b bez zmian
▶ Wyjście
30 60 18 20 12 30

Zwróć uwagę na trzy rzeczy.

Argumentami nie muszą być zmienne — max(a, 20) porównuje zmienną z liczbą.

max(a, b) - min(a, b) to odległość między liczbami: od większej odejmujemy mniejszą, więc wynik nigdy nie jest ujemny. To dokładnie to samo co abs(a - b).

Ostatni wiersz: max i min niczego nie zmieniają. Tylko patrzą na a i b i oddają wynik. Zmienne mają te same wartości co na początku.

Wynik, którego nikt nie zapisał, przepada Częsty błąd początkujących: max(a, b); w osobnej linijce, a potem cout << a; w nadziei, że w a jest teraz większa liczba. Nie jest! Funkcja policzyła wynik, ale nikt go nie zapisał ani nie wypisał, więc przepadł. Jeśli chcesz, żeby a stało się większą z dwóch liczb, napisz a = max(a, b);. Kompilator z włączonymi ostrzeżeniami (-Wall) nawet o tym przypomni: warning: ignoring return value of max — „ignorujesz wynik funkcji max”.
przepada.cpp
int a = 4, b = 9;
max(a, b);           // wynik nikomu się nie przydał
cout << a << "\n";
a = max(a, b);       // teraz zapisujemy go do a
cout << a << "\n";

Zapis a = max(a, b); czytaj tak: „nowe a to większa z liczb: stare a i b”. Jeśli b było większe, a dostaje wartość b. Jeśli nie — a zostaje takie, jakie było.

Ten zapis będzie bohaterem części 3: w pętli zamieni się w maks = max(maks, x); — rekord, który poprawia się z każdą wczytaną liczbą.

To samo bez max — dla porównania

Żeby nie było w tym magii: max robi dokładnie to, co umiesz już napisać instrukcją if. Poniżej trzy sposoby na tę samą rzecz. Wszystkie dają ten sam wynik — ale wersja z max mieści się w jednej krótkiej linijce i trudniej się w niej pomylić.

trzy_sposoby.cpp
int a = 8, b = 13;

int w1;                       // sposób 1: if / else
if (a > b) w1 = a;
else w1 = b;

int w2 = (a > b ? a : b);     // sposób 2: ?: z lekcji o if
int w3 = max(a, b);           // sposób 3: max

cout << w1 << " " << w2 << " " << w3 << "\n";
▶ Wyjście
13 13 13

Kiedy więc wybrać if, a kiedy max? Gdy chcesz tylko poznać większą liczbę — max. Gdy przy okazji musisz zrobić coś więcej (zapamiętać, kto miał więcej punktów, albo wypisać komunikat) — if. Do tej drugiej sytuacji wrócimy w części 4.

Najważniejsza pułapka: oba argumenty tego samego typu

max i min mają jeden kaprys: oba argumenty muszą być dokładnie tego samego typu. Dwa int-y — dobrze. Dwa double — dobrze. Ale int i double naraz — błąd kompilacji, i to z długim, strasznym komunikatem, w którym zobaczysz coś w rodzaju no matching function for call to max(int, double) oraz deduced conflicting types. Kompilator nie wie, jakiego typu ma być wynik, więc się poddaje.

zle_typy.cpp
cout << max(3, 2.5) << "\n";   // int i double — błąd

double b = 2.5;

Liczba 3 to dla C++ int, a 3.0 to double. Gdy porównujesz zmienną typu int ze zmienną typu double, zamień jedną z nich przed porównaniem: (double)a to wartość a jako double — tak samo jak w lekcji o typach zmiennych.

Najczęściej ta pułapka łapie przy long long. Liczba 7 napisana w programie to int, więc max(x, 7) dla long long x się nie skompiluje. Dopisz na końcu liczby literki LL — wtedy 7LL jest typu long long — albo zamień ją: (long long)7.

Nie tylko liczby: znaki i napisy

max i min działają dla wszystkiego, co da się porównać znakiem <. Znaki porównują się po kodach (pamiętasz z lekcji o napisach: wielkie litery 65–90, małe 97–122), a napisy — w porządku słownikowym, litera po literze. Pary z lekcji o parach też: najpierw po first, a przy remisie po second.

znaki_napisy.cpp
cout << max('k', 'c') << "\n";
cout << min('Z', 'a') << "\n";      // 'Z' ma kod 90, 'a' — 97
string s = "kot", t = "kotek";
cout << max(s, t) << "\n";
cout << min(s, t) << "\n";
pair<int, int> p = {2, 9}, q = {2, 5};
cout << max(p, q).second << "\n";   // remis na first, wygrywa second
▶ Wyjście
k Z kotek kot 9

max('k', 'c') to litera, która jest dalej w alfabecie.

min('Z', 'a') to wielkie Z, bo wszystkie wielkie litery mają mniejsze kody od małych — tak samo jak przy sortowaniu.

Napis „kot” jest początkiem napisu „kotek”, więc w słowniku stoi wcześniej — jest „mniejszy”.

Pary (2, 9) i (2, 5) remisują na first, więc rozstrzyga second: większa jest (2, 9).

02 — Trzy i więcej

Trzy, cztery, pięć liczb — max w max i lista w klamrach

max(a, b) porównuje dokładnie dwie liczby. A co, gdy liczb jest trzy albo pięć? Są dwa sposoby: wkładać jedno max w drugie albo podać wszystkie liczby naraz w klamrach. Poznasz oba, a potem użyjesz ich do trzech klasycznych zadań: noty sędziów, liczba środkowa i trójkąt.

max w max — czytamy od środka

Największą z trzech liczb dostaniesz tak: max(a, max(b, c)). Komputer liczy to od środka, tak jak nawiasy w matematyce: najpierw max(b, c) — większa z b i c — a potem porównuje ten wynik z a. To jak turniej: najpierw grają b i c, a zwycięzca gra w finale z a.

trzy.cpp
int a = 4, b = 9, c = 6;
cout << max(a, max(b, c)) << "\n";
cout << min(a, min(b, c)) << "\n";
cout << max(max(a, b), c) << "\n";   // inna kolejność, ten sam wynik
▶ Wyjście
9 4 9
krokco liczymywynik
1max(b, c) = max(9, 6)9
2max(a, 9) = max(4, 9)9

Kolejność „meczów” nie ma znaczenia: największa liczba wygra każdy mecz, w którym zagra, więc zawsze dojdzie do końca.

Dla czterech liczb wkładamy jeszcze głębiej: max(max(a, b), max(c, d)) — dwa półfinały i finał. Działa, ale przy pięciu liczbach nawiasów robi się tyle, że łatwo się w nich zgubić. Dlatego jest drugi sposób.

Lista w klamrach: max({…})

Wszystkie liczby możesz podać naraz, w klamrach wewnątrz nawiasów: max({a, b, c, d, e}). Klamry tworzą listę — taką samą, jakiej używałeś do wypełniania vectora: vector<int> v = {4, 9, 6};. Liczb w liście może być dowolnie wiele.

klamry.cpp
int a = 4, b = 9, c = 6, d = -2, e = 9;
cout << max({a, b, c, d, e}) << "\n";
cout << min({a, b, c, d, e}) << "\n";
cout << max({3, 1, 4, 1, 5, 9, 2, 6}) << "\n";
long long x = 7000000000LL;
cout << max({x, 5LL, 0LL}) << "\n";   // wszystkie long long
▶ Wyjście

Noty sędziów: odrzuć najwyższą i najniższą

W skokach narciarskich pięciu sędziów ocenia styl skoczka. Żeby jeden zbyt surowy albo zbyt łaskawy sędzia nie zepsuł wyniku, odrzuca się najwyższą i najniższą notę, a pozostałe trzy się sumuje. W programie to jedna linijka: suma wszystkich minus największa minus najmniejsza.

03 — Rekord w pętli

Rekord: maks = max(maks, x)

Lista w klamrach działa, gdy liczb jest kilka i znasz je, pisząc program. Ale w zadaniach liczb jest zwykle n — i n poznajesz dopiero po wczytaniu danych. Może ich być pięć, a może sto tysięcy. Wtedy potrzebny jest rekord: jedna zmienna, która pamięta najlepszą wartość widzianą do tej pory i poprawia się przy każdej kolejnej liczbie. To najważniejszy schemat tej lekcji — rekord pojawi się prawie w każdym zadaniu.

Sędzia na zawodach w skoku w dal

Sędzia nie musi zapisywać wszystkich skoków, żeby po zawodach wiedzieć, który był najdłuższy. Wystarczy, że trzyma w głowie dotychczasowy rekord. Po każdym skoku porównuje: jeśli nowy skok jest dłuższy, rekord się zmienia; jeśli nie — zostaje. Po ostatnim skoku rekord jest wynikiem całych zawodów. W programie „porównaj i weź lepszy” to dokładnie maks = max(maks, x);.

Rekord tylko z niektórych liczb

Co, jeśli szukasz największej liczby parzystej? Nie możesz zacząć od pierwszej liczby, bo może być nieparzysta. Nie możesz też zacząć od zera, bo parzyste liczby mogą być ujemne. A może parzystych nie ma wcale i trzeba wypisać BRAK? Rozwiązanie: dodatkowa zmienna bool jest, która mówi, czy rekord już istnieje. Pierwsza pasująca liczba zostaje rekordem bez porównywania.

    int x;
    cin >> x;
    if (x % 2 == 0) {
        if (!jest || x > maks) maks = x;
        jest = true;
    }
}

04 — Gdzie i kto

Gdzie był rekord, ile razy padł i kto go ustanowił

Samo max odpowiada tylko na pytanie „ile?”. Zadania często pytają o więcej: na której pozycji stoi największa liczba? Kto zdobył najwięcej punktów? Ile osób ma najlepszy wynik? Do tego potrzebny jest zwykły if, w którym razem z rekordem zapamiętujesz dodatkowe informacje. W tej części nauczysz się też panować nad remisami — sytuacją, gdy rekord występuje kilka razy.

Pozycja rekordu

Wracamy do sędziego: tym razem zapisuje nie tylko długość najlepszego skoku, ale też jego numer. Gdy pada nowy rekord, zmieniają się obie rzeczy naraz — dlatego zamiast max używamy if z dwiema instrukcjami w klamrach.

    int x;
    cin >> x;
    if (x > maks) {
        maks = x;
        poz = i;

Pierwsze czy ostatnie wystąpienie? > kontra >=

Jeden znak decyduje, które z równych wystąpień rekordu wygra. Z ostrym > rekord zmienia się tylko na lepszy, więc zostaje pierwsze wystąpienie. Z >= rekord zmienia się także na równy, więc każde kolejne wystąpienie nadpisuje poprzednie i zostaje ostatnie.

    if (v[i] > m1) { m1 = v[i]; p1 = i; }
    if (v[i] >= m2) { m2 = v[i]; p2 = i; }
}
cout << "pierwsza: " << p1 + 1 << "\n";
cout << "ostatnia: " << p2 + 1 << "\n";

Ile razy pojawia się rekord?

Prosty sposób to dwie pętle: pierwsza znajduje rekord, druga liczy, ile liczb jest mu równych. Da się to jednak zrobić w jednej pętli, z licznikiem ile. Gdy pada nowy rekord, licznik zaczyna od 1 — stare wystąpienia gorszego rekordu już się nie liczą. Gdy liczba wyrównuje rekord, licznik rośnie.

Czasem „najlepsza” nie znaczy „największa”. W zgadywance wygrywa liczba najbliżej celu. Odległość liczby x od celu to abs(x - cel) (z lekcji o parach: abs zabiera minus). Szukamy więc najmniejszej odległości, a przy remisie — powiedzmy — mniejszej liczby.

05 — Gotowce

max_element i min_element — rekord bez pętli

Gdy dane siedzą już w vectorze, tablicy albo napisie, pętli z rekordem nie musisz pisać sam. C++ ma gotowe polecenia max_element i min_element, które poznałeś przelotnie w lekcji o vectorze. Teraz przyjrzymy się im dokładnie: jak odczytać z nich wartość i pozycję, jak użyć ich na tablicy, na kawałku danych i na napisie, jak znaleźć oba skrajne elementy naraz i jak szukać rekordu według własnej reguły.

Strzałka na rekord

max_element(v.begin(), v.end()) przegląda vector od pierwszej strzałki do drugiej i oddaje strzałkę (iterator) na największy element — nie samą liczbę. Ze strzałki wyciągasz dwie rzeczy, tak jak w lekcji o vectorze: gwiazdka * daje wartość, na którą strzałka pokazuje, a odjęcie v.begin() daje numer pudełka. Gdy największych jest kilka, strzałka pokazuje pierwszy z nich.

Pamiętasz z lekcji o sortowaniu regułę porównania — lambdę, która odpowiada na pytanie „czy a jest przed b?”. max_element i min_element też ją przyjmują jako trzeci argument. });

06 — Granice

Nie mniej niż, nie więcej niż — przycinanie i przedziały

Do tej pory max i min szukały rekordów. Teraz poznasz ich drugie, równie częste zastosowanie: pilnowanie granic. Punkty życia w grze nie spadają poniżej zera, bateria nie naładuje się ponad 100%, a szklanka nie pomieści więcej wody, niż ma pojemności. Każde takie „nie mniej niż” i „nie więcej niż” to jedno max albo min. Na koniec użyjemy tego samego pomysłu do przedziałów: gdzie zaczyna się i kończy ich wspólna część.

Podłoga: max(0, x)

Postać w grze ma 30 punktów życia i dostaje 45 obrażeń. Ile ma życia? Matematycznie 30 − 45 = −15, ale w grze nie ma ujemnego życia — jest zero. Zapis max(0, hp - obrazenia) robi z zera podłogę: jeśli wynik jest dodatni, zostaje bez zmian; jeśli spadłby poniżej zera, max wybierze zero.

podloga.cpp
int hp = 30;
hp = max(0, hp - 12);   // 18 — normalnie
cout << hp << "\n";
hp = max(0, hp - 45);   // -27 → 0
cout << hp << "\n";
▶ Wyjście

Czytaj max(0, x) jako „x, ale nie mniej niż 0”. To samo zrobiłbyś if-em: if (hp < 0) hp = 0; — ale tu wszystko mieści się w jednej linijce z odejmowaniem.

Podłoga nie musi być zerem. „Ocena nie niższa niż 1” to max(1, ocena).

Sufit: min(limit, x)

W drugą stronę działa min. Bateria ma 85% i ładujesz ją o 30 punktów procentowych — nie będzie 115%, tylko 100%. Zapis min(100, bateria + 30) robi z setki sufit: „bateria + 30, ale nie więcej niż 100”.

Sufit przydaje się też, gdy coś ma ograniczoną pojemność. Przelewasz wodę z dzbanka do szklanki: przeleje się tyle, ile jest w dzbanku, ale nie więcej, niż zmieści się w szklance. Ile się zmieści? Pojemność minus to, co już jest w środku.

int bateria = 85;
bateria = min(100, bateria + 30);
cout << bateria << "\n";

szklanka += ile;
cout << ile << " " << dzbanek << " " << szklanka << "\n";

W szklance jest 150 ml, a mieści się 250 ml, więc wolnego miejsca jest 100 ml. W dzbanku jest dużo więcej (700 ml), więc przelewa się tylko 100 ml i szklanka jest pełna.

Gdyby w dzbanku było tylko 60 ml, min(60, 100) dałoby 60 — przelałaby się cała woda z dzbanka.

Podłoga i sufit naraz: przycinanie

Gdy wartość ma się mieścić między dwiema granicami — od lo do hi — składamy oba pomysły: max(lo, min(hi, x)). Czytamy od środka: min(hi, x) ścina wszystko powyżej górnej granicy, a max(lo, …) podnosi wszystko poniżej dolnej. Takie działanie nazywa się przycinaniem (po angielsku clamp), i od C++17 jest na nie gotowa funkcja clamp(x, lo, hi). Uwaga na kolejność: w clamp najpierw idzie wartość, potem dolna i górna granica.

Wspólna część dwóch przedziałów

Ola ma czas od 14 do 18, a Kuba od 16 do 20. Kiedy oboje mają czas? Wspólna część zaczyna się wtedy, gdy oboje już zaczęli — czyli w późniejszym z początków: max(14, 16) = 16. Kończy się, gdy ktoś pierwszy skończy — we wcześniejszym z końców: min(18, 20) = 18. Jeśli wyszło, że początek jest za końcem, wspólnej części nie ma. prostokaty.cpp
// prostokąt: lewy dolny róg (x1, y1), prawy górny (x2, y2)

cout << szer << " " << wys << " " << szer * wys << "\n";

07 — Podium

Dwie największe w jednym przejściu

Na zawodach nie liczy się tylko zwycięzca — jest też drugie i trzecie miejsce. Jak znaleźć drugą największą liczbę? Jeden sposób już znasz: posortować malejąco i wziąć v[1]. Działa, ale miesza kolejność danych i wymaga trzymania ich wszystkich w vectorze. W tej części poznasz sposób bez sortowania: dwa rekordy naraz, które w jednym przejściu pilnują złota i srebra. Potem użyjemy go do najlepszej pary, największego iloczynu i całego podium.

Złoto i srebro: m1 i m2

Trzymamy dwie zmienne: m1 — największa liczba do tej pory (złoto) i m2 — druga największa (srebro). Przychodzi nowa liczba x. Są trzy możliwości:

1) x jest większa od złota — nowa mistrzyni! Dotychczasowe złoto nie znika, tylko spada na srebro: najpierw m2 = m1, dopiero potem m1 = x.
2) x nie bije złota, ale jest większa od srebra — zabiera srebro: m2 = x.
3) x nie bije nikogo — nic się nie zmienia.

Dla liczb 9, 9, 5 program powyżej odpowie: m1 = 9, m2 = 9. Czy to dobrze? To zależy od treści zadania. Najlepsza para: suma i iloczyn

Największa suma dwóch różnych elementów to po prostu m1 + m2 — dwie największe liczby razem. Z iloczynem jest ciekawiej, bo minus razy minus daje plus. Całe podium: trzy największe

Schemat rozszerza się na trzy miejsca bez nowych pomysłów — jest tylko dłuższy łańcuch przesunięć. Gdy x bije złoto, wszyscy spadają o jedno miejsce: brąz dostaje srebro, srebro dostaje złoto. Gdy bije tylko srebro — przesuwa się srebro na brąz. Gdy bije tylko brąz — zabiera brąz.

Rekordy na bieżąco, widok z prawej i najlepszy zysk

Do tej pory rekord był ważny dopiero na końcu, po obejrzeniu wszystkich liczb. A przecież w trakcie pętli on też coś znaczy: po każdym kroku mówi, jaki jest rekord do tej pory. Biegacz notuje wyniki kolejnych treningów (powiedzmy, ile kilometrów przebiegł). Po każdym treningu chce wiedzieć, jaki jest jego rekord życiowy i czy właśnie go pobił. Najlepszy zysk: kup tanio, sprzedaj drogo

Znasz ceny akcji z n kolejnych dni. Możesz kupić jedną akcję w jednym dniu i sprzedać ją w którymś późniejszym. Jaki największy zysk da się osiągnąć? Sprawdzanie wszystkich par dni (kupno, sprzedaż) to pętla w pętli. Sprytniej: idziemy dzień po dniu i zakładamy, że sprzedajemy dzisiaj. Kiedy najlepiej było kupić? Oczywiście najtaniej — a najniższą cenę z dni wcześniejszych pamięta rekord mini. Zysk przy sprzedaży dziś to cena - mini, a najlepszy zysk to rekord tych wartości.

09 — Serie i fragmenty

Najdłuższa seria, najlepsze okno i największa suma fragmentu

Ostatnia część lekcji to rekordy wśród fragmentów — kawałków ciągu złożonych z sąsiednich liczb. Najdłuższa seria wygranych, najcieplejsze trzy dni z rzędu, najlepszy kawałek drogi. We wszystkich tych zadaniach działa ten sam pomysł: idziemy po ciągu, trzymamy coś, co opisuje fragment kończący się w bieżącym miejscu, i robimy z tego rekord. Na koniec zobaczysz, jak szukać maksimów i minimów w tabeli dwuwymiarowej.

Najdłuższa seria: obecny i najlepszy

Seria to fragment, w którym wszystkie liczby są takie same. Trzymamy dwie zmienne: obecny — długość serii, w której właśnie jesteśmy, i najlepszy — rekord. Jeśli liczba jest taka sama jak poprzednia, seria trwa (obecny++). Jeśli inna — zaczyna się nowa seria o długości 1. Po każdym kroku poprawiamy rekord.

vector<int> v = {7, 7, 2, 2, 2, 5, 2, 2};

for (int i = 1; i < (int)v.size(); i++) {
    if (v[i] == v[i - 1]) obecny++;
    else obecny = 1;
    najlepszy = max(najlepszy, obecny);   // w KAŻDYM kroku
}
cout << najlepszy << "\n";

Najlepsze okno: k kolejnych liczb

Masz temperatury z n dni i chcesz znaleźć najcieplejsze k dni z rzędu — czyli k kolejnych liczb o największej sumie. Takie k kolejnych liczb to okno, które przesuwamy po danych o jedno miejsce. vector<int> t = {2, 5, 1, 8, 7, 3, 4};

int najl = suma, start = 0;
for (int i = k; i < (int)t.size(); i++) {
    suma += t[i] - t[i - k];   // wchodzi t[i], wychodzi t[i - k]
    if (suma > najl) {
        najl = suma;

}

Największa suma fragmentu

A co, jeśli długość fragmentu jest dowolna? Liczby mogą być ujemne, więc nie opłaca się brać wszystkiego. Przykład: dla ciągu 2, −5, 3, 1, −2, 4, −6, 1 najlepszy kawałek to 3, 1, −2, 4 o sumie 6 — mimo że w środku jest −2. To zadanie ma piękne rozwiązanie w jednej pętli (w świecie programistów znane jako algorytm Kadane’a).

Pomysł: dla każdego miejsca i liczymy obecna — największą sumę fragmentu, który kończy się dokładnie w i. Taki fragment albo składa się z samej liczby x, albo jest najlepszym fragmentem kończącym się w i − 1 z doklejonym x. Wybieramy lepszą z tych dwóch możliwości: obecna = max(x, obecna + x). Innymi słowy: jeśli to, co mamy za sobą, ma sumę ujemną, lepiej to wyrzucić i zacząć od nowa. Wynikiem jest rekord wszystkich wartości obecna.

kadane.cpp
vector<long long> v = {2, -5, 3, 1, -2, 4, -6, 1};
long long obecna = v[0], najl = v[0];
for (int i = 1; i < (int)v.size(); i++) {
    obecna = max(v[i], obecna + v[i]);   // od nowa albo doklej
    najl = max(najl, obecna);
}
cout << najl << "\n";

Maksima i minima w tabeli

W tabeli dwuwymiarowej (vector vectorów z lekcji o vectorze) rekord można liczyć dla każdego wiersza, dla każdej kolumny albo dla całości. Ciekawy przykład: trzy trasy rowerowe, każda ma cztery podjazdy o różnej trudności. Trudność trasy to jej najtrudniejszy podjazd — maksimum wiersza. Chcemy wybrać trasę, która jest najłatwiejsza, czyli taką, której najtrudniejszy podjazd jest jak najłatwiejszy — najmniejsze z maksimów.

Baza zadań: max i min w praktyce

Znasz już wszystkie narzędzia: max i min dla dwóch liczb i dla listy w klamrach, zasadę jednego typu, rekord w pętli z dobrym startem, pozycję rekordu i remisy, liczenie wystąpień, max_element i min_element, przycinanie i wspólne części przedziałów, dwie i trzy największe liczby, rekordy na bieżąco od lewej i od prawej, najlepszy zysk, serie, okna i największą sumę fragmentu. Czas na zadania, które łączą kilka z tych rzeczy naraz. Są ułożone od najłatwiejszego do najtrudniejszego: najpierw rozgrzewka z jednym pomysłem, potem zadania średnie, w których łączysz dwa, trzy pomysły, a na końcu trudne — z wielkim finałem.

Przy każdym zadaniu widać, jakich zagadnień używa — także tych z poprzednich lekcji, jak napisy, pary, vector czy sortowanie. Jeśli coś brzmi obco, wróć do odpowiedniej części — mapa lekcji jest na górze strony. A tu masz najważniejsze schematy z lekcji w jednym miejscu:

Ściąga: gotowe schematy

Dwie i więcej liczb

max(a, b)   min(a, b)
max({a, b, c, d})
a + b + c - mx - mn  // środkowa
max(x, 0LL)          // long long!

Oba argumenty tego samego typu: 3.0, 7LL, (int)s.size().

Rekord w pętli

int maks = pierwsza;   // albo INT_MIN
for (...) maks = max(maks, x);
int mini = INT_MAX;
for (...) mini = min(mini, x);

Nigdy od 0, gdy liczby mogą być ujemne. Rekord „tylko z niektórych” — z flagą bool jest.

Gdzie i ile razy

if (x > maks) { maks = x; poz = i; }
// >  pierwsze,  >= ostatnie
if (x > maks) { maks = x; ile = 1; }
else if (x == maks) ile++;

Kto ma rekord — zapamiętaj imię albo numer obok wartości.

Gotowce

*max_element(v.begin(), v.end())
max_element(...) - v.begin()  // numer
max_element(t, t + n) - t
auto [lo, hi] = minmax_element(...);

Pierwsze wystąpienie (hi z minmax — ostatnie). Reguła jak w sort: [](a, b) { return … < …; }.

Granice

max(0, x)               // podłoga
min(limit, x)           // sufit
max(lo, min(hi, x))     // clamp(x, lo, hi)
max(0, min(b1, b2) - max(a1, a2))

Wspólna część: max początków, min końców.

Podium

if (x > m1) { m2 = m1; m1 = x; }
else if (x > m2) m2 = x;
// różne: else if (x < m1 && x > m2)
max(m1 * m2, s1 * s2)   // iloczyn

Najpierw przesuń w dół, potem wpisz na górę.

Na bieżąco

pm[i] = max(pm[i - 1], a[i]);
sm[i] = max(sm[i + 1], a[i]);
zysk = max(zysk, cena - mini);
mini = min(mini, cena);

Para „wcześniej — później”: jedna pętla z rekordem zamiast dwóch pętli.

Serie i fragmenty

ob = (warunek) ? ob + 1 : 1;
naj = max(naj, ob);        // co krok!
suma += t[i] - t[i - k];   // okno
ob = max(x, ob + x);       // Kadane

Sumy fragmentów bywają duże — long long.

Jak rozwiązywać zadania z max i min 1) Znajdź w treści słowo „naj…” i przetłumacz je: największy, najdłuższy, najlepszy → max; najmniejszy, najkrótszy, najtańszy, najszybszy → min. 2) Ustal, czego jest rekord: samej liczby, czegoś policzonego (długości, odległości, sumy), a może fragmentu? 3) Wybierz start: pierwsza liczba, INT_MIN / INT_MAX albo flaga. 4) Sprawdź, co z remisami i czy trzeba podać pozycję — wtedy if z ostrym albo nieostrym znakiem. 5) Gdy w pomyśle pojawia się pętla w pętli, a n jest duże, poszukaj rekordu „na bieżąco”. 6) Przetestuj skrajności: jedna liczba, wszystkie równe, wszystkie ujemne, ogromne wartości (long long!).

11 — Częste błędy

Częste błędy i dobre praktyki

⚖️
Dwa różne typy
max(3, 2.5), max(x, 7) dla long long x i max(d, s.size()) się nie skompilują. Wyrównaj typy: 3.0, 7LL, (int)s.size().
🗑️
Wynik bez przypisania
max(a, b); w osobnej linijce niczego nie zmienia — wynik przepada. Pisz a = max(a, b); albo od razu go wypisz.
0️⃣
Rekord od zera
Przy samych liczbach ujemnych maks = 0 daje 0 — liczbę spoza danych. Zaczynaj od pierwszej liczby albo od INT_MIN / INT_MAX.
🧩
Brak klamer
Trzy liczby i więcej to max({a, b, c}). Bez klamer, w max(a, b, c), trzecie miejsce czeka na regułę porównania i kompilator zgłasza błąd.
🎯
> czy >=
Ostry znak zostawia pierwsze wystąpienie rekordu, nieostry — ostatnie. Przeczytaj w treści, które jest potrzebne, zanim napiszesz warunek.
🔁
Licznik bez zerowania
Licząc wystąpienia rekordu w jednej pętli, przy nowym rekordzie ustaw ile = 1. Inaczej licznik pamięta wyrównania starego, gorszego rekordu.
⭐
Gwiazdka przy max_element
max_element oddaje strzałkę. Wartość to *max_element(…), numer to max_element(…) - v.begin(). Na pustym vectorze gwiazdka czyta śmieci.
🧱
Odwrócone granice
Przycinanie to max(lo, min(hi, x)) albo clamp(x, lo, hi). Przy dolnej granicy stoi max, przy górnej min — zamienione dają zawsze tę samą liczbę.
🥈
Srebro nadpisane złotem
Przy nowym rekordzie najpierw m2 = m1, dopiero potem m1 = x. Odwrotna kolejność kopiuje nowe złoto na srebro.
🏁
Ostatnia seria
Rekord serii poprawiaj w każdym kroku, a nie tylko przy przerwaniu — ostatnia seria nigdy się nie przerywa i bez tego przepada.
⏱️
Pętla w pętli przy dużym n
Szukanie maksimum osobno dla każdego miejsca to około n·n kroków. Rekord „na bieżąco” (pm, sm, najniższa cena do tej pory) robi to samo w jednej pętli.
💥
Za mały typ
Iloczyn dwóch liczb rzędu miliarda, suma fragmentu albo pole prostokąta nie mieszczą się w int. Używaj long long — razem z LLONG_MIN, LLONG_MAX i 0LL.
12 — Idź dalej

Co dalej?

max i min będą w Twoich programach już zawsze — w rekordach, granicach, przedziałach i w niemal każdym zadaniu, w którym pada słowo „naj…”. Rekord liczony „na bieżąco” wróci w programowaniu dynamicznym, a szukanie najlepszego fragmentu — w zadaniach olimpijskich na każdym poziomie. Następna lekcja to kolejne narzędzie matematyczne: zaokrąglanie liczb w górę, w dół i do najbliższej całości. A jeśli chcesz trenować z mentorami — dołącz do T-Olimpians.
