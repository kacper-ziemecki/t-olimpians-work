Max i min w C++

Największa i najmniejsza wartość — potrzebne w co drugim programie. C++ ma na to gotowe funkcje, więc nie musisz za każdym razem pisać if-a.

01 — Podstawy

Dwie liczby, jedna odpowiedź

Funkcje max(a, b) i min(a, b) robią dokładnie to, co sugerują nazwy: zwracają większą i mniejszą z dwóch wartości. Mieszkają w nagłówku <algorithm>, więc dopisz go na górze pliku.

bez_funkcji.cpp
int a = 7, b = 3;

// tak sie da, ale po co
int wiekszy;
if (a > b) {
    wiekszy = a;
} else {
    wiekszy = b;
}

cout << wiekszy;
▶ Wyjście programu
7
z_funkcja.cpp
#include <algorithm>

int a = 7, b = 3;

// to samo w jednej linijce
int wiekszy = max(a, b);
int mniejszy = min(a, b);

cout << wiekszy << " " << mniejszy;
▶ Wyjście programu
7 3

Działają dla dowolnego typu, który da się porównać: liczb całkowitych, ułamków, znaków, a nawet napisów (wtedy porównują alfabetycznie). Jest tylko jeden warunek: oba argumenty muszą być tego samego typu.

typy.cpp
#include <iostream>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    cout << max(3, 8) << "\n";              // liczby calkowite
    cout << max(2.5, 1.75) << "\n";         // ulamki
    cout << max('a', 'z') << "\n";          // znaki
    cout << max(string("Ala"), string("Ola")) << "\n";

    // BLAD: int i double to rozne typy
    // cout << max(3, 2.5);

    // poprawka - obie strony tak samo
    cout << max(3.0, 2.5);

    return 0;
}
▶ Wyjście programu
8 2.5 z Ola 3

Gdy porównujesz trzy wartości, po prostu zagnieżdżasz wywołania: max(a, max(b, c)). Można też podać całą listę w klamrach — max({a, b, c, d}) — co przy czterech i więcej robi się czytelniejsze.

02 — Wzorzec rekordu

Największy element w zbiorze danych

Najczęstsze zastosowanie w praktyce to nie porównanie dwóch liczb, tylko znalezienie rekordu wśród wielu. Schemat jest zawsze ten sam i nazywa się wzorcem rekordu: trzymasz zmienną z dotychczas najlepszą wartością i poprawiasz ją w pętli.

🏁

wartość startowa

Ustaw ją na pierwszy element, nie na zero. Zero zepsuje wynik, gdy wszystkie dane są ujemne.

🔄

pętla po reszcie

Przechodzisz pozostałe wartości i porównujesz każdą z aktualnym rekordem.

📈

maks = max(maks, x)

Jedna linijka zamiast if-a. Czyta się jako: „nowy rekord to większa z dwóch wartości”.

📍

zapamiętaj też gdzie

Jeśli potrzebujesz nie tylko wartości, ale i pozycji, dołóż drugą zmienną aktualizowaną w tym samym if-ie.

rekord.cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;

    int pierwszy;
    cin >> pierwszy;

    int maks = pierwszy;      // start od PIERWSZEJ wartosci
    int mini = pierwszy;

    for (int i = 1; i < n; i++) {
        int x;
        cin >> x;

        maks = max(maks, x);
        mini = min(mini, x);
    }

    cout << "Najwiekszy:  " << maks << "\n";
    cout << "Najmniejszy: " << mini << "\n";
    cout << "Roznica:     " << maks - mini << "\n";

    return 0;
}
▶ Wyjście programu
Wejście: 5 -4 -9 -2 -7 -1 Najwiekszy: -1 Najmniejszy: -9 Roznica: 8

Zwróć uwagę na dane w przykładzie: same liczby ujemne. Gdybyś zaczął od int maks = 0, program odpowiedziałby 0 — wartość, której w danych w ogóle nie ma. To jeden z najczęstszych błędów w zadaniach i wykrywa się go dopiero na testach z liczbami ujemnymi.

Gdy dane siedzą już w tablicy albo wektorze, C++ ma gotowca: max_element i min_element. Uwaga — zwracają one wskazanie na element, a nie samą wartość, więc przed nimi stawia się gwiazdkę.

recznie.cpp
vector<int> v = {4, 8, 15, 16, 23};

int maks = v[0];
for (int i = 1; i < v.size(); i++) {
    maks = max(maks, v[i]);
}

cout << maks;
▶ Wyjście programu
23
gotowcem.cpp
#include <algorithm>
vector<int> v = {4, 8, 15, 16, 23};

// gwiazdka = "wartosc spod tego wskazania"
int maks = *max_element(v.begin(), v.end());
int mini = *min_element(v.begin(), v.end());

cout << maks << " " << mini;
▶ Wyjście programu
23 4
03 — Przycinanie zakresu

max i min razem

Jest jeszcze jedna sztuczka, którą warto znać. Gdy chcesz wcisnąć wartość do przedziału — żeby nie wyszła poza ustalone granice — wystarczy złożyć obie funkcje: max(dolny, min(gorny, x)).

Czyta się to od środka: min(gorny, x) ścina wszystko powyżej górnej granicy, a max(dolny, ...) podnosi wszystko poniżej dolnej. Przydaje się przy poziomie głośności, punktach życia w grze albo współrzędnych, które nie mogą uciec poza planszę.

przycinanie.cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    // glosnosc musi zostac w przedziale 0-100
    int zmiany[] = {150, -30, 42};

    for (int x : zmiany) {
        int glosnosc = max(0, min(100, x));
        cout << x << " -> " << glosnosc << "\n";
    }

    return 0;
}
▶ Wyjście programu
150 -> 100 -30 -> 0 42 -> 42

Ta sama sztuczka bez max i min wymagałaby dwóch if-ów. Nie chodzi o to, że jest szybsza — chodzi o to, że mieści się w jednej linijce i trudniej się pomylić.

04 — Ściąga

Sposoby szukania wartości skrajnych

Osiem zapisów, które pokrywają wszystkie sytuacje z max i min, jakie spotkasz w zadaniach dla początkujących.

ZapisCo robiUwaga
max(a, b) Większą z dwóch wartości. Oba argumenty tego samego typu
min(a, b) Mniejszą z dwóch wartości. —
max(a, max(b, c)) Największą z trzech. Zagnieżdżone wywołanie
max({a, b, c, d}) Największą z listy. Klamry w środku nawiasu
maks = max(maks, x) Aktualizuje rekord w pętli. Krócej niż if
*max_element(v.begin(), v.end()) Największy element wektora. Gwiazdka obowiązkowa
*min_element(v.begin(), v.end()) Najmniejszy element wektora. —
max(dolny, min(gorny, x)) Wciska x w przedział. Gotowiec do zapamiętania

Piąty wiersz to serce większości zadań: maks = max(maks, x) w pętli. Cała trudność sprowadza się do tego, żeby dobrze ustawić wartość startową — zawsze na pierwszy element danych.

05 — Przykładowe zadania

Sprawdź się na zadaniach

Sześć zadań od najprostszego. W każdym chodzi o ten sam wzorzec rekordu — różni je tylko to, co uznajesz za „lepsze”. Najpierw spróbuj sam.

Łatwe Większa z dwóch
Wczytaj dwie liczby i wypisz większą, mniejszą oraz ich różnicę.
Jak to ugryźć: Zadanie na rozgrzewkę — chodzi o samo wywołanie max i min. Pamiętaj o #include <algorithm>.
Pokaż rozwiązanie
wieksza.cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    cout << "Wieksza:  " << max(a, b) << "\n";
    cout << "Mniejsza: " << min(a, b) << "\n";
    cout << "Roznica:  " << max(a, b) - min(a, b) << "\n";

    return 0;
}
Łatwe Rozstęp temperatur
Wczytaj n pomiarów temperatury (mogą być ujemne) i wypisz najwyższą, najniższą oraz różnicę między nimi.
Jak to ugryźć: Wzorzec rekordu. Wczytaj pierwszy pomiar osobno i od niego zacznij obie zmienne — start od zera zepsułby wynik przy samych mrozach.
Pokaż rozwiązanie
temperatury.cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;

    int t;
    cin >> t;

    int maks = t, mini = t;

    for (int i = 1; i < n; i++) {
        cin >> t;
        maks = max(maks, t);
        mini = min(mini, t);
    }

    cout << "Najwyzsza: " << maks << "\n";
    cout << "Najnizsza: " << mini << "\n";
    cout << "Rozstep:   " << maks - mini << "\n";

    return 0;
}
Łatwe Ogranicz do przedziału
Wczytaj n liczb i wypisz każdą z nich przyciętą do przedziału 0–100. Wartości mniejsze od zera zamień na 0, większe od stu na 100.
Jak to ugryźć: Gotowiec z ostatniej sekcji: max(0, min(100, x)). Jedna linijka zamiast dwóch if-ów.
Pokaż rozwiązanie
przytnij.cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;

    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        cout << max(0, min(100, x)) << " ";
    }

    return 0;
}
Średnie Gdzie był rekord
Wczytaj n liczb i wypisz największą z nich oraz jej pozycję (numerując od 1). Jeśli rekord się powtarza, podaj pierwsze wystąpienie.
Jak to ugryźć: Tu max nie wystarczy, bo potrzebujesz też indeksu. Wróć do zwykłego if-a i aktualizuj obie zmienne naraz. Warunek > (a nie >=) zapewni pierwsze wystąpienie.
Pokaż rozwiązanie
gdzie_rekord.cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int maks, pozycja = 1;
    cin >> maks;

    for (int i = 2; i <= n; i++) {
        int x;
        cin >> x;

        if (x > maks) {        // > a nie >=
            maks = x;
            pozycja = i;
        }
    }

    cout << "Rekord: " << maks << "\n";
    cout << "Pozycja: " << pozycja << "\n";

    return 0;
}
Średnie Największy iloczyn dwóch liczb
Wczytaj n liczb (mogą być ujemne) i wypisz największy iloczyn, jaki da się uzyskać, mnożąc dwie z nich.
Jak to ugryźć: Uwaga na pułapkę: dwie duże liczby ujemne po pomnożeniu dają dużą liczbę dodatnią. Trzeba więc sprawdzić dwie możliwości — iloczyn dwóch największych albo dwóch najmniejszych. Najprościej: posortuj i porównaj oba warianty.
Pokaż rozwiązanie
iloczyn.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<long long> v(n);
    for (int i = 0; i < n; i++) cin >> v[i];

    sort(v.begin(), v.end());

    // dwie najwieksze ALBO dwie najmniejsze
    long long a = v[n - 1] * v[n - 2];
    long long b = v[0] * v[1];

    cout << max(a, b);
    return 0;
}
Trudne Najdłuższy rosnący fragment
Wczytaj n liczb i wypisz długość najdłuższego fragmentu, w którym każda kolejna liczba jest większa od poprzedniej.
Jak to ugryźć: Trzymaj dwie zmienne: obecny (długość fragmentu, w którym właśnie jesteś) i najlepszy (rekord). Gdy liczba rośnie — zwiększ obecny; gdy nie — zresetuj go do 1. Rekord aktualizuj w każdym obrocie, nie tylko przy resecie.
Pokaż rozwiązanie
rosnacy.cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;

    int poprzedni;
    cin >> poprzedni;

    int obecny = 1;
    int najlepszy = 1;

    for (int i = 1; i < n; i++) {
        int x;
        cin >> x;

        if (x > poprzedni) obecny++;
        else               obecny = 1;

        najlepszy = max(najlepszy, obecny);
        poprzedni = x;
    }

    cout << najlepszy;
    return 0;
}
06 — Porady

Częste błędy i dobre praktyki

📦
Nagłówek <algorithm>
Bez #include <algorithm> funkcje max i min mogą nie zadziałać, mimo że u niektórych kompilatorów przechodzą przypadkiem.
⚖️
Te same typy po obu stronach
max(3, 2.5) się nie skompiluje — pierwszy argument to int, drugi double. Napisz max(3.0, 2.5).
🚫
Nie zaczynaj od zera
Startową wartość rekordu ustawiaj na pierwszy element danych. Przy samych liczbach ujemnych start od zera daje wynik, którego w danych nie było.
⭐
max_element zwraca wskazanie
Przed wywołaniem postaw gwiazdkę: *max_element(v.begin(), v.end()). Bez niej dostaniesz adres zamiast wartości.
📍
Pozycja, nie tylko wartość
Jeśli potrzebujesz wiedzieć, gdzie był rekord, użyj zwykłego if-a i zapamiętuj indeks obok wartości.
🎯
Przycinanie do przedziału
max(dolny, min(gorny, x)) wciska wartość w zadany przedział. Zapamiętaj jako gotowca.
