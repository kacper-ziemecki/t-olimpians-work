Operator modulo w C++

Jeden znak, który znasz już z podstawówki: reszta z dzielenia. W programowaniu okazuje się jedną z najczęściej używanych rzeczy w ogóle.

01 — Podstawy

Reszta z dzielenia, czyli %

Pamiętasz dzielenie z resztą z podstawówki? „14 podzielić przez 4 to 3 i reszty 2”. C++ potrafi policzyć obie te liczby, tylko każdą innym znakiem. Ukośnik / daje wynik dzielenia, a procent % daje resztę.

dzielenie.cpp
int a = 14, b = 4;

cout << a / b << "\n";   // ile razy sie miesci
cout << a % b << "\n";   // ile zostalo

// sprawdzenie: 3 * 4 + 2 = 14
▶ Wyjście programu
3 2
wiecej_przykladow.cpp
cout << 10 % 3 << "\n";   // 10 = 3*3 + 1
cout << 20 % 5 << "\n";   // dzieli sie rowno
cout << 7 % 10 << "\n";   // 7 jest mniejsze od 10
cout << 0 % 8 << "\n";    // zero przez cokolwiek
▶ Wyjście programu
1 0 7 0

Zwróć uwagę na trzeci przykład: 7 % 10 daje 7. Skoro siódemka nie mieści się w dziesiątce ani razu, cała zostaje jako reszta. To nie jest wyjątek, tylko reguła: reszta zawsze jest mniejsza od dzielnika.

Z tej reguły wynika najważniejsza własność %: wynik a % b zawsze mieści się w przedziale od 0 do b - 1 (dla dodatniego a). Dlatego % 2 daje tylko 0 albo 1, a % 10 tylko cyfrę od 0 do 9.

zakres_wyniku.cpp
#include <iostream>
using namespace std;

int main() {
    // % 3 daje zawsze 0, 1 albo 2 - w kolko
    for (int i = 0; i <= 9; i++) {
        cout << i << "%3=" << i % 3 << "  ";
    }
    return 0;
}
▶ Wyjście programu
0%3=0 1%3=1 2%3=2 3%3=0 4%3=1 5%3=2 6%3=0 7%3=1 8%3=2 9%3=0
02 — Parzystość

Najczęstsze zastosowanie: czy liczba jest parzysta

Liczba jest parzysta, gdy dzieli się przez 2 bez reszty. Czyli dokładnie wtedy, gdy liczba % 2 daje zero. To jedno z pierwszych zastosowań, jakie napotkasz — i najprostsze.

parzysta.cpp
int x;
cin >> x;

if (x % 2 == 0) {
    cout << "parzysta";
} else {
    cout << "nieparzysta";
}
▶ Wyjście programu
Wejście: 7 nieparzysta
co_druga.cpp
// wypisz tylko liczby parzyste z zakresu 1-10
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        cout << i << " ";
    }
}
▶ Wyjście programu
2 4 6 8 10

Ten sam pomysł działa dla dowolnej liczby. x % 3 == 0 sprawdza podzielność przez 3, x % 100 == 0 — przez sto. Zawsze chodzi o to samo pytanie: czy zostaje zero?

fizzbuzz.cpp
#include <iostream>
using namespace std;

int main() {
    // klasyczne cwiczenie: liczby 1-15, ale
    // podzielne przez 3 zamieniamy na "Fizz",
    // przez 5 na "Buzz", przez oba na "FizzBuzz"
    for (int i = 1; i <= 15; i++) {
        if (i % 15 == 0)     cout << "FizzBuzz ";
        else if (i % 3 == 0) cout << "Fizz ";
        else if (i % 5 == 0) cout << "Buzz ";
        else                 cout << i << " ";
    }
    return 0;
}
▶ Wyjście programu
1 2 Fizz 4 Buzz Fizz 7 8 Fizz Buzz 11 Fizz 13 14 FizzBuzz
03 — Cyfry liczby

Jak rozłożyć liczbę na cyfry

Drugie wielkie zastosowanie: wyciąganie cyfr. n % 10 daje ostatnią cyfrę liczby, a n / 10 tę cyfrę obcina. Powtarzając oba kroki w pętli, rozłożysz dowolną liczbę na pojedyncze cyfry — od prawej do lewej.

🔚

n % 10

Ostatnia cyfra. Dla 4821 daje 1.

✂️

n / 10

Obcina ostatnią cyfrę. Z 4821 robi 482.

🔁

while (n > 0)

Powtarzaj oba kroki, dopóki coś jeszcze zostało.

⚠️

kolejność

Cyfry wychodzą od końca — najpierw jedności, potem dziesiątki.

cyfry.cpp
#include <iostream>
using namespace std;

int main() {
    int n = 4821;
    int suma = 0;

    while (n > 0) {
        int cyfra = n % 10;    // ostatnia
        cout << cyfra << " ";
        suma += cyfra;

        n /= 10;               // obcinamy ja
    }

    cout << "\nSuma cyfr: " << suma;
    return 0;
}
▶ Wyjście programu
1 2 8 4 Suma cyfr: 15

Prześledź to na kartce: 4821 → reszta 1, zostaje 482 → reszta 2, zostaje 48 → reszta 8, zostaje 4 → reszta 4, zostaje 0 → koniec. Cztery obroty, cztery cyfry. Jeśli zamiast % 10 dasz % 2, w ten sam sposób rozłożysz liczbę na zera i jedynki.

04 — Zawijanie w kółko

Zegar, dni tygodnia i inne cykle

Skoro % n zawsze daje wynik od 0 do n-1, to idealnie nadaje się do wszystkiego, co chodzi w kółko: godzin na zegarze, dni tygodnia, kolorów, które się powtarzają.

zegar.cpp
// jaka godzina bedzie za 50 godzin,
// jesli teraz jest 20:00?
int teraz = 20;
int za = 50;

int wynik = (teraz + za) % 24;

cout << "Bedzie godzina " << wynik;
▶ Wyjście programu
Bedzie godzina 22
dni.cpp
// dzien 0 = poniedzialek
// jaki dzien bedzie za 100 dni?
int dzis = 0;
int za = 100;

int wynik = (dzis + za) % 7;

cout << "Dzien numer " << wynik;
▶ Wyjście programu
Dzien numer 2

Ten sam trik pozwala „chodzić w kółko” po liście rzeczy. Zapis (i + 1) % n zwiększa i o jeden, ale po dojściu do końca wraca na początek zamiast wyjść poza zakres.

w_kolko.cpp
#include <iostream>
using namespace std;

int main() {
    // trzy kolory powtarzane w kolko
    for (int i = 0; i < 8; i++) {
        int kolor = i % 3;

        if (kolor == 0)      cout << "czerwony ";
        else if (kolor == 1) cout << "zielony ";
        else                 cout << "niebieski ";
    }
    return 0;
}
▶ Wyjście programu
czerwony zielony niebieski czerwony zielony niebieski czerwony zielony
05 — Pułapki

Trzy rzeczy, które zaskakują

Pierwsza: w C++ reszta z liczby ujemnej też jest ujemna. -7 % 3 daje -1, a nie 2, jak nauczyłeś się w szkole. Jeśli wynik ma być zawsze dodatni, napraw go jedną linijką: ((a % n) + n) % n.

ujemne.cpp
cout << (-7 % 3) << "\n";       // -1
cout << (7 % -3) << "\n";       // 1

// poprawka - zawsze wynik 0..n-1
int a = -7, n = 3;
cout << ((a % n) + n) % n;      // 2
▶ Wyjście programu
-1 1 2
przez_zero.cpp
int a = 10, b = 0;

// UWAGA: to wysypie program!
// cout << a % b;

// zawsze sprawdzaj dzielnik
if (b != 0) {
    cout << a % b;
} else {
    cout << "nie dziele przez zero";
}
▶ Wyjście programu
nie dziele przez zero

Druga: % działa wyłącznie na liczbach całkowitych. Na double kompilator zgłosi błąd. To nie jest usterka — dla ułamków pojęcie „reszty” po prostu nie ma sensu.

Trzecia: dzielenie przez zero, także przez %, wysypuje program — nie zwraca żadnej dziwnej wartości, tylko kończy działanie z błędem. Gdy dzielnik pochodzi z wejścia, zawsze sprawdź go przez if.

06 — Ściąga

Gotowe zapisy z modulo

Wszystkie te zapisy poznałeś już na tej stronie. Tabelka jest po to, żeby mieć je w jednym miejscu — wróć tu, gdy będziesz pisać zadanie i zapomnisz szczegółu.

ZapisCo dajeKiedy tego użyjesz
a % b Resztę z dzielenia a przez b. Podstawa wszystkiego poniżej
x % 2 == 0 Prawdę, gdy x jest parzyste. Parzystość, co drugi element
x % k == 0 Prawdę, gdy x dzieli się przez k bez reszty. Podzielność przez cokolwiek
n % 10 Ostatnią cyfrę liczby. Suma cyfr, sprawdzanie ostatniej cyfry
n / 10 Liczbę bez ostatniej cyfry. Zawsze w parze z n % 10
(a + b) % n Wynik zawinięty do zakresu 0…n-1. Zegar, dni tygodnia, cykle
(i + 1) % n Następną pozycję, z powrotem na początek po ostatniej. Chodzenie w kółko po liście
((a % n) + n) % n Resztę zawsze dodatnią, także dla ujemnego a. Gdy dane mogą być ujemne

Ostatni wiersz wygląda dziwnie, ale robi prostą rzecz: jeśli reszta wyszła ujemna, dodaje do niej n, żeby wskoczyła z powrotem do zakresu. Zapamiętaj go jako gotowca — przyda się, gdy tylko Twoje dane mogą być ujemne.

07 — Przykładowe zadania

Sprawdź się na zadaniach

Sześć zadań od najprostszego. Wszystkie da się rozwiązać samym %, if i pętlą — nic więcej nie jest potrzebne. Najpierw spróbuj sam, rozwiązanie jest schowane pod przyciskiem.

Łatwe Parzysta czy nieparzysta
Wczytaj liczbę całkowitą i wypisz parzysta albo nieparzysta.
Jak to ugryźć: Jedno porównanie: x % 2 == 0. Dla liczb, które mogą być ujemne, bezpieczniej napisać x % 2 != 0 dla nieparzystych.
Pokaż rozwiązanie
parzysta.cpp
#include <iostream>
using namespace std;

int main() {
    int x;
    cin >> x;

    if (x % 2 == 0) {
        cout << "parzysta";
    } else {
        cout << "nieparzysta";
    }

    return 0;
}
Łatwe Ostatnia cyfra
Wczytaj liczbę naturalną i wypisz jej ostatnią cyfrę oraz liczbę bez tej cyfry. Dla 4821 odpowiedzią jest 1 i 482.
Jak to ugryźć: Dokładnie ta para, o której była mowa w sekcji o cyfrach: n % 10 i n / 10. Żadnej pętli tu nie potrzeba.
Pokaż rozwiązanie
ostatnia_cyfra.cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    cout << "Ostatnia cyfra: " << n % 10 << "\n";
    cout << "Bez niej:       " << n / 10 << "\n";

    return 0;
}
Łatwe FizzBuzz
Wypisz liczby od 1 do n, ale te podzielne przez 3 zamień na Fizz, przez 5 na Buzz, a przez oba na FizzBuzz.
Jak to ugryźć: Kolejność warunków ma znaczenie! Sprawdzenie podzielności przez 15 musi być pierwsze — inaczej liczba 15 wpadnie do warunku dla trójki i nigdy nie zobaczysz napisu FizzBuzz.
Pokaż rozwiązanie
fizzbuzz.cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    for (int i = 1; i <= n; i++) {
        if (i % 15 == 0)     cout << "FizzBuzz\n";
        else if (i % 3 == 0) cout << "Fizz\n";
        else if (i % 5 == 0) cout << "Buzz\n";
        else                 cout << i << "\n";
    }

    return 0;
}
Średnie Suma cyfr
Wczytaj liczbę naturalną i wypisz sumę wszystkich jej cyfr. Dla 4821 odpowiedzią jest 15.
Jak to ugryźć: Pętla while (n > 0), a w środku para n % 10 i n /= 10. Sumę ustaw na zero przed pętlą.
Pokaż rozwiązanie
suma_cyfr.cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;

    int suma = 0;
    while (n > 0) {
        suma += n % 10;
        n /= 10;
    }

    cout << suma;
    return 0;
}
Średnie Zegar 24-godzinny
Wczytaj aktualną godzinę (0–23) oraz liczbę godzin do przodu. Wypisz, która będzie godzina.
Jak to ugryźć: Dodaj obie liczby i weź resztę z dzielenia przez 24. Jeśli liczba godzin może być ujemna (cofanie czasu), użyj poprawki ((a % 24) + 24) % 24.
Pokaż rozwiązanie
zegar.cpp
#include <iostream>
using namespace std;

int main() {
    int teraz, za;
    cin >> teraz >> za;

    // poprawka dziala tez dla cofania czasu
    int wynik = ((teraz + za) % 24 + 24) % 24;

    cout << "Bedzie godzina " << wynik;
    return 0;
}
Trudne Palindrom liczbowy
Wczytaj liczbę naturalną i sprawdź, czy czyta się tak samo od przodu i od tyłu. Dla 12321 odpowiedzią jest TAK, dla 1234 — NIE.
Jak to ugryźć: Zbuduj liczbę odwróconą tak jak w temacie o pętli while: odwrocona = odwrocona * 10 + n % 10. Uwaga — musisz zapamiętać oryginalną liczbę w osobnej zmiennej, bo pętla zniszczy n.
Pokaż rozwiązanie
palindrom.cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;

    long long oryginal = n;      // zapamietujemy!
    long long odwrocona = 0;

    while (n > 0) {
        odwrocona = odwrocona * 10 + n % 10;
        n /= 10;
    }

    if (odwrocona == oryginal) {
        cout << "TAK";
    } else {
        cout << "NIE";
    }

    return 0;
}
08 — Porady

Częste błędy i dobre praktyki

➖
Ujemne dają ujemne
-7 % 3 to -1, nie 2. Gdy potrzebujesz wyniku dodatniego, użyj ((a % n) + n) % n.
💥
Dzielenie przez zero
a % 0 wysypuje program. Jeśli dzielnik pochodzi od użytkownika, sprawdź go przez if (b != 0).
🔢
Tylko liczby całkowite
% nie działa na double ani float — kompilator zgłosi błąd. Do reszty z ułamków służy funkcja fmod.
🔄
Para % i /
n % 10 daje ostatnią cyfrę, n / 10 ją obcina. Te dwie operacje prawie zawsze chodzą razem.
⚖️
Parzystość
x % 2 == 0 to parzysta, x % 2 == 1 to nieparzysta. Dla liczb ujemnych bezpieczniejsze jest x % 2 != 0.
🎯
Zawijanie indeksu
(i + 1) % n zwiększa i, ale po ostatniej pozycji wraca na początek zamiast wyjść poza zakres.
