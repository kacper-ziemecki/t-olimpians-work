Pair — dwie wartości w jednym pudełku

Imię i liczba punktów. Godzina i minuta. Współrzędne x i y. Bardzo często dwie wartości należą do siebie i powinny trzymać się razem. Para — pair — skleja je w jedno pudełko z dwiema przegródkami: first i second. Zobaczysz, jak tworzyć pary, liczyć na punktach, godzinach, ułamkach i przedziałach, porównywać pary jak słowa w słowniku, trzymać je w tablicach, chodzić nimi po planszy i sortować jedną linijką. Na koniec rozwiążesz olimpijskie zadania z przedziałami i zdarzeniami. Po każdej części czekają ćwiczenia ze sprawdzarką.

01 — Pierwsza para

Para: jedno pudełko, dwie przegródki

Zacznijmy od problemu, który para rozwiązuje. W lekcji o tablicach trzymałeś imiona uczniów w jednej tablicy, a ich punkty w drugiej. Uczeń numer 0 to imię z pudełka imie[0] i punkty z pudełka punkty[0]. Wystarczy jednak jedna nieuwaga, żeby te dwie tablice się rozjechały. Zobacz:

rozjechane.cpp
string imie[2] = {"Ola", "Jan"};
int punkty[2] = {95, 87};
swap(imie[0], imie[1]);    // zamieniamy kolejność uczniów…
                           // …ale zapominamy o punktach!
cout << imie[0] << " " << punkty[0] << "\n";
cout << imie[1] << " " << punkty[1] << "\n";
▶ Wyjście — źle
Jan 95 Ola 87
razem.cpp
pair<string, int> u[2] = {{"Ola", 95}, {"Jan", 87}};
swap(u[0], u[1]);          // zamieniamy całych uczniów
cout << u[0].first << " " << u[0].second << "\n";
cout << u[1].first << " " << u[1].second << "\n";

W lewym programie Jan nagle ma 95 punktów, które zdobyła Ola. Kompilator nie protestuje, bo z jego punktu widzenia to dwie niezależne tablice. W prawym programie imię i punkty siedzą w jednym pudełku — w parze — więc zamieniając pudełka, zamieniasz całych uczniów. Nie da się „zgubić” punktów po drodze. Nie przejmuj się, jeśli zapis po prawej wygląda na razie obco: w tej części rozbierzemy go na kawałki.

pair — jedno pudełko, dwie przegródki

Para to zmienna, która przechowuje dwie wartości naraz. Wyobraź sobie pudełko przedzielone na pół: w lewej przegródce leży jedna wartość, w prawej — druga. Lewa przegródka nazywa się first (pierwsza), a prawa second (druga). Parę tworzysz tak: pair<int, int> p;. W nawiasach ostrych podajesz dwa typy: typ przegródki first i typ przegródki second.

p
3.first
7.second
pair<int, int> p = {3, 7}; — jedno pudełko o nazwie p. W przegródce first leży 3, w przegródce second leży 7.
pierwsza_para.cpp
pair<int, int> p;      // para dwóch liczb int
p.first = 3;           // wkładamy 3 do pierwszej przegródki
p.second = 7;          // i 7 do drugiej
cout << p.first << " " << p.second << "\n";
cout << p.first + p.second << "\n";
▶ Wyjście
3 7 10

Do przegródki dostajesz się przez kropkę: p.first i p.second. Każda przegródka zachowuje się jak zwykła zmienna swojego typu — tutaj int. Możesz do niej coś wpisać, wypisać ją, dodawać, mnożyć, zwiększać przez ++.

Para jest w bibliotece <utility>, ale nie musisz jej osobno dołączać: wciąga ją już <iostream>, <string> i oczywiście <bits/stdc++.h>.

first i second piszesz bez nawiasów W lekcji o napisach pisałeś s.length() — z nawiasami, bo length to polecenie, które coś liczy. first i second to nie polecenia, tylko nazwy przegródek. Piszesz p.first, a nie p.first() — z nawiasami program się nie skompiluje.

Wartości od razu: klamry i make_pair

Wpisywanie każdej przegródki osobno jest długie. Parę możesz wypełnić od razu przy tworzeniu — wartości w klamrach, w kolejności: najpierw first, potem second. Drugi sposób to funkcja make_pair(a, b), która robi parę z dwóch wartości. Klamry działają też później, przy zwykłym przypisaniu — i to jest ważna różnica w porównaniu z tablicą, której klamrami później już nie wypełnisz.

klamry.cpp
pair<int, int> a = {3, 7};          // klamry przy tworzeniu
pair<int, int> b = make_pair(5, 1); // make_pair robi parę
pair<int, int> c;
c = {9, 2};                         // klamry działają też później
cout << a.first << " " << a.second << "\n";
cout << b.first << " " << b.second << "\n";
cout << c.first << " " << c.second << "\n";
▶ Wyjście
3 7 5 1 9 2

Wszystkie trzy sposoby dają taki sam rodzaj pary. Klamry są najkrótsze i to ich będziemy używać najczęściej. make_pair spotkasz w starszych programach i w internecie — dobrze go rozpoznawać.

Zapis c = {9, 2}; wymienia całą zawartość pary naraz: obie przegródki dostają nowe wartości w jednej linijce.

Różne typy w jednej parze

Przegródki pary nie muszą mieć tego samego typu. To jedna z największych zalet pary: w jednym pudełku zmieścisz imię i wiek, literę i liczbę, współrzędne z przecinkiem. Typy wpisujesz w nawiasach ostrych w tej samej kolejności, w jakiej potem podajesz wartości.

typy.cpp
pair<string, int> uczen = {"Ola", 95};
pair<char, int> ocena = {'A', 6};
pair<double, double> punkt = {1.5, -2.25};
pair<int, long long> duze = {3, 5000000000};
cout << uczen.first << " ma " << uczen.second << " pkt\n";
cout << ocena.first << ocena.second << "\n";
cout << punkt.first + punkt.second << "\n";
cout << duze.second * duze.first << "\n";

Nowa para ma zera

Pamiętasz śmieci w tablicy utworzonej wewnątrz main? Z parą tego problemu nie ma. Para utworzona bez wartości dostaje w każdej przegródce „zero” swojego typu: liczby dostają 0, napisy — pusty napis. Zawsze, nawet w środku main.

zera.cpp
pair<int, int> p;           // bez wartości
pair<string, int> q;        // też bez wartości
cout << p.first << " " << p.second << "\n";
cout << "[" << q.first << "] " << q.second << "\n";
▶ Wyjście
0 0 [] 0

p to para (0, 0), a q — para z pustym napisem i zerem. Nawiasy kwadratowe wokół q.first to znany z lekcji o napisach trik, dzięki któremu widać, że napis jest pusty.

Dzięki temu para świetnie nadaje się na licznik albo zbiornik na wynik: tworzysz ją bez wartości i od razu możesz zwiększać przegródki.

Wczytywanie i wypisywanie

pair<int, int> p;

cout << "(" << p.first << ", " << p.second << ")\n";
cout << p.first << ":" << p.second << "\n";

Kopia, porównanie i zamiana

Z parą jest tak wygodnie jak z napisem. Znak = robi pełną, osobną kopię. Znak == sprawdza, czy obie przegródki są takie same. A swap zamienia wartości miejscami — dwie przegródki jednej pary albo dwie całe pary.

kopia.cpp
pair<int, int> a = {1, 2};
pair<int, int> b = a;             // osobna kopia
b.second = 5;                     // zmieniamy tylko b
cout << a.second << " " << b.second << "\n";
cout << (a == b) << "\n";         // czy równe?
b.second = 2;
cout << (a == b) << "\n";
swap(a.first, a.second);          // zamiana wewnątrz pary
cout << a.first << " " << a.second << "\n";

Zmiana jednej przegródki — prześledźmy

Ostatni przykład tej części pokazuje, że przegródki to zwykłe zmienne. Prześledź program w tabelce — w każdym wierszu fioletowa liczba to przegródka, która właśnie się zmieniła.

pair<int, int> p = {4, 10};
p.first++;                  // 4 → 5
p.second -= p.first;        // 10 - 5 = 5
p.first *= 3;               // 5 * 3 = 15
p = {p.second, p.first};    // zamiana przez klamry
cout << p.first << " " << p.second << "\n";

02 — Pary z życia

Pary z życia: punkty, godziny, ułamki, przedziały

Para to tylko pudełko z dwiema przegródkami — znaczenie nadajesz jej Ty. Te same dwie liczby mogą być punktem na mapie, godziną na zegarze, ułamkiem albo odcinkiem czasu. W tej części przejdziemy przez cztery najczęstsze „pary z życia” i przy okazji poznamy trzy małe, bardzo przydatne funkcje: abs, max i min. Przy każdej parze warto zostawić sobie komentarz, co oznacza first, a co second — po tygodniu sam tego nie będziesz pamiętał.

Punkt na płaszczyźnie: (x, y)

Punkt na kartce w kratkę opisują dwie liczby: x (jak daleko w prawo) i y (jak wysoko). To naturalna para: pair<int, int> a = {1, 2}; — a.first to x, a.second to y. Jak daleko są od siebie dwa punkty? Na olimpiadzie często liczy się odległość „taksówkarza” (zwaną też odległością miejską): taksówka nie jeździ na ukos, tylko wzdłuż ulic — najpierw w poziomie, potem w pionie. Odległość to różnica x plus różnica y, obie wzięte bez minusa.

„Bez minusa” załatwia funkcja abs(x) — wartość bezwzględna: abs(-5) to 5, a abs(3) to 3. Dzięki niej nie musisz się zastanawiać, który punkt jest bardziej na lewo.

taksowka.cpp
pair<int, int> a, b;          // first = x, second = y
cin >> a.first >> a.second >> b.first >> b.second;
int dx = abs(a.first - b.first);
int dy = abs(a.second - b.second);
cout << dx + dy << "\n";

Dzielimy przez 2.0, a nie przez 2 — inaczej dzielenie liczb całkowitych obcięłoby 2,5 do 2 (pamiętasz pułapkę 7 / 2 z lekcji o typach?). Dlatego środek trzymamy w parze pair<double, double>.

Godzina: (godzina, minuta)

Godzina 13:45 to też para: {13, 45}. Jak dodać do niej 100 minut? Najprościej zamienić godzinę na liczbę minut od północy, dodać, a potem rozłożyć z powrotem na godziny i minuty — dzieleniem i resztą z dzielenia, jak w lekcji o modulo. Reszta z dzielenia przez 24 · 60 = 1440 dba o to, żeby po północy zegar zaczął liczyć od zera.

dodaj_minuty.cpp
pair<int, int> t = {13, 45};             // 13:45
int k = 100;                             // dodajemy 100 minut
int minuty = t.first * 60 + t.second + k;
minuty %= 24 * 60;                       // po północy znów od 0
t = {minuty / 60, minuty % 60};
cout << t.first << ":" << t.second << "\n";

Ułamek: (licznik, mianownik)

Ułamek ⅓ to para {1, 3}: first to licznik, second to mianownik. Dodawanie ułamków znasz ze szkoły: a/b + c/d = (a·d + c·b) / (b·d). Potem warto ułamek skrócić — podzielić licznik i mianownik przez ich największy wspólny dzielnik, liczony algorytmem Euklidesa z lekcji o modulo.

ulamki.cpp
pair<long long, long long> x = {1, 6}, y = {1, 3};

                                x.second * y.second};
long long a = s.first, b = s.second;    // NWD — algorytm Euklidesa
while (b != 0) {
    long long r = a % b;
    a = b;
    b = r;
}
s = {s.first / a, s.second / a};        // skracamy przez NWD
cout << s.first << "/" << s.second << "\n";

03 — Porównywanie par

Porównywanie par: najpierw first, potem second

W części 1 widziałeś, że == sprawdza obie przegródki pary. Pary umieją jednak więcej: można zapytać, która z dwóch par jest mniejsza. To jedna z najważniejszych umiejętności pary — dzięki niej w części 7 posortujesz całą tablicę par jedną linijką. Dobra wiadomość: zasadę już znasz. Pary porównują się dokładnie tak jak słowa w słowniku, które porównywałeś w lekcji o napisach.

Najpierw first, a przy remisie second

Gdy porównujesz dwie pary, C++ najpierw patrzy na przegródki first. Jeśli są różne — ta para, której first jest mniejszy, jest mniejsza, i koniec: second w ogóle nie jest oglądany. Dopiero gdy first są równe, o wyniku decydują przegródki second. Dokładnie tak jak w słowniku: pierwsza litera rozstrzyga, a gdy jest taka sama — patrzymy na drugą.

porownania.cpp
pair<int, int> a = {1, 9}, b = {2, 0}, c = {1, 5}, d = {1, 9};
cout << (a < b) << "\n";    // first: 1 < 2 — to rozstrzyga
cout << (c < a) << "\n";    // first równe, więc second: 5 < 9
cout << (b < a) << "\n";    // first: 2 > 1 — b jest większa
cout << (a == d) << "\n";   // obie przegródki równe
cout << (a <= d) << "\n";   // równe, więc „mniejsza lub równa”

if (a > b) swap(a, b);

04 — Tablica par

Tablica par: rząd par zamiast dwóch tablic

Pojedyncza para przydaje się rzadko. Prawdziwa siła pojawia się, gdy par jest dużo: lista uczniów z punktami, lista punktów na mapie, lista produktów z cenami. Wtedy robisz tablicę par — dokładnie taką tablicę jak w lekcji o tablicach, tylko w każdym pudełku leży cała para. To jest właśnie rozwiązanie problemu z początku lekcji: zamiast dwóch równoległych tablic masz jedną, w której dane każdej osoby trzymają się razem.

05 — Rozpakowywanie i pary w parach

Rozpakowywanie i pary w parach

Ciągłe pisanie u[i].first i u[i].second szybko robi się męczące — a po kilku linijkach trudno pamiętać, która przegródka to imię, a która punkty. W tej części poznasz dwie rzeczy. Pierwsza to rozpakowywanie: nadajesz przegródkom pary własne, czytelne nazwy. Druga to para w parze: gdy wartości są trzy, druga przegródka sama może być parą — i wtedy trzy wartości porównują się naraz, we właściwej kolejności.

auto [a, b] — nazwy zamiast first i second

Zapis auto [imie, punkty] = u; tworzy dwie nowe zmienne i wkłada do nich przegródki pary: do pierwszej first, do drugiej second. Słowo auto znasz z lekcji o typach — kompilator sam odgadnie, że imie to string, a punkty to int. Nawiasy są kwadratowe.

rozpakuj.cpp
pair<string, int> u = {"Ola", 95};
auto [imie, punkty] = u;      // imie = "Ola", punkty = 95
cout << imie << " ma " << punkty << " pkt\n";
punkty = 100;                 // zmieniamy kopię…
cout << u.second << "\n";     // …a para zostaje bez zmian
▶ Wyjście

Zmienne imie i punkty to kopie przegródek. Zmiana punkty nie zmienia pary u — dokładnie tak jak w pętli for (char c : s) bez znaku &.

Rozpakowywanie wymaga C++17. Sprawdzarka i każdy nowy kompilator go mają. Jeśli Twój edytor zgłasza błąd przy nawiasach kwadratowych, poszukaj w jego ustawieniach opcji standardu C++ i wybierz C++17 (albo nowszy).

auto &[a, b] — zmiany trafiają do pary

Gdy chcesz przez nowe nazwy zmieniać parę, dopisz & — tak samo jak w for (char &c : s). Wtedy x i y nie są kopiami, tylko drugimi nazwami przegródek: co zrobisz z x, dzieje się z p.first.

swap(x, y);           // zamieniamy przegródki p
cout << p.first << " " << p.second << "\n";

06 — Pary na planszy

Pary na planszy: kierunki i ruchy

W lekcji o tablicach poznałeś plansze: tablice dwuwymiarowe i napisy ułożone w wiersze, po których chodziłeś, sprawdzając sąsiednie kratki. Kratkę na planszy opisują dwie liczby — numer wiersza i numer kolumny — więc to idealne miejsce dla par. W tej części para będzie dwiema rzeczami naraz: pozycją (wiersz, kolumna) i krokiem, czyli o ile zmienia się wiersz i kolumna przy jednym ruchu. Dzięki temu ruchy w czterech, a nawet ośmiu kierunkach zapiszesz jedną pętlą zamiast łańcucha if-ów.

Kierunki jako pary

Ustalmy, jak jest numerowana plansza: wiersze od góry (wiersz 0 to górny), kolumny od lewej. Krok w górę zmniejsza numer wiersza o 1, a kolumny nie zmienia — to para (−1, 0). Krok w prawo nie zmienia wiersza i zwiększa kolumnę — (0, 1). Cztery kierunki to cztery pary, które wygodnie trzymać w tablicy:

07 — Sortowanie par

Sortowanie par: sort i klucz na pierwszym miejscu

W części 3 porządkowałeś trzy pary ręcznie, trzema zamianami. Dla stu albo stu tysięcy par tak się nie da. C++ ma gotowe polecenie sort, które układa całą tablicę w kolejności rosnącej — jedną linijką. Jak sort działa w środku i jakie są różne sposoby sortowania, poznasz dokładnie w lekcji o sortowaniu. Tutaj wystarczy Ci jedno: sort porównuje elementy tak samo jak operator <. A skoro pary umieją się porównywać — pary układają się same, najpierw po first, a przy remisie po second.

sort — cała tablica w porządku jedną linijką

Zapis sort(a, a + n); układa rosnąco pierwsze n pudełek tablicy a, od a[0] do a[n - 1]. Drugi argument, a + n, czytaj jako „aż do pudełka n — ale bez niego”. To ta sama zasada co w pętli i < n. Polecenie działa na liczbach, napisach (alfabetycznie, jak w lekcji o napisach) i na parach.

sort_liczby.cpp
int a[6] = {5, 2, 9, 1, 5, 3};
sort(a, a + 6);                    // całe 6 pudełek
for (int i = 0; i < 6; i++) {
    cout << a[i] << " ";
}
cout << "\n";
string s[4] = {"ola", "ala", "ewa", "ela"};
sort(s, s + 4);                    // napisy — alfabetycznie
for (int i = 0; i < 4; i++) {
    cout << s[i] << " ";
}
cout << "\n";
▶ Wyjście

sort jest w bibliotece <algorithm> (jest też w <bits/stdc++.h>). Zmienia tablicę w miejscu — po sortowaniu stara kolejność przepada.

Gdy tablica ma zapas, na przykład int a[1005], a liczb jest n, sortujesz tylko zajęte pudełka: sort(a, a + n). Gdybyś napisał sort(a, a + 1005), do sortowania trafiłyby też puste pudełka.

Sortowanie jest szybkie: sto tysięcy liczb układa w ułamku sekundy.

08 — Pary na olimpiadzie

Pary na olimpiadzie: przedziały i zdarzenia

Połączenie par z sortowaniem to jeden z najczęstszych schematów w zadaniach olimpijskich. Typowa historia: na wejściu jest mnóstwo przedziałów — wizyt w sklepie, wykładów, pomalowanych kawałków płotu — i trzeba odpowiedzieć na pytanie, które dla nieposortowanych danych wymagałoby porównywania każdego z każdym. Po posortowaniu par wystarcza jedno przejście pętlą. W tej części poznasz cztery takie schematy: scalanie przedziałów, zdarzenia, najbliższą parę i zachłanny wybór. Na koniec zobaczysz, dlaczego to wszystko jest tak szybkie.

Scalanie przedziałów

Mamy kilka przedziałów, które mogą na siebie nachodzić — na przykład godziny, w których działała lampa. Chcemy je połączyć w rozłączne kawałki. Pomysł: posortuj przedziały po początku. Wtedy idziesz od lewej i trzymasz bieżący kawałek. Kolejny przedział albo zaczyna się przed końcem bieżącego (nachodzi na niego — rozszerzasz bieżący), albo za nim (bieżący jest gotowy — wypisujesz go i zaczynasz nowy).

int n;

Najbliższa para po sortowaniu

Na prostej drodze stoi n domów. Jaka jest najmniejsza odległość między dwoma domami? Porównywanie każdego z każdym to n² / 2 par — dla stu tysięcy domów za dużo. Zachłanny wybór: najwięcej wykładów

W auli odbywają się wykłady, każdy od pewnej godziny do pewnej godziny. Chcesz pójść na jak najwięcej z nich, ale nie możesz być na dwóch naraz. Który wykład wybrać najpierw? Okazuje się, że zawsze najlepiej wybrać ten, który najwcześniej się kończy — zostawia najwięcej czasu na resztę. Potem z pozostałych, które zaczynają się nie wcześniej niż koniec wybranego, znowu ten kończący się najwcześniej. Taki sposób — „bierz to, co teraz wygląda najlepiej” — nazywa się algorytmem zachłannym.

Żeby sortować po końcu, koniec musi stać w first. Dlatego wczytujemy wykład do pary (koniec, początek).

wyklady.cpp
int n;
cin >> n;
pair<int, int> w[1005];               // (koniec, początek)
for (int i = 0; i < n; i++) {
    cin >> w[i].second >> w[i].first;  // wejście: początek koniec
}
sort(w, w + n);                       // od najwcześniej kończącego się
int ile = 0, wolneOd = -1;            // od kiedy jesteśmy wolni
for (int i = 0; i < n; i++) {
    if (w[i].second >= wolneOd) {     // zaczyna się, gdy jesteśmy wolni
        ile++;
        wolneOd = w[i].first;
    }
}
cout << ile << "\n";

Intuicja, dlaczego to działa: wykład, który kończy się najwcześniej, „zabiera” najmniej czasu z przyszłości. Każdy inny pierwszy wybór kończyłby się później i mógłby tylko przeszkodzić kolejnym. Dowód takiego algorytmu to temat na dalsze lekcje — tu ważne, żeby zapamiętać schemat.

Ile to wszystko kosztuje?

Dlaczego sortowanie tak bardzo przyspiesza? Po sortowaniu wystarcza jedno przejście pętlą, czyli n kroków.

Baza zadań: pary w praktyce

Znasz już wszystko, co potrzebne: first i second, klamry i make_pair, punkty, godziny, ułamki i przedziały zapisane jako pary, kolejność par i sztuczkę z minusem, tablice par i parę (wartość, numer), rozpakowywanie i pary w parach, kierunki na planszy, sortowanie par oraz scalanie przedziałów, zdarzenia i zachłanny wybór. Czas na zadania, które łączą kilka z tych rzeczy naraz. Są ułożone od najłatwiejszego do najtrudniejszego: najpierw rozgrzewka z jednym pomysłem, potem zadania średnie — prostokąty, punkty niezdominowane, balony, pole działki — a na końcu trudne, z mrówką Langtona, największym trójkątem, pokryciem odcinka i wielkim finałem.

10 — Częste błędy

Częste błędy i dobre praktyki

🧩
p.first, nie p.first()
first i second to nazwy przegródek, a nie polecenia — piszesz je bez nawiasów. Z nawiasami program się nie skompiluje.
🖨️
cout << p nie działa
Para nie umie się wypisać ani wczytać sama. Pracuj na przegródkach: cin >> p.first >> p.second; i wypisuj je w formacie, którego chce zadanie.
🔀
Kolejność typów i wartości
pair<int, string> ma liczbę w first. Klamry {"Ola", 95} do niej nie pasują. Typy w nawiasach ostrych i wartości w klamrach muszą iść w tej samej kolejności.
⚖️
second tylko przy remisie
(1, 1000) < (2, 0), bo o wyniku decyduje first. second liczy się dopiero wtedy, gdy first są równe — jak druga litera w słowniku.
🥇
Najważniejsze do first
Sortujesz po punktach? Punkty idą do first. Godziny porównujesz? (godzina, minuta), nie odwrotnie. Kolejność przegródek to kolejność kryteriów.
➖
„Mniej znaczy lepiej” — minus
Więcej punktów, ale mniej czasu? Para {punkty, -czas} i szukasz największej. Nie zapomnij cofnąć minusa przy wypisywaniu.
🏷️
Numer w parze
Po sortowaniu stara kolejność przepada. Jeśli będzie Ci potrzebna, zrób parę (wartość, numer) jeszcze przed sortowaniem.
📏
sort(t, t + n)
Sortuj tylko zajęte pudełka. sort(t, t + 1005) wciągnie do sortowania puste pary (0, 0) i rozjedzie wynik.
🔁
auto [a, b] to kopie
Zmiany w rozpakowanych zmiennych nie wracają do pary. Chcesz zmieniać parę — pisz auto &[a, b]. Pętla for (auto [a, b] : t) idzie po całej tablicy, także po zapasie.
🧭
Brzegi przed kratką
Na planszy najpierw sprawdź, czy nowa pozycja leży na planszy, a dopiero potem zaglądaj do p[nw][nk]. Obrót w lewo to (d + 3) % 4, nie (d - 1) % 4.
📐
Czy końce się liczą?
Przedziały [1, 5] i [5, 8] — nachodzą na siebie czy nie? To zależy od treści. Zdecyduj raz i sprawdź warunek (<= czy <) oraz kolejność zdarzeń w tej samej chwili.
🌍
Duże tablice par globalnie
Sto tysięcy par to 800 KB. Takie tablice deklaruj przed main, a wyniki mnożenia współrzędnych trzymaj w long long.
