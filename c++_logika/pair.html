01 — Podstawy

Dwie wartości w jednym pudełku

Wyobraź sobie, że masz wypisać wyniki zawodów: nazwisko i liczbę punktów. Możesz trzymać je w dwóch osobnych tablicach — ale wtedy przy sortowaniu musisz pamiętać, żeby przestawiać oba naraz. Jeden błąd i Kowalski dostaje punkty Nowaka.

pair rozwiązuje to raz na zawsze: skleja dwie wartości w jedną. Dobierasz się do nich przez .first i .second. Nagłówek to <utility>, ale zwykle jest już dołączony przez inne biblioteki, więc rzadko trzeba o nim pamiętać.

📦

pair<int, string> p;

Tworzy parę: pierwsza wartość to liczba, druga to tekst. Typy mogą być dowolne i różne.

1️⃣

p.first

Pierwsza wartość pary. Czytasz i zapisujesz jak zwykłą zmienną.

2️⃣

p.second

Druga wartość pary. Uwaga: żadnych nawiasów — to nie jest funkcja.

🔨

{a, b}

Najkrótszy sposób utworzenia pary: p = {5, "Ala"};

⚖️

p1 < p2

Pary porównują się same: najpierw po first, a przy remisie po second.

📋

vector<pair<...>>

Lista par — najczęstsze zastosowanie. Tym zajmiemy się w trzeciej sekcji.

podstawy.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // para: liczba punktow i nazwisko
    pair<int, string> wynik;

    wynik.first = 95;
    wynik.second = "Kowalski";

    cout << wynik.second << ": "
         << wynik.first << " pkt\n";

    // krocej - od razu przy tworzeniu
    pair<int, string> drugi = {87, "Nowak"};

    cout << drugi.second << ": "
         << drugi.first << " pkt\n";

    return 0;
}
▶ Wyjście programu
Kowalski: 95 pkt Nowak: 87 pkt

Kiedy sięgać po parę, a kiedy po coś innego? Para jest idealna, gdy wartości są dokładnie dwie i ich znaczenie jest oczywiste z kontekstu. Gdy pól jest trzy albo więcej, albo gdy po tygodniu sam nie będziesz pamiętał, co siedzi w second — lepsza będzie własna struktura z nazwanymi polami (temat Struct).

02 — Sortowanie par

Dlaczego pary same się sortują

Tu kryje się największa zaleta pary. Gdy porównujesz dwie pary, C++ robi to po kolei: najpierw patrzy na first, a dopiero przy remisie zagląda do second. Dokładnie tak, jak układa się nazwiska w dzienniku.

porownania.cpp
pair<int, int> a = {1, 5};
pair<int, int> b = {1, 9};
pair<int, int> c = {2, 0};

// remis na first -> decyduje second
cout << (a < b) << "\n";    // 1 (5 < 9)

// first rozstrzyga od razu
cout << (a < c) << "\n";    // 1 (1 < 2)

// rowne pary
pair<int, int> d = {1, 5};
cout << (a == d) << "\n";   // 1
▶ Wyjście programu
1 1 1
sortowanie.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<pair<int, int>> v =
        {{3, 100}, {1, 50}, {3, 20}, {2, 70}};

    sort(v.begin(), v.end());

    for (int i = 0; i < v.size(); i++) {
        cout << v[i].first << "-"
             << v[i].second << " ";
    }
    return 0;
}
▶ Wyjście programu
1-50 2-70 3-20 3-100

Zwróć uwagę na wynik po prawej: pary z first równym 3 ustawiły się obok siebie, a między sobą uporządkowały się po second — najpierw 20, potem 100. I nie musiałeś napisać ani jednej linijki porównania.

Z tego bierze się najczęstsza sztuczka z parami: jeśli chcesz posortować ludzi po punktach, ale w wyniku pokazać nazwiska — włóż punkty na pierwsze miejsce, a nazwisko na drugie. Kolejność pól w parze decyduje o kolejności sortowania.

ranking.cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    vector<pair<int, string>> ranking = {
        {87, "Nowak"},
        {95, "Kowalski"},
        {91, "Wisniewski"}
    };

    // rosnaco - od najmniejszej liczby punktow
    sort(ranking.begin(), ranking.end());

    // ...wiec wypisujemy OD KONCA, zeby bylo malejaco
    for (int i = ranking.size() - 1; i >= 0; i--) {
        cout << ranking[i].second << " - "
             << ranking[i].first << " pkt\n";
    }

    return 0;
}
▶ Wyjście programu
Kowalski - 95 pkt Wisniewski - 91 pkt Nowak - 87 pkt
03 — Pary w praktyce

Lista par i rozpakowywanie

Pojedyncza para przydaje się rzadko. Prawdziwa siła pojawia się, gdy wsadzisz je do wektora: dostajesz listę rzeczy, z których każda ma dwie właściwości — i możesz ją posortować jedną linijką.

punkty.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<pair<int, int>> punkty;

    for (int i = 0; i < n; i++) {
        int x, y;
        cin >> x >> y;
        punkty.push_back({x, y});   // dokladamy pare
    }

    sort(punkty.begin(), punkty.end());

    for (int i = 0; i < n; i++) {
        cout << "(" << punkty[i].first << ", "
             << punkty[i].second << ")\n";
    }

    return 0;
}
▶ Wyjście programu
Wejście: 3 5 2 1 9 5 0 (1, 9) (5, 0) (5, 2)

Ciągłe pisanie p.first i p.second robi się męczące. Nowsze C++ pozwala rozpakować parę do dwóch zwykłych zmiennych o normalnych nazwach — i kod od razu staje się czytelny.

bez_rozpakowania.cpp
vector<pair<int, string>> lista =
    {{95, "Kowalski"}, {87, "Nowak"}};

for (int i = 0; i < lista.size(); i++) {
    cout << lista[i].second << " ma "
         << lista[i].first << " pkt\n";
}
▶ Wyjście programu
Kowalski ma 95 pkt Nowak ma 87 pkt
z_rozpakowaniem.cpp
vector<pair<int, string>> lista =
    {{95, "Kowalski"}, {87, "Nowak"}};

// nazwy zamiast first/second
for (auto [punkty, nazwisko] : lista) {
    cout << nazwisko << " ma "
         << punkty << " pkt\n";
}
▶ Wyjście programu
Kowalski ma 95 pkt Nowak ma 87 pkt

Obie wersje robią to samo, ale prawa czyta się jak zdanie. Zapis for (auto [a, b] : lista) znaczy: „dla każdej pary z listy nazwij jej pierwszą wartość a, a drugą b”. Wymaga C++17, który jest standardem od lat — jeśli u Ciebie nie działa, sprawdź ustawienia kompilatora.

04 — Ściąga

Wszystko, co robi się z parą

Para jest tak prosta, że cała jej obsługa mieści się w ośmiu wierszach. Cała trudność polega na tym, żeby wiedzieć, co wstawić na pierwsze miejsce.

ZapisCo robiUwaga
pair<A, B> p; Tworzy parę o typach A i B. Typy mogą być różne
p = {a, b}; Wpisuje obie wartości naraz. Najkrótszy zapis
make_pair(a, b) To samo, starszym zapisem. Spotkasz w starszym kodzie
p.first / p.second Pierwsza i druga wartość. Bez nawiasów — to pola, nie funkcje
p1 == p2 Prawdę, gdy oba pola są równe. —
p1 < p2 Porównanie: najpierw first, przy remisie second. Stąd darmowe sortowanie
vector<pair<A,B>> v; Lista par. Najczęstsze zastosowanie
v.push_back({a, b}); Dokłada parę na koniec listy. —
sort(v.begin(), v.end()); Sortuje listę par — bez pisania porównania. Rosnąco po first
for (auto [a, b] : v) Rozpakowuje parę do dwóch nazwanych zmiennych. Wymaga C++17

Ostatnie trzy wiersze to w praktyce cały przepis na zadania z rankingami: wrzuć dane do wektora par, posortuj jedną linijką, przejdź pętlą z rozpakowaniem. Nic więcej nie trzeba.

05 — Przykładowe zadania

Sprawdź się na zadaniach

Sześć zadań od najprostszego. Kluczem w każdym jest pytanie: co wstawić na pierwsze miejsce pary, żeby sortowanie zrobiło robotę za Ciebie.

Łatwe Pierwsza para
Wczytaj imię i wiek jednej osoby, zapisz je do pary i wypisz w formacie Ala ma 12 lat.
Jak to ugryźć: Zadanie na rozgrzewkę — chodzi tylko o składnię. Utwórz pair<string, int> i przypisz przez .first oraz .second.
Pokaż rozwiązanie
pierwsza_para.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    pair<string, int> osoba;

    cin >> osoba.first >> osoba.second;

    cout << osoba.first << " ma "
         << osoba.second << " lat";

    return 0;
}
Łatwe Ranking zawodników
Wczytaj n par: nazwisko i liczba punktów. Wypisz zawodników od najlepszego do najgorszego.
Jak to ugryźć: Punkty wstaw na pierwsze miejsce pary, żeby sortowanie ustawiło ludzi według nich. Potem posortuj rosnąco i wypisz od końca.
Pokaż rozwiązanie
ranking.cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<pair<int, string>> v;

    for (int i = 0; i < n; i++) {
        string nazwisko;
        int punkty;
        cin >> nazwisko >> punkty;

        v.push_back({punkty, nazwisko});   // punkty PIERWSZE
    }

    sort(v.begin(), v.end());

    for (int i = n - 1; i >= 0; i--) {
        cout << v[i].second << " " << v[i].first << "\n";
    }

    return 0;
}
Łatwe Największa suma pary
Wczytaj n par liczb. Wypisz tę parę, w której suma obu liczb jest największa.
Jak to ugryźć: Nie sortuj — wystarczy wzorzec szukania maksimum, który znasz z tablic. Trzymaj zapamiętaną najlepszą parę i porównuj sumy.
Pokaż rozwiązanie
najwieksza_suma.cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    pair<int, int> najlepsza;
    int najlepszaSuma = -1000000000;

    for (int i = 0; i < n; i++) {
        int a, b;
        cin >> a >> b;

        if (a + b > najlepszaSuma) {
            najlepszaSuma = a + b;
            najlepsza = {a, b};
        }
    }

    cout << najlepsza.first << " " << najlepsza.second
         << " (suma " << najlepszaSuma << ")";

    return 0;
}
Średnie Sortowanie po dwóch kryteriach
Wczytaj n uczniów: nazwisko i ocena. Posortuj ich rosnąco po ocenie, a przy równych ocenach — alfabetycznie po nazwisku.
Jak to ugryźć: To działa samo, jeśli ułożysz parę jako {ocena, nazwisko}. Porównanie par najpierw sprawdza ocenę, a przy remisie automatycznie porównuje nazwiska alfabetycznie.
Pokaż rozwiązanie
dwa_kryteria.cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<pair<int, string>> v;

    for (int i = 0; i < n; i++) {
        string nazwisko;
        int ocena;
        cin >> nazwisko >> ocena;
        v.push_back({ocena, nazwisko});
    }

    // jedna linijka zalatwia oba kryteria
    sort(v.begin(), v.end());

    for (auto [ocena, nazwisko] : v) {
        cout << ocena << " " << nazwisko << "\n";
    }

    return 0;
}
Średnie Najbliższa para na osi
Wczytaj n liczb — pozycji punktów na prostej. Znajdź dwie najbliższe siebie i wypisz je wraz z odległością.
Jak to ugryźć: Po posortowaniu najbliższe punkty muszą leżeć obok siebie — nie trzeba porównywać każdego z każdym. Wystarczy jedna pętla po sąsiednich parach.
Pokaż rozwiązanie
najblizsza_para.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> v(n);
    for (int i = 0; i < n; i++) cin >> v[i];

    sort(v.begin(), v.end());

    pair<int, int> najblizsze;
    int najmniejsza = 2000000000;

    for (int i = 0; i + 1 < n; i++) {
        int roznica = v[i + 1] - v[i];

        if (roznica < najmniejsza) {
            najmniejsza = roznica;
            najblizsze = {v[i], v[i + 1]};
        }
    }

    cout << najblizsze.first << " " << najblizsze.second
         << " (odleglosc " << najmniejsza << ")";

    return 0;
}
Trudne Kto wygrał i o ile
Wczytaj n zawodników: nazwisko, punkty i czas. Wygrywa ten, kto ma najwięcej punktów; przy remisie — ten z krótszym czasem. Wypisz zwycięzcę i różnicę punktów do drugiego miejsca.
Jak to ugryźć: Dwa kryteria działające w przeciwnych kierunkach. Sztuczka: wstaw {punkty, -czas} — minus odwraca kolejność czasu, więc krótszy czas wypada wyżej przy zwykłym sortowaniu rosnącym. Zwycięzcą jest ostatni element posortowanej listy.
Pokaż rozwiązanie
zwyciezca.cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;

    // {punkty, -czas, nazwisko}
    vector<pair<pair<int,int>, string>> v;

    for (int i = 0; i < n; i++) {
        string nazwisko;
        int punkty, czas;
        cin >> nazwisko >> punkty >> czas;

        v.push_back({{punkty, -czas}, nazwisko});
    }

    sort(v.begin(), v.end());

    // zwyciezca to ostatni po sortowaniu rosnacym
    auto zwyciezca = v[n - 1];
    auto drugi = v[n - 2];

    cout << "Wygral: " << zwyciezca.second << "\n";
    cout << "Przewaga: "
         << zwyciezca.first.first - drugi.first.first
         << " pkt\n";

    return 0;
}
06 — Porady

Częste błędy i dobre praktyki

⚖️
Kolejność decyduje o sortowaniu
Pary porównują się najpierw po first, potem po second. To, które pole wstawisz jako pierwsze, ustala kryterium sortowania.
🚫
first bez nawiasów
p.first, nie p.first(). To zwykłe pole, a nie funkcja — dodatkowe nawiasy to błąd kompilacji.
🔄
Sortowanie malejąco
Najprościej posortuj rosnąco i wypisz od końca. Alternatywa: sort(v.rbegin(), v.rend()).
📦
Nagłówek <utility>
Formalnie pair mieszka w <utility>, ale dołączają go też <vector> i <map>, więc zwykle działa bez niego.
📛
Gdy nazwy przestają być oczywiste
Jeśli po dwóch dniach nie pamiętasz, co siedzi w second, to znak, że zamiast pary potrzebujesz struktury z nazwanymi polami.
🧱
Więcej niż dwie wartości
Da się zagnieżdżać: pair<int, pair<int,int>>. Da się, ale nie warto — przy trzech polach sięgnij po struct.
