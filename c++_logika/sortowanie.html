01 — Podstawy

Jedna linijka
zamiast algorytmu

Sortowanie to ułożenie danych po kolei — od najmniejszej do największej. Brzmi jak coś, co trzeba samemu napisać, i rzeczywiście da się to zrobić na kilkanaście sposobów. Ale w C++ nie musisz: gotowa funkcja sort robi to za Ciebie.

Potrzebujesz tylko nagłówka <algorithm> i jednej linijki. Działa na wektorze, na zwykłej tablicy i na tekście — wszędzie tak samo.

Domyślnie układa rosnąco. Żeby dostać kolejność malejącą, wystarczy drobna zmiana — pokazujemy obie obok.

💡 To naprawdę wszystko. Nie musisz wiedzieć, jak sortowanie działa w środku, żeby z niego korzystać — tak samo jak nie musisz znać budowy silnika, żeby prowadzić samochód. Zaglądamy tam dopiero w sekcji 03, z czystej ciekawości.
Wektor
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {5, 2, 8, 1, 9, 3};

    // rosnaco - domyslnie
    sort(v.begin(), v.end());

    for (int x : v) cout << x << " ";
    // 1 2 3 5 8 9

    return 0;
}
Malejaco, tablica, tekst
// malejaco - odwrotny zapis
vector<int> v = {5, 2, 8, 1};
sort(v.rbegin(), v.rend());     // 8 5 2 1

// zwykla tablica - podajesz t i t+n
int t[5] = {7, 3, 1, 9, 4};
sort(t, t + 5);                 // 1 3 4 7 9

// tekst - litery po alfabecie
string s = "komputer";
sort(s.begin(), s.end());       // "ekmoprtu"
02 — begin i end

Co znaczy
v.begin(), v.end()

Zapis sort(v.begin(), v.end()) wygląda dziwnie, dopóki nie wiadomo, co znaczą te dwa argumenty. Odpowiedź jest prosta: mówią one, od którego do którego miejsca sortować.

begin() to pierwszy element. end() to miejsce tuż za ostatnim — pusta pozycja, która mówi „tutaj koniec”. Dokładnie tak samo jak w pętli for (int i = 0; i < n; i++), gdzie n to pierwszy indeks poza tablicą.

Dzięki temu możesz posortować nie tylko całość, ale i dowolny fragment. Wystarczy podać inne dwa miejsca — na przykład v.begin() + 2 zamiast początku.

💡 Skąd ta dziwna nazwa „end”? Gdyby end() wskazywało na ostatni element, to dla pustego wektora nie miałoby na co wskazywać. Pozycja „tuż za końcem” zawsze istnieje — nawet gdy w środku nie ma nic.

end()

Sortowaniu podlega wszystko od begin() do end(), ale bez samego end() — bo tam już nic nie ma.

Zakres w praktyce
vector<int> v = {5, 2, 8, 1, 9};

// calosc
sort(v.begin(), v.end());        // 1 2 5 8 9

// tylko trzy pierwsze elementy
sort(v.begin(), v.begin() + 3);

// od trzeciego do konca
sort(v.begin() + 2, v.end());

// malejaco - r jak "reverse", od tylu
sort(v.rbegin(), v.rend());      // 9 8 5 2 1

// ile elementow miesci sie w zakresie
cout << v.size();                // 5

Jak działa

Wielokrotnie przechodzi przez tablicę porównując sąsiednie pary. Jeśli są w złej kolejności — zamienia je. Każda pełna iteracja "bąbelkuje" największy nieposortowany element na koniec. Flaga swapped umożliwia wcześniejsze zakończenie gdy tablica jest już posortowana.

Bubble Sort — C++
void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n-1; i++) {
        bool swapped = false;
        for (int j = 0; j < n-i-1; j++) {
            if (arr[j] > arr[j+1]) {
                swap(arr[j], arr[j+1]);
                swapped = true;
            }
        }
        if (!swapped) break; // early exit
    }
}
✓ MocneProsty. Stabilny. O(n) dla posortowanych. O(1) pamięci.
✗ SłabeWolny — O(n²). Dużo operacji swap. Brak wartości praktycznej.
Zastosowania

Jak działa

Dzieli tablicę na część posortowaną (lewa) i nieposortowaną (prawa). W każdej iteracji znajduje minimum w części nieposortowanej i zamienia je z jej pierwszym elementem. Zawsze dokładnie n−1 operacji swap niezależnie od danych wejściowych.

Selection Sort — C++
void selectionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n-1; i++) {
        int minIdx = i;
        for (int j = i+1; j < n; j++)
            if (arr[j] < arr[minIdx]) minIdx = j;
        if (minIdx != i)
            swap(arr[i], arr[minIdx]);
    }
}
✓ MocneMinimalna liczba swapów — O(n). Przydatny gdy swap jest kosztowny. O(1) pamięci.
✗ SłabeZawsze O(n²) — brak early exit. Niestabilny. Wolny dla dużych danych.
Zastosowania

Jak działa

Buduje posortowaną część element po elemencie — jak układanie kart w ręce. Bierze kolejny element z części nieposortowanej i "wstawia" go we właściwe miejsce, przesuwając większe elementy o jedno miejsce w prawo.

Insertion Sort — C++
void insertionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i], j = i-1;
        while (j >= 0 && arr[j] > key) {
            arr[j+1] = arr[j]; j--;
        }
        arr[j+1] = key;
    }
}
✓ MocneO(n) dla prawie posortowanych. Stabilny. O(1) pamięci. Używany wewnętrznie w std::sort!
✗ SłabeO(n²) dla odwrotnie posortowanych. Nieefektywny dla dużych n.
Zastosowania

Jak działa

Klasyczne "dziel i zwyciężaj". Rekurencyjnie dzieli tablicę na pół aż do jednoelementowych podtablic, a następnie scala je w posortowane pary, czwórki, ósemki. Krok merge łączy dwie posortowane tablice w O(n). Gwarantuje O(n log n) zawsze — bez pesymistycznych przypadków.

Merge Sort — C++
void merge(vector<int>& a, int l, int m, int r) {
    vector<int> L(a.begin()+l, a.begin()+m+1);
    vector<int> R(a.begin()+m+1, a.begin()+r+1);
    int i=0, j=0, k=l;
    while (i<L.size() && j<R.size())
        a[k++] = (L[i]<=R[j]) ? L[i++] : R[j++];
    while (i<L.size()) a[k++]=L[i++];
    while (j<R.size()) a[k++]=R[j++];
}
void mergeSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    int m = l+(r-l)/2;
    mergeSort(a, l, m);
    mergeSort(a, m+1, r);
    merge(a, l, m, r);
}
✓ MocneGwarantowane O(n log n). Stabilny. External sort. Łatwy do zrównoleglenia.
✗ SłabeO(n) dodatkowej pamięci. Wolniejszy od QuickSort w praktyce. Narzut rekurencji.

Jak działa

Wybiera element "pivot" i partycjonuje tablicę — mniejsze od pivota po lewej, większe po prawej. Rekurencyjnie sortuje obie partycje. Kluczowy jest dobry wybór pivota: losowy lub mediana-z-3 minimalizuje ryzyko O(n²).

Quick Sort — Lomuto
int partition(vector<int>& a, int lo, int hi) {
    int pivot = a[hi], i = lo-1;
    for (int j = lo; j < hi; j++)
        if (a[j] <= pivot) swap(a[++i], a[j]);
    swap(a[i+1], a[hi]);
    return i+1;
}
void quickSort(vector<int>& a, int lo, int hi) {
    if (lo < hi) {
        int pi = partition(a, lo, hi);
        quickSort(a, lo, pi-1);
        quickSort(a, pi+1, hi);
    }
}
✓ MocneNajszybszy w praktyce. Cache-friendly. O(log n) pamięci. Dobry in-place.
✗ SłabePesymistycznie O(n²). Niestabilny. Wrażliwy na posortowane dane.
Zastosowania

Jak działa

Buduje max-heap (rodzic ≥ dzieci) z tablicy. Następnie wielokrotnie usuwa korzeń (maksimum) i umieszcza go na końcu tablicy, przywracając własność kopca (heapify). Gwarantuje O(n log n) bez pesymistycznych przypadków jak QuickSort.

Heap Sort — C++
void heapify(vector<int>& a, int n, int i) {
    int lg=i, l=2*i+1, r=2*i+2;
    if(l<n && a[l]>a[lg]) lg=l;
    if(r<n && a[r]>a[lg]) lg=r;
    if(lg!=i){ swap(a[i],a[lg]); heapify(a,n,lg); }
}
void heapSort(vector<int>& a) {
    int n = a.size();
    for(int i=n/2-1; i>=0; i--) heapify(a,n,i);
    for(int i=n-1; i>0; i--){
        swap(a[0],a[i]); heapify(a,i,0);
    }
}
✓ MocneGwarantowane O(n log n). O(1) pamięci. Fallback w IntroSort.
✗ SłabeNiestabilny. Cache-unfriendly. Wolniejszy od QuickSort w praktyce.
Zastosowania

Jak działa — Counting Sort

Zlicza wystąpienia każdej wartości (zakres [0, k]), buduje tablicę skumulowanych zliczeń, a następnie układa elementy bez porównań. Przełamuje barierę O(n log n) dla liczb całkowitych.

Jak działa — Radix Sort

Sortuje cyfra po cyfrze od najmniej znaczącej (LSD) do najbardziej (MSD), używając Counting Sort jako stabilnej procedury pomocniczej. d = liczba cyfr, k = podstawa systemu.

Counting + Radix Sort
// Counting Sort (wartości 0..k)
void countingSort(vector<int>& arr, int k) {
    vector<int> cnt(k+1,0), out(arr.size());
    for(int x : arr) cnt[x]++;
    for(int i=1; i<=k; i++) cnt[i]+=cnt[i-1];
    for(int i=arr.size()-1; i>=0; i--)
        out[--cnt[arr[i]]]=arr[i];
    arr = out;
}
// Radix Sort (LSD, baza 10)
void radixSort(vector<int>& arr) {
    int mx = *max_element(arr.begin(), arr.end());
    for(int exp=1; mx/exp>0; exp*=10)
        countByDigit(arr, exp); // counting per cyfra
}
✓ MocnePrzełamuje O(n log n). Liniowy dla małego k. Stabilny. Świetny dla milionów int.
✗ SłabeTylko int/string. O(n+k) pamięci. Nieefektywny gdy k >> n.
Zastosowania

04 — Własne kryterium

Sortowanie po swojemu

Domyślnie sort układa rosnąco. Ale czasem chcesz inaczej: malejąco, po długości słowa, po drugiej cyfrze. Wtedy podajesz funkcji własną regułę porównania jako trzeci argument.

Reguła to zwykła odpowiedź na pytanie: „czy a ma stać przed b?”. Zapisuje się ją najkrócej jako [](int a, int b){ return a > b; } — ten dziwny zapis z nawiasami kwadratowymi to tzw. lambda, czyli funkcja bez nazwy, napisana w miejscu, w którym jest potrzebna.

ZapisCo robiKiedy tego użyjesz
sort(v.begin(), v.end()) Układa rosnąco, od najmniejszego. Domyślny wybór
sort(v.rbegin(), v.rend()) Układa malejąco. Litera r znaczy „od tyłu”. Najkrótszy zapis dla malejąco
sort(v.begin(), v.end(), greater<int>()) To samo, gotowym narzędziem z <functional>. Gdy wolisz nazwę od skrótu
sort(..., [](int a, int b){ return a > b; }) Własna reguła porównania. Gdy chcesz sortować po czymś nietypowym
sortowanie par Samo: najpierw po first, przy remisie po second. Ranking z dwoma kryteriami
sort(t, t + n) To samo na zwykłej tablicy. Gdy nie używasz wektora
sort(s.begin(), s.end()) Układa litery tekstu po alfabecie. Anagramy, porządkowanie liter
stable_sort(...) Nie zamienia miejscami elementów równych. Gdy kolejność remisów ma znaczenie

Reguła musi zwracać true, gdy pierwszy element ma stać przed drugim. I jedna żelazna zasada: dla elementów równych musi zwracać false. Napisanie <= zamiast < łamie tę zasadę i potrafi wysypać program — mimo że kod wygląda całkowicie poprawnie.

Jeśli sortujesz pary albo struktury, w większości przypadków nie musisz pisać reguły w ogóle. Pary porównują się same: najpierw po pierwszym polu, przy remisie po drugim. Wystarczy ułożyć pola w odpowiedniej kolejności — o czym była mowa w temacie Pair.

💡 Zacznij od dwóch pierwszych wierszy tabeli. Rosnąco i malejąco załatwiają zdecydowaną większość zadań. Po lambdę sięgaj dopiero wtedy, gdy naprawdę potrzebujesz nietypowej kolejności.
05 — Po sortowaniu

Co dalej

Sortowanie rzadko bywa celem samym w sobie — zwykle jest przygotowaniem. Gdy dane leżą po kolei, nagle robi się prosto: najmniejszy jest na początku, największy na końcu, jednakowe wartości stoją obok siebie, a szukanie konkretnej liczby przestaje wymagać przeglądania wszystkiego.

FunkcjaCo robiUwaga
binary_search(b, e, x) Odpowiada true / false: czy x jest w danych. Dane muszą być posortowane
lower_bound(b, e, x) Znajduje pierwsze miejsce, gdzie stoi x (albo gdzie by stał). Zwraca miejsce, nie wartość
upper_bound(b, e, x) Znajduje pierwsze miejsce za wszystkimi x. —
upper − lower Ile razy x występuje w danych. Różnica dwóch powyższych
unique(b, e) Zbija powtórzenia stojące obok siebie. Najpierw posortuj!
v.erase(unique(...), v.end()) Naprawdę usuwa duplikaty z wektora. Samo unique nie skraca wektora
min_element / max_element Najmniejszy i największy element. Sortowanie nie jest do tego potrzebne
is_sorted(b, e) Sprawdza, czy dane są już ułożone. Przydaje się przy testowaniu

Dwie pierwsze funkcje robią prawie to samo, ale zwracają co innego. binary_search odpowiada tylko „jest albo nie ma”. lower_bound mówi, gdzie ta wartość siedzi — a jeśli jej nie ma, to gdzie by stała. Obie wymagają posortowanych danych; na nieposortowanych dadzą bzdurną odpowiedź bez żadnego ostrzeżenia.

Uwaga na unique: ta funkcja zbija tylko powtórzenia, które stoją obok siebie. Bez wcześniejszego posortowania nie zadziała tak, jak oczekujesz. Sama też nie skraca wektora — dlatego zawsze łączy się ją z erase w jednej linijce.

06 — Zadania

Sprawdź się na zadaniach

Sześć zadań od najprostszego. Pierwsze trzy sprawdzają, czy umiesz użyć sort; dalsze łączą sortowanie z własną regułą i z tym, co można zrobić z już ułożonymi danymi. Rozwiązania są schowane — najpierw spróbuj sam.

Łatwe Posortuj i wypisz
Wczytaj n liczb, posortuj je rosnąco i wypisz. Potem wypisz je jeszcze raz — malejąco.
Jak to ugryźć: Dwie linijki: sort(v.begin(), v.end()) i sort(v.rbegin(), v.rend()). Nic więcej nie trzeba.
Pokaż rozwiązanie
posortuj.cpp
<code>#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> v(n);
    for (int i = 0; i < n; i++) cin >> v[i];

    sort(v.begin(), v.end());
    for (int x : v) cout << x << " ";
    cout << "\n";

    sort(v.rbegin(), v.rend());
    for (int x : v) cout << x << " ";

    return 0;
}</code>
Łatwe Trzeci największy
Wczytaj n liczb i wypisz trzecią co do wielkości. Załóż, że n jest co najmniej 3.
Jak to ugryźć: Po posortowaniu rosnąco największy jest ostatni — czyli v[n-1]. Trzeci największy to po prostu v[n-3]. Żadnych pętli szukających.

Jak to ugryźć: Tekst zachowuje się jak wektor znaków, więc sort(s.begin(), s.end()) działa dokładnie tak samo jak na liczbach.

Średnie Ranking po dwóch kryteriach
Wczytaj n zawodników (imię i punkty). Wypisz ich malejąco po punktach, a przy remisie alfabetycznie po imieniu.
Jak to ugryźć: Dwa kryteria idące w przeciwne strony, więc samo porównanie par nie wystarczy. Napisz własną regułę: najpierw porównaj punkty malejąco, a gdy są równe — imiona rosnąco.
Pokaż rozwiązanie
ranking.cpp
<code>#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

struct Zawodnik {
    string imie;
    int punkty;
};

int main() {
    int n;
    cin >> n;

    vector<Zawodnik> v(n);
    for (int i = 0; i < n; i++) {
        cin >> v[i].imie >> v[i].punkty;
    }

    sort(v.begin(), v.end(), [](Zawodnik a, Zawodnik b) {
        if (a.punkty != b.punkty) {
            return a.punkty > b.punkty;    // wiecej punktow wyzej
        }
        return a.imie < b.imie;            // remis - alfabetycznie
    });

    for (auto z : v) {
        cout << z.imie << " " << z.punkty << "\n";
    }

    return 0;
}</code>
Średnie Usuń duplikaty
Wczytaj n liczb i wypisz je posortowane rosnąco, bez powtórzeń. Na końcu podaj, ile zostało różnych wartości.
Jak to ugryźć: Najpierw sort, żeby jednakowe liczby stanęły obok siebie. Potem v.erase(unique(v.begin(), v.end()), v.end()) — unique zbija sąsiednie powtórzenia, a erase naprawdę je usuwa.
Pokaż rozwiązanie
duplikaty.cpp
<code>#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> v(n);
    for (int i = 0; i < n; i++) cin >> v[i];

    sort(v.begin(), v.end());
    v.erase(unique(v.begin(), v.end()), v.end());

    for (int x : v) cout << x << " ";
    cout << "\nRoznych: " << v.size();

    return 0;
}</code>
Trudne Ile razy występuje wartość
Wczytaj n liczb, a potem q zapytań. Dla każdego zapytania podaj, ile razy dana wartość występuje wśród wczytanych liczb.
Jak to ugryźć: Posortuj dane raz, na starcie. Wtedy jednakowe wartości stoją obok siebie, a ich liczbę daje różnica upper_bound - lower_bound. Przechodzenie całej tablicy przy każdym zapytaniu byłoby znacznie wolniejsze.
Pokaż rozwiązanie
wystapienia.cpp
<code>#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> v(n);
    for (int i = 0; i < n; i++) cin >> v[i];

    sort(v.begin(), v.end());       // raz, na starcie

    int q;
    cin >> q;

    while (q--) {
        int x;
        cin >> x;

        int ile = upper_bound(v.begin(), v.end(), x)
                - lower_bound(v.begin(), v.end(), x);

        cout << ile << "\n";
    }

    return 0;
}</code>
