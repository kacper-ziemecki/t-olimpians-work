01 — Podstawy

Tworzenie i wczytywanie tekstu

string poznałeś już przy typach zmiennych. Teraz przyjrzymy mu się bliżej, bo potrafi znacznie więcej niż tylko przechowywać imię. Na górze pliku potrzebujesz #include <string> — bez tego kompilator nie będzie wiedział, o czym mówisz.

Najważniejsza różnica względem zwykłej zmiennej: string sam dba o swój rozmiar. Nie musisz z góry zgadywać, ile znaków się zmieści — dokładasz tekst, a on rośnie.

📝

string s = "tekst";

Tworzenie z gotową zawartością. Tekst zawsze w cudzysłowie.

➕

s = s + " kolejny";

Sklejanie plusem. Krócej: s += " kolejny";

📏

s.length()

Ile znaków ma tekst. Spacje też się liczą.

🔤

s[0]

Pojedynczy znak na danej pozycji — jak w tablicy, numerowanie od zera.

📥

cin >> s

Wczytuje jedno słowo, do pierwszej spacji.

📃

getline(cin, s)

Wczytuje całą linię, razem ze spacjami.

podstawy.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string imie = "Ala";
    string nazwisko = "Kowalska";

    // sklejanie plusem
    string pelne = imie + " " + nazwisko;

    cout << pelne << "\n";
    cout << "Znakow: " << pelne.length() << "\n";
    cout << "Pierwsza litera: " << pelne[0] << "\n";

    // doklejanie na koncu
    pelne += "!";
    cout << pelne << "\n";

    return 0;
}
▶ Wyjście programu
Ala Kowalska Znakow: 12 Pierwsza litera: A Ala Kowalska!

Uwaga na jedną rzecz przy sklejaniu: plus działa tylko wtedy, gdy po którejś stronie jest string. Zapis "ala" + "kot" na dwóch gołych cudzysłowach się nie skompiluje, ale s + "kot" już tak. W praktyce prawie zawsze sklejasz ze zmienną, więc problem pojawia się rzadko.

Liczby nie sklejają się ze stringiem plusem. s + 5 to błąd — najpierw zamień liczbę na tekst: s + to_string(5). W drugą stronę działa stoi(s), które zamienia napis na int.

02 — Najważniejsze metody

Cztery rzeczy, które robisz najczęściej

Metoda to funkcja doczepiona do zmiennej — piszesz ją po kropce: s.length(). Poniżej cztery, które pokrywają większość tego, co robi się z tekstem.

dlugosc_i_fragment.cpp
string s = "programowanie";

// ile znakow
cout << s.length() << "\n";       // 13

// fragment: od pozycji 0, dlugosc 7
cout << s.substr(0, 7) << "\n";   // program

// od pozycji 7 do konca
cout << s.substr(7) << "\n";      // owanie
▶ Wyjście programu
13 program owanie
szukanie.cpp
string s = "programowanie";

// gdzie jest "gram"?
cout << s.find("gram") << "\n";      // 3

// czego nie ma, to npos (ogromna liczba)
if (s.find("kot") == string::npos) {
    cout << "nie ma slowa kot\n";
}

// czy zaczyna sie od "pro"?
if (s.substr(0, 3) == "pro") {
    cout << "zaczyna sie od pro";
}
▶ Wyjście programu
3 nie ma slowa kot zaczyna sie od pro

Najważniejsza pułapka tej strony: find nie zwraca -1, gdy czegoś nie znajdzie, tylko specjalną wartość string::npos — ogromną liczbę dodatnią. Dlatego if (s.find(x) > 0) prawie zawsze jest prawdą i nic nie sprawdza. Porównuj zawsze z string::npos.

Do dokładania znaków służy += albo push_back(c). Oba robią to samo; += przyjmuje też całe słowa, a push_back tylko pojedynczy znak w apostrofach.

03 — Pętla po znakach

String jako ciąg liter

Tekst zachowuje się jak tablica znaków: s[0] to pierwsza litera, s[s.length() - 1] ostatnia. Dzięki temu możesz przejść go pętlą dokładnie tak jak tablicę i policzyć, sprawdzić albo zamienić, co chcesz.

zliczanie.cpp
string s = "Ala ma kota";

int samogloski = 0;
int spacje = 0;

for (int i = 0; i < s.length(); i++) {
    char c = s[i];

    if (c == 'a' || c == 'e' || c == 'i' ||
        c == 'o' || c == 'u' || c == 'y') {
        samogloski++;
    }
    if (c == ' ') spacje++;
}

cout << "Samoglosek: " << samogloski << "\n";
cout << "Spacji: " << spacje;
▶ Wyjście programu
Samoglosek: 4 Spacji: 2
palindrom.cpp
string s = "kajak";

bool palindrom = true;
int n = s.length();

for (int i = 0; i < n / 2; i++) {
    if (s[i] != s[n - 1 - i]) {
        palindrom = false;
        break;
    }
}

if (palindrom) cout << "palindrom";
else           cout << "nie palindrom";
▶ Wyjście programu
palindrom

Teraz rzecz, która zaskakuje wszystkich na początku: znaki to tak naprawdę liczby. Litera 'a' ma numer 97, 'A' numer 65, a cyfra '0' numer 48. Z tego wynikają dwa trik, których będziesz używać bardzo często.

znaki_to_liczby.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    char c = 'd';

    // numer litery w alfabecie (a = 0)
    cout << c - 'a' << "\n";        // 3

    // zamiana malej litery na duza
    cout << (char)(c - 'a' + 'A') << "\n";   // D

    // znak-cyfra na prawdziwa liczbe
    char cyfra = '7';
    cout << cyfra - '0' << "\n";    // 7 jako liczba

    // suma cyfr z napisu
    string s = "4821";
    int suma = 0;
    for (int i = 0; i < s.length(); i++) {
        suma += s[i] - '0';
    }
    cout << "Suma cyfr: " << suma;

    return 0;
}
▶ Wyjście programu
3 D 7 Suma cyfr: 15

Zapis c - '0' czyta się prosto: „o ile ten znak jest dalej niż zero”. Dla '7' to siedem pozycji, więc dostajesz liczbę 7. Ta jedna sztuczka zamienia napis z cyframi na liczby bez żadnych dodatkowych funkcji.

04 — Ściąga

Wszystko, co robi się ze stringiem

Jedna tabelka zamiast szukania po internecie. Pierwsza kolumna to zapis, ostatnia — konkretny wynik dla s = "programowanie".

ZapisCo robiPrzykład
s.length() Liczbę znaków. To samo robi s.size(). 13
s.empty() Prawdę, gdy tekst jest pusty. false
s[i] Znak na pozycji i, licząc od zera. s[0] to 'p'
s.substr(od, ile) Fragment o zadanej długości. Bez drugiego argumentu — do końca. s.substr(0,7) to "program"
s.find(co) Pozycję pierwszego wystąpienia albo string::npos. s.find("gram") to 3
s += "tekst" Dokleja na końcu. To samo co s = s + "tekst". —
s.push_back(c) Dokleja jeden znak. s.push_back('!')
s.pop_back() Usuwa ostatni znak. —
s.clear() Czyści tekst do pustego. —
s1 == s2 Porównuje zawartość — działa tak, jak się spodziewasz. —
s1 < s2 Porządek alfabetyczny (duże litery przed małymi). "Ala" < "ala"
stoi(s) / to_string(x) Zamiana napisu na liczbę i odwrotnie. stoi("42") to 42

Zwróć uwagę na przedostatni wiersz: porównanie < układa napisy alfabetycznie, ale wszystkie duże litery idą przed małymi, bo mają mniejsze numery. Dlatego "Zebra" wypadnie przed "ala".

05 — Przykładowe zadania

Sprawdź się na zadaniach

Sześć zadań od najprostszego. Wszystkie da się rozwiązać samym string, pętlą i if. Najpierw spróbuj sam — rozwiązanie jest schowane pod przyciskiem.

Łatwe Długość i pierwsza litera
Wczytaj całą linię tekstu i wypisz: ile ma znaków, jaka jest pierwsza litera i jaka ostatnia.
Jak to ugryźć: Cała linia to getline(cin, s). Ostatni znak to s[s.length() - 1] — pamiętaj o odjęciu jedynki.
Pokaż rozwiązanie
dlugosc.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);

    cout << "Znakow:   " << s.length() << "\n";
    cout << "Pierwsza: " << s[0] << "\n";
    cout << "Ostatnia: " << s[s.length() - 1] << "\n";

    return 0;
}
Łatwe Zliczanie liter
Wczytaj linię tekstu i policz, ile w niej samogłosek, ile spółgłosek i ile spacji.
Jak to ugryźć: Pętla po znakach i if z długim warunkiem ||. Spółgłoska to litera, która nie jest samogłoską ani spacją — najprościej sprawdzić przez c >= 'a' && c <= 'z'.
Pokaż rozwiązanie
zliczanie.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);

    int samogloski = 0, spolgloski = 0, spacje = 0;

    for (int i = 0; i < s.length(); i++) {
        char c = s[i];

        if (c == ' ') {
            spacje++;
        } else if (c == 'a' || c == 'e' || c == 'i' ||
                   c == 'o' || c == 'u' || c == 'y') {
            samogloski++;
        } else if (c >= 'a' && c <= 'z') {
            spolgloski++;
        }
    }

    cout << "Samoglosek: " << samogloski << "\n";
    cout << "Spolglosek: " << spolgloski << "\n";
    cout << "Spacji:     " << spacje << "\n";

    return 0;
}
Łatwe Odwróć napis
Wczytaj słowo i wypisz je od tyłu. Dla kot odpowiedzią jest tok.
Jak to ugryźć: Najprościej: pętla od ostatniego indeksu w dół do zera, wypisująca po jednym znaku. Można też zbudować nowy napis, doklejając znaki przez +=.
Pokaż rozwiązanie
odwroc.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;

    string wynik = "";
    for (int i = s.length() - 1; i >= 0; i--) {
        wynik += s[i];
    }

    cout << wynik;
    return 0;
}
Średnie Palindrom
Wczytaj słowo i sprawdź, czy czyta się tak samo od przodu i od tyłu. Wypisz TAK albo NIE.
Jak to ugryźć: Porównuj parami: pierwszy z ostatnim, drugi z przedostatnim. Wystarczy przejść połowę napisu — dalej porównywałbyś te same pary jeszcze raz. Gdy trafisz na różnicę, od razu break.
Pokaż rozwiązanie
palindrom.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;

    int n = s.length();
    bool palindrom = true;

    for (int i = 0; i < n / 2; i++) {
        if (s[i] != s[n - 1 - i]) {
            palindrom = false;
            break;
        }
    }

    if (palindrom) cout << "TAK";
    else           cout << "NIE";

    return 0;
}
Średnie Zamiana wielkości liter
Wczytaj linię tekstu i zamień w niej małe litery na duże, a duże na małe. Pozostałe znaki zostaw bez zmian.
Jak to ugryźć: Mała litera ma numer z przedziału 'a'…'z', duża 'A'…'Z'. Różnica między nimi jest zawsze taka sama, więc c - 'a' + 'A' zamienia małą na dużą. Wynik rzutuj na char.
Pokaż rozwiązanie
zamiana_liter.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);

    for (int i = 0; i < s.length(); i++) {
        char c = s[i];

        if (c >= 'a' && c <= 'z') {
            s[i] = c - 'a' + 'A';
        } else if (c >= 'A' && c <= 'Z') {
            s[i] = c - 'A' + 'a';
        }
    }

    cout << s;
    return 0;
}
Trudne Czy to anagramy?
Wczytaj dwa słowa i sprawdź, czy jedno jest przestawieniem liter drugiego. Dla kota i atok odpowiedzią jest TAK.
Jak to ugryźć: Nie porównuj słów wprost. Policz, ile razy występuje każda litera — do tego wystarczy tablica 26 liczników, gdzie pozycję daje c - 'a'. Dla pierwszego słowa dodawaj, dla drugiego odejmuj. Jeśli na końcu wszystkie liczniki są zerami, to anagramy.
Pokaż rozwiązanie
anagramy.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a, b;
    cin >> a >> b;

    if (a.length() != b.length()) {
        cout << "NIE";
        return 0;
    }

    int licznik[26] = {};        // 26 zer

    for (int i = 0; i < a.length(); i++) {
        licznik[a[i] - 'a']++;   // z pierwszego dodajemy
        licznik[b[i] - 'a']--;   // z drugiego odejmujemy
    }

    bool anagram = true;
    for (int i = 0; i < 26; i++) {
        if (licznik[i] != 0) anagram = false;
    }

    if (anagram) cout << "TAK";
    else         cout << "NIE";

    return 0;
}
06 — Porady

Częste błędy i dobre praktyki

📥
cin >> a getline
cin >> s bierze jedno słowo, getline(cin, s) całą linię. Po wczytaniu liczby przez cin wstaw cin.ignore(), zanim sięgniesz po getline.
🔍
find zwraca npos
Gdy szukany fragment nie istnieje, find zwraca string::npos — ogromną liczbę, nie -1. Porównuj zawsze if (s.find(x) == string::npos).
📦
Dołącz <string>
Bez #include <string> część metod nie zadziała, mimo że czasem program i tak się skompiluje przez przypadek.
🔢
Znaki to liczby
c - 'a' daje numer litery w alfabecie, c - '0' zamienia znak-cyfrę na liczbę. Obie sztuczki przydają się w co drugim zadaniu z tekstem.
↔️
Liczba na tekst i z powrotem
to_string(42) robi z liczby napis, stoi("42") z napisu liczbę. Plus sam z siebie ich nie połączy.
🧭
Ostatni znak
To s[s.length() - 1], nie s[s.length()]. Ta druga pozycja już nie należy do tekstu.
