String — napisy w C++

Imię, słowo, całe zdanie, tekst czytany wiersz po wierszu, a nawet liczba tak wielka, że nie mieści się w żadnym typie — wszystko to zapiszesz w napisie. Podstawy już znasz: sklejanie plusem, length() i s[i]. Teraz poznasz napisy naprawdę. Nauczysz się wczytywać tekst na każdy sposób, rozpoznawać rodzaje znaków, budować i zmieniać napisy, porównywać je słownikowo, wycinać i szukać fragmentów, liczyć na olbrzymich liczbach zapisanych cyfra po cyfrze, a na koniec rozwiązywać olimpijskie zadania z tekstem. Po każdej części czekają ćwiczenia ze sprawdzarką.

01 — Napis od środka

Napis to rząd pudełek ze znakami

W lekcji o tablicach poznałeś rząd pudełek z numerami. Napis — zmienna typu string — w środku wygląda bardzo podobnie. To też rząd pudełek, tylko w każdym leży jeden znak, czyli wartość typu char. Pudełka są ponumerowane od zera, a do każdego dobierasz się zapisem s[numer]. Są dwie ważne różnice: napis sam wie, ile ma pudełek, i potrafi dokładać nowe pudełka na końcu, kiedy dopisujesz tekst. Nie musisz więc z góry zgadywać rozmiaru, jak przy tablicy.

s

o1
t2

string s = „kotek”; — pięć znaków w pięciu pudełkach o numerach od 0 do 4. Napis wie, że ma 5 pudełek: tyle zwraca s.length().
kotek.cpp
string s = "kotek";
cout << s << "\n";            // cały napis
cout << s.length() << "\n";   // ile ma znaków
cout << s[0] << "\n";         // pierwszy znak
cout << s[4] << "\n";         // ostatni znak
cout << s[1] << s[2] << "\n"; // drugi i trzeci, jeden za drugim
▶ Wyjście
kotek 5 k k ot

Prześledź wyjście linijka po linijce. cout << s wypisuje cały napis naraz — tego tablica nie potrafiła. s.length() mówi, ile jest pudełek: 5.

s[0] to pierwsze pudełko, a s[4] — ostatnie. W słowie „kotek” oba zawierają literę k, dlatego w wyjściu są dwa k pod rząd.

Ostatnia linijka wypisuje dwa znaki jeden za drugim: s[1] to o, a s[2] to t. Między nimi nie ma spacji, bo żadnej nie wypisaliśmy.

Numery pudełek: od 0 do długość − 1 Napis o długości n ma pudełka s[0], s[1], …, s[n - 1]. Pierwszy znak to zawsze s[0], a ostatni — s[n - 1], czyli s[s.length() - 1]. Pudełka s[n] już nie ma. To dokładnie ta sama zasada co w tablicach.

Długość: length() i size()

Długość napisu to liczba jego znaków. Liczą się wszystkie znaki: litery, cyfry, kropki, wykrzykniki — i spacje. Spacja to pełnoprawny znak, który zajmuje swoje pudełko. Na rysunkach będziemy ją pokazywać jako ␣, żeby było ją widać.

string a = "Ala ma kota";

string c = " ";      // jedna spacja
string d = "?!";
cout << a.length() << "\n";
cout << b.length() << "\n";
cout << c.length() << "\n";
cout << d.size() << "\n";   // size() to to samo co length()

length() i size() robią dokładnie to samo — możesz używać, którego chcesz. W wielu programach olimpijskich zobaczysz size(), bo tak samo nazywa się długość w innych strukturach, które poznasz później.

Zwróć uwagę na napis b. Dwa cudzysłowy bez niczego w środku to napis pusty — prawdziwy napis, który ma zero znaków. A c to nie pusty napis, tylko napis z jedną spacją. Na ekranie wyglądają tak samo, ale mają różne długości.

Nawiasy po length są obowiązkowe. Bez nich kompilator zgłosi błąd.

Pusty napis i empty()

Gdy tworzysz napis bez wartości — string s; — dostajesz napis pusty. To ważna różnica względem int: zmienna liczbowa utworzona w main bez wartości zawiera śmieci, a napis zawsze zaczyna jako pusty. Czy napis jest pusty, sprawdzisz metodą empty(). Zwraca prawdę albo fałsz, więc nadaje się prosto do if.

pusty.cpp
string s;                      // bez wartości — pusty
cout << s.length() << "\n";
cout << s.empty() << "\n";     // 1, czyli prawda
s = "a";
cout << s.empty() << "\n";     // 0, czyli fałsz
if (s.empty()) {
    cout << "pusto\n";
} else {
    cout << "jest tekst\n";
}
▶ Wyjście
0 1 0 jest tekst

Zapis s.empty() czytaj: „czy napis s jest pusty?”. Pamiętasz z lekcji o typach, że cout wypisuje prawdę jako 1, a fałsz jako 0.

Zamiast s.empty() możesz napisać s.length() == 0 albo s == "" — znaczą to samo. empty() jest po prostu najkrótsze i najczytelniejsze.

Pusty napis przyda się bardzo często jako punkt startowy: zaczynasz od "" i dokładasz kolejne znaki. Tak będziemy budować napisy w części 4.

Napis ma 13 znaków. Pierwszy to s[0], ostatni — s[12], czyli s[n - 1]. Środkowy (pomarańczowy) leży w pudełku 13 / 2 = 6.
pozycje.cpp
string s = "programowanie";
int n = s.length();        // 13
cout << s[0] << "\n";      // pierwszy
cout << s[n - 1] << "\n";  // ostatni
cout << s[n / 2] << "\n";  // środkowy: s[6]
cout << s.front() << s.back() << "\n";

Dla nieparzystej długości środek jest jeden: przed nim i za nim stoi tyle samo znaków. W słowie o 13 znakach to pudełko 6 — przed nim pudełka 0–5, za nim 7–12, po sześć z każdej strony. Dzielenie całkowite n / 2 daje właśnie 6.

Dla parzystej długości środkowe są dwa: s[n / 2 - 1] i s[n / 2]. Sprawdź na kartce: w słowie „domek” (5 liter) środkiem jest m, a w słowie „okno” (4 litery) środkowe są k i n.

s.front() i s.back() to skróty: pierwszy i ostatni znak. Działają tylko dla napisu, który nie jest pusty.

Zmiana jednego znaku

Pudełko napisu zachowuje się jak zwykła zmienna typu char. Możesz do niego wpisać nowy znak przez =. Napis zmienia się w tym jednym miejscu, a długość zostaje taka sama. Prześledź program w tabelce obok — w każdej linijce zmienia się dokładnie jedno pudełko.

zmiana.cpp
string s = "kot";
s[0] = 'p';      // k zamienia się w p
cout << s << "\n";
s[2] = 'r';      // t zamienia się w r
cout << s << "\n";
s[1] = s[0];     // drugie pudełko dostaje kopię pierwszego
cout << s << "\n";

Znak wpisujesz w apostrofach: 'p'. Zapis s[0] = "p"; się nie skompiluje — w cudzysłowie jest napis, a do pudełka mieści się tylko jeden znak.

Przez s[i] = … możesz tylko podmienić istniejący znak. Nowego pudełka na końcu tak nie dodasz: w trzyznakowym napisie s[3] = 'y'; to błąd. Dokładanie znaków poznasz w części 4.

Napis tworzony na różne sposoby

Napis możesz utworzyć na kilka sposobów. Pięć z nich znasz już z lekcji o typach, szósty jest nowy. W programie obok każdy napis wypisujemy w nawiasach kwadratowych — to prosty trik, dzięki któremu widać, gdzie napis się zaczyna i kończy, nawet gdy jest pusty albo kończy się spacją.

tworzenie.cpp
string a;                 // pusty
string b = "tekst";       // z gotowym tekstem
string c(4, '*');         // 4 razy ten sam znak
string d = b;             // kopia napisu b
string e = b + "!";       // sklejony z dwóch kawałków
string f(1, 'x');         // napis z jednego znaku
cout << "[" << a << "]\n";
cout << "[" << b << "]\n";
cout << "[" << c << "]\n";
cout << "[" << d << "]\n";
cout << "[" << e << "]\n";
cout << "[" << f << "]\n";
▶ Wyjście
[] [tekst] [****] [tekst] [tekst!] [x]

string c(4, '*'); to ten sam przepis co string(4, '*') z lekcji o typach: „zrób napis z czterech gwiazdek”. Najpierw liczba, potem znak w apostrofach.

string f(1, 'x'); wygląda dziwnie, ale bywa potrzebny: robi napis z jednego znaku. Znak 'x' i napis "x" to w C++ różne rzeczy — w części 4 zobaczysz, kiedy ta różnica gryzie.

Nawiasy kwadratowe w cout nie są częścią napisów — to zwykły tekst, który wypisujemy dookoła. Używaj tego triku zawsze, gdy nie masz pewności, co naprawdę jest w napisie.

Kopiowanie i porównywanie — tu napis wygrywa z tablicą

Z lekcji o tablicach pamiętasz, że tablicy nie da się skopiować znakiem =, a a == b nie porównuje jej zawartości. Z napisami jest dużo wygodniej: = robi pełną kopię, a == porównuje tekst znak po znaku. Kopia jest osobnym napisem — zmiana kopii nie rusza oryginału.

kopia.cpp
string a = "kot";
string b = a;          // b to osobna kopia
b[0] = 'p';            // zmieniamy tylko b
cout << a << " " << b << "\n";
cout << (a == b) << "\n";   // czy takie same?
b[0] = 'k';
cout << (a == b) << "\n";
▶ Wyjście
kot pot 0 1

Po b = a oba napisy zawierają „kot”, ale leżą w osobnych pudełkach. Zmiana b[0] zmienia tylko b, więc a zostaje „kot”, a b staje się „pot”.

Porównanie a == b sprawdza, czy oba napisy mają tę samą długość i te same znaki na tych samych miejscach. Po przywróceniu b[0] = 'k' znowu są równe. Nawias wokół porównania w cout jest obowiązkowy — pamiętasz to z lekcji o typach.

Porównywaniem napisów — także tym, który jest „mniejszy” — zajmiemy się dokładnie w części 5.

Poza napisem — ten sam błąd co w tablicy

Co się stanie, gdy sięgniesz po pudełko, którego nie ma, na przykład s[5] w trzyznakowym napisie? Dokładnie to samo co w tablicy: C++ nie sprawdza numeru. Nie zobaczysz komunikatu. Dostaniesz przypadkowy znak z pamięci obok albo program się wysypie — czasem dopiero w sprawdzarce.

Napis ma jednak bezpieczniejszą wersję nawiasów: metodę at. Zapis s.at(i) działa jak s[i], ale najpierw sprawdza, czy pudełko i istnieje. Jeśli nie — zatrzymuje program z komunikatem o błędzie zamiast udawać, że wszystko gra.

poza.cpp
string s = "kot";
cout << s[5] << "\n";      // BŁĄD: nie ma pudełka 5 — wynik przypadkowy
cout << s.at(5) << "\n";   // at() sprawdza numer i zatrzymuje program

Program dziwnie się zachowuje? Użyj at Pierwsza linijka wypisała jakiś przypadkowy znak (albo nic) i program poszedł dalej, jakby nic się nie stało. Dopiero at zatrzymał program i powiedział wprost: pytasz o pudełko 5, a napis ma rozmiar 3. Gdy Twój program daje dziwne wyniki, zamień na chwilę s[i] na s.at(i) — jeśli gdzieś wychodzisz poza napis, od razu się dowiesz. W gotowym rozwiązaniu możesz wrócić do zwykłych nawiasów.

Pułapka: długość nie zna liczb ujemnych

Teraz rzecz, która zaskakuje prawie każdego. Liczba zwracana przez s.length() ma specjalny typ, który nie ma liczb ujemnych — taki typ nazywa się „bez znaku” (po angielsku unsigned). Co się dzieje, gdy od zera w takim typie odejmiesz jeden? Wynik „przekręca się” jak licznik kilometrów w starym samochodzie: po 0000 cofnięciu wychodzi 9999. Tu wychodzi największa liczba, jaką ten typ mieści.

bez_znaku.cpp
string s = "";                    // pusty, długość 0
cout << s.length() - 1 << "\n";   // 0 - 1 w typie bez znaku
int n = s.length();               // długość w zwykłym int
cout << n - 1 << "\n";            // teraz -1, tak jak trzeba
▶ Wyjście
18446744073709551615 -1

Pierwsza linijka wyniku to nie żart: 18 446 744 073 709 551 615, czyli 264 − 1. Tyle wychodzi z 0 − 1, gdy liczba nie może być ujemna.

Czym to grozi? Pętla for (int i = 0; i < s.length() - 1; i++) dla pustego napisu wykonałaby się miliardy razy i wyszła daleko poza napis. To bardzo częsty powód błędu wykonania w sprawdzarce.

Najprostsza ochrona: na początku zapisz długość w zmiennej int n = s.length(); i dalej używaj n. W zwykłym int zero minus jeden to po prostu −1. Przy okazji znikną ostrzeżenia kompilatora o porównywaniu liczb „ze znakiem i bez znaku”.

Polskie litery to dwa znaki

Na koniec obiecane wyjaśnienie, dlaczego w zadaniach nie ma polskich liter. Komputer zapisuje znaki z ogonkami — ą, ć, ę, ł, ń, ó, ś, ź, ż — za pomocą dwóch bajtów, a string liczy bajty, nie litery. Słowo „żółw” ma dla nas cztery litery, ale dla C++ siedem znaków: ż, ó i ł zajmują po dwa pudełka, a w — jedno.

zolw.cpp
string s = "żółw";
cout << s.length() << "\n";
▶ Wyjście
7

Z tego samego powodu s[0] to tylko połowa litery ż — wypisany osobno pokaże się jako dziwny znaczek, a toupper w ogóle go nie zmieni. Dlatego w zadaniach olimpijskich (także na OI i OIJ) teksty składają się ze zwykłych liter od a do z — i tak samo jest we wszystkich zadaniach tej lekcji.

Jeśli testujesz program u siebie, wpisuj dane bez polskich liter: „zolw”, a nie „żółw”.

Sprawdź się w głowie

Najpierw odpowiedz w myślach — rozpisz sobie znaki napisu w pudełkach z numerami i śledź program linijka po linijce — a dopiero potem kliknij „Pokaż odpowiedź”.

Co wypisze ten fragment?
string s = "olimpiada";
cout << s.length() << " " << s[3];
Pokaż odpowiedź
9 m„olimpiada” ma 9 liter. Numerujemy od zera: s[0] = o, s[1] = l, s[2] = i, s[3] = m.
Ile znaków ma ten napis?
string s = "Ala ma kota.";
cout << s.length();
Pokaż odpowiedź
129 liter, 2 spacje i kropka: 9 + 2 + 1 = 12. Spacje i znaki przestankowe też zajmują pudełka.
Co wypisze ten fragment?
string s = "mama";
s[0] = 'l';
s[2] = 'l';
cout << s;
Pokaż odpowiedź
lalaZmieniamy pudełka 0 i 2 — oba zawierały m. Pudełka 1 i 3 (litery a) zostają bez zmian.
Kopia i oryginał. Co wypisze ten fragment?
string s = "abc";
string t = s;
t[1] = 'X';
cout << s << t;
Pokaż odpowiedź
abcaXct to osobna kopia, więc zmiana t[1] nie rusza s. Wypisujemy „abc”, a zaraz za nim „aXc”.
Co wypisze ten fragment?
string s(3, 'o');
cout << s + "k" << " " << s.length();
Pokaż odpowiedź
oook 3s to „ooo”. s + "k" tworzy nowy napis „oook” do wypisania, ale samego s nie zmienia — jego długość to nadal 3.
Co wypisze ten fragment?
string s = "programista";
int n = s.length();
cout << s[n - 2] << s[n / 2];
Pokaż odpowiedź
tan = 11. s[9] to t (przedostatnia litera), a s[11 / 2] = s[5] to a: p-r-o-g-r-a.
Co wypisze ten fragment?
string s;

Jaki to znak? Warunki na przedziałach

W tabeli ASCII małe litery stoją jedna za drugą (od 97 do 122), wielkie też (od 65 do 90), cyfry też (od 48 do 57). 04 — Zmienianie i budowanie

Zmieniamy i budujemy napisy

Z napisem możesz pracować na dwa sposoby. Pierwszy: zmieniasz znaki w miejscu, pudełko po pudełku. Napis ma wtedy cały czas tę samą długość — każdy znak zamienia się na inny. Drugi: budujesz nowy napis od pustego, dokładając kawałek po kawałku. Wtedy możesz robić, co chcesz: pomijać znaki, podwajać je, wstawiać nowe. W tej części przećwiczymy oba sposoby i poznamy pułapki, które czyhają przy sklejaniu.

Sklejanie plusem wydaje się proste, ale kryje cztery pułapki. Wszystkie biorą się z tego samego: w C++ tylko string umie się sklejać. Znak w apostrofach to tak naprawdę liczba (kod ASCII), a tekst w cudzysłowie, który nie trafił jeszcze do zmiennej string, to „surowy” tekst, który sklejać się nie umie. 05 — Porównywanie napisów

Porównywanie napisów: równe, mniejsze, większe

Liczby porównujesz od pierwszej lekcji: 3 < 7, 10 == 10. Napisy też można porównywać tymi samymi operatorami: ==, !=, <, >, <=, >=. Równość jest prosta. Ciekawsze jest pytanie, kiedy jeden napis jest mniejszy od drugiego. Odpowiedź: wtedy, gdy w słowniku stałby wcześniej. Zobaczysz jednak, że „słownik” komputera ma kilka niespodzianek.

== i != — czy to dokładnie ten sam tekst?

Dwa napisy są równe, gdy mają tę samą długość i na każdej pozycji ten sam znak. Wielkość liter ma znaczenie, spacje też — nawet niewidoczna spacja na końcu.

string a = "kot", b = "Kot", c = "kot ", d = "kot";

cout << (a == c) << "\n";   // c ma spację na końcu
cout << (a == d) << "\n";   // dokładnie ten sam tekst
cout << (a != b) << "\n";   // != to „różne”

Wielkie litery przed małymi

Pierwsza niespodzianka. Komputer nie zna alfabetu, zna tylko kody ASCII. Wielkie litery mają kody od 65 do 90, a małe od 97 do 122. Każda wielka litera jest więc „mniejsza” od każdej małej. Gdy liczby są tak wielkie, że nie mieszczą się w żadnym typie i muszą zostać napisami — zajmiemy się nimi w części 7. Na szczęście naprawa jest prosta.     cin >> s;
    if (s < najm) najm = s;
    if (s > najw) najw = s;
}

06 — Fragmenty i szukanie

Fragmenty i szukanie: substr, find, erase, insert, replace

Do tej pory wszystko robiłeś pętlą, znak po znaku. To dobra szkoła, ale napis ma też gotowe metody — polecenia pisane po kropce, jak s.length() — które załatwiają typowe zadania jedną linijką. W tej części poznasz pięć najważniejszych: substr wycina kawałek, find szuka fragmentu, a erase, insert i replace usuwają, wstawiają i podmieniają. Każdą pokażemy na rysunku pudełek, żeby było widać, które dokładnie znaki biorą udział.

07 — Napisy i liczby

Napisy i liczby: cyfry, zamiany i olbrzymy

Liczba i napis z cyframi to dla komputera dwie zupełnie różne rzeczy. 123 to liczba — można ją dodawać i mnożyć. "123" to trzy znaki w pudełkach — można je wycinać, odwracać i liczyć. W tej części nauczysz się przechodzić między tymi światami i korzystać z obu. A na koniec zobaczysz, jak liczyć na liczbach, które mają sto albo tysiąc cyfr — za dużych dla każdego typu, ale nie dla napisu.

Cyfra jako znak, cyfra jako liczba

Przypomnienie z lekcji o typach: znaki cyfr stoją w tabeli ASCII po kolei, od '0' (kod 48) do '9' (kod 57). Dlatego c - '0' zamienia znak cyfry na jej wartość, a '0' + d zamienia wartość od 0 do 9 na znak. Te dwa zapisy będą Ci towarzyszyć przez całą tę część.

cyfra_znak.cpp
char c = '7';
int d = c - '0';           // znak '7' → liczba 7
char e = '0' + 3;          // liczba 3 → znak '3'
cout << d * 2 << " " << e << "\n";
string s = "2026";
int suma = 0;
for (char z : s) {
    suma += z - '0';       // dodajemy wartości cyfr
}
cout << suma << "\n";

to_string i stoi — w obie strony

Całą liczbę zamienisz na napis funkcją to_string(x), a napis z cyframi na liczbę — funkcją stoi(s) („string to int”). Dla dużych liczb jest stoll („string to long long”). Obie znasz z lekcji o typach. Teraz zobacz, ile dają w połączeniu z tym, co wiesz o napisach: liczba cyfr to po prostu długość napisu, a pierwsza i ostatnia cyfra to pierwszy i ostatni znak.

to_string.cpp
int x = 4096;

cout << s.length() << "\n";                  // liczba cyfr
cout << s[0] << s[s.length() - 1] << "\n";   // pierwsza i ostatnia cyfra
string t = "123";
cout << stoi(t) + 1 << "\n";                 // liczba: dodawanie
cout << t + "1" << "\n";                     // napis: sklejanie
long long duza = stoll("9000000000");
cout << duza * 2 << "\n";

W lekcji o pętli while sprawdzałeś, czy liczba jest palindromem, rozbierając ją na cyfry przez % 10 i / 10. Z napisem jest krócej: zamieniasz liczbę na napis i porównujesz go z odwróconym. Oba sposoby są dobre — wybierz ten, który w danym zadaniu jest prostszy.

Na co uważać przy stoi stoi czyta cyfry od początku napisu i zatrzymuje się na pierwszym znaku, który do liczby nie pasuje: stoi("12abc") to 12, a stoi(" 7") to 7 (spacje na początku pomija). Ale gdy napis nie zaczyna się od liczby — stoi("abc") — program zatrzyma się z błędem invalid_argument. A gdy liczba nie mieści się w int — z błędem out_of_range; wtedy użyj stoll.

Olbrzymy: liczby za duże dla każdego typu

Największy typ, który znasz, long long, mieści liczby do około 9 · 1018 — to 19 cyfr. Co zrobić z liczbą, która ma 100 cyfr? W zadaniach olimpijskich takie liczby się zdarzają, a jedyne miejsce, gdzie się zmieszczą, to napis. Wczytujesz je przez cin >> s jak zwykłe słowo i liczysz na nich cyfra po cyfrze — tak jak w szkole liczysz pisemnie.

Sporo pytań o olbrzyma da się rozstrzygnąć bez żadnych obliczeń, samym oglądaniem cyfr. Ostatnia cyfra mówi o parzystości i o podzielności przez 5 i 10. Suma cyfr — o podzielności przez 3 i 9. Dwie ostatnie cyfry — o podzielności przez 4.

olbrzym.cpp
string s;
cin >> s;
int n = s.length();
int ostatnia = s[n - 1] - '0';
int suma = 0;
for (char c : s) {
    suma += c - '0';
}
cout << "cyfr: " << n << "\n";
cout << "parzysta: " << (ostatnia % 2 == 0) << "\n";
cout << "podzielna przez 3: " << (suma % 3 == 0) << "\n";

Zwróć uwagę, że suma cyfr jest mała nawet dla gigantycznej liczby: tysiąc cyfr daje sumę najwyżej 9000. Spokojnie zmieści się w int.

Reszta z dzielenia olbrzyma

A co z podzielnością przez 7 albo przez 1000? Tu przydaje się sztuczka z lekcji o modulo. Liczbę budujemy cyfra po cyfrze: przy każdej nowej cyfrze stara wartość mnoży się przez 10 i dochodzi cyfra. Ale nie musimy pamiętać całej wartości — wystarczy jej reszta. Po każdym kroku bierzemy % k, więc liczby nigdy nie urosną.

reszta.cpp
string s;
long long k;
cin >> s >> k;
long long r = 0;
for (char c : s) {
    r = (r * 10 + (c - '0')) % k;
}
cout << r << "\n";

Dodawanie pisemne na napisach

Dwóch olbrzymów można dodać dokładnie tak, jak uczyli Cię w podstawówce: od ostatnich cyfr, z przeniesieniem. Idziemy dwoma indeksami od końca obu liczb. W każdym kroku dodajemy dwie cyfry (albo jedną, gdy krótsza liczba już się skończyła) i przeniesienie z poprzedniego kroku. Ostatnia cyfra sumy trafia do wyniku, a dziesiątki idą dalej jako przeniesienie.

dodawanie.cpp
string a, b;
cin >> a >> b;
string wynik = "";
int i = a.length() - 1, j = b.length() - 1;
int przeniesienie = 0;
while (i >= 0 || j >= 0 || przeniesienie > 0) {
    int suma = przeniesienie;
    if (i >= 0) {
        suma += a[i] - '0';
        i--;
    }
    if (j >= 0) {
        suma += b[j] - '0';
        j--;
    }
    wynik = (char)('0' + suma % 10) + wynik;  // cyfra na początek
    przeniesienie = suma / 10;
}
cout << wynik << "\n";

System dwójkowy na napisach

W lekcji o modulo zamieniałeś liczby na inne systemy. Napisy bardzo to ułatwiają, bo liczba w systemie dwójkowym to po prostu napis z zer i jedynek. Liczby ukryte w tekście

Ostatni schemat tej części: tekst, w którym między literami stoją liczby, na przykład „W koszyku 12 jablek i 125 sliwek”. Jak wyciągnąć z niego liczby? Idziemy znak po znaku i budujemy bieżącą liczbę: każda cyfra to liczba = liczba * 10 + cyfra. Gdy trafimy na znak, który nie jest cyfrą, bieżąca liczba się skończyła — zapisujemy ją i zaczynamy od zera.

liczby_w_tekscie.cpp
string s;
getline(cin, s);
long long suma = 0, liczba = 0;
for (char c : s) {
    if (isdigit(c)) {
        liczba = liczba * 10 + (c - '0');
    } else {
        suma += liczba;    // liczba się skończyła
        liczba = 0;
    }
}
suma += liczba;            // liczba na samym końcu tekstu
cout << suma << "\n";

▶ Wyjście

Dodawanie przy każdym znaku, który nie jest cyfrą, wygląda podejrzanie — przecież liter jest dużo. Ale gdy przed literą nie było cyfr, liczba wynosi 0, więc dodanie jej niczego nie zmienia. Prosto i bez dodatkowych warunków.

Najczęstszy błąd: brak linijki po pętli. Gdy tekst kończy się cyfrą, ostatnia liczba nie ma za sobą litery, która by ją „zamknęła” — trzeba ją dodać osobno.

08 — Napisy na olimpiadzie

Napisy na olimpiadzie: liczniki, szyfry, okna

Na olimpiadzie napisy są długie — sto tysięcy, a nawet milion znaków — a pytań o nie jest dużo. Pętla w pętli, która dla zwykłych danych działa w mgnieniu oka, nagle potrzebuje godzin. W tej części poznasz sztuczki, które pozwalają odpowiadać szybko: tablicę liczników liter, szyfry z modulo, przesuwane okno i sumy prefiksowe na napisie. Większość z nich znasz już z tablic — teraz zobaczysz je w świecie tekstu. Na koniec sprawdzimy, które operacje na napisach są tanie, a które drogie.

Tablica liczników liter

W lekcji o tablicach liczyłeś litery w tablicy int ile[26], gdzie literze c odpowiada pudełko c - 'a'. To jedna z najważniejszych sztuczek w zadaniach tekstowych, bo wiele pytań dotyczy nie kolejności liter, tylko tego, ile ich jest. Na przykład: dwa słowa są anagramami (jedno powstaje z drugiego przez przestawienie liter), gdy każda litera występuje w nich tyle samo razy.

anagramy.cpp
string a, b;
cin >> a >> b;
int ile[26] = {};
for (char c : a) ile[c - 'a']++;    // litery a dodajemy
for (char c : b) ile[c - 'a']--;    // litery b odejmujemy
bool anagram = true;
for (int k = 0; k < 26; k++) {
    if (ile[k] != 0) anagram = false;
}
cout << (anagram ? "TAK" : "NIE") << "\n";

Ile to kosztuje? Jedno przejście po każdym słowie i 26 obrotów na koniec. Porównywanie „każda litera z każdą” byłoby dużo wolniejsze — dla słów o stu tysiącach liter różnica to ułamek sekundy kontra wiele minut.

Gdy w tekście mogą być nie tylko małe litery, możesz liczyć wszystkie znaki naraz. Kody ASCII zwykłych znaków mieszczą się między 0 a 127, więc wystarczy tablica int ile[128], a znak sam w sobie jest numerem pudełka: ile[c]++.

Szyfry i modulo

Szyfr Cezara znasz z wcześniejszych lekcji: każdą literę przesuwamy o k miejsc w alfabecie, a gdy wyjdziemy za z — wracamy na początek. To „wracanie w kółko” to dokładnie modulo: numer litery to c - 'a', po przesunięciu (c - 'a' + k) % 26, a z powrotem na znak — 'a' + …. Wielkie litery obsługujemy osobno, z 'A' zamiast 'a', a pozostałe znaki zostawiamy.

cezar.cpp
int k;
string s;
cin >> k;
cin.ignore();
getline(cin, s);
for (char &c : s) {
    if (islower(c)) {
        c = 'a' + (c - 'a' + k) % 26;
    } else if (isupper(c)) {
        c = 'A' + (c - 'A' + k) % 26;
    }
}
cout << s << "\n";

Baza zadań: napisy w praktyce

Znasz już wszystko, co potrzebne: napis jako rząd znaków, wczytywanie słów, wierszy i całego tekstu, rodzaje znaków i toupper, budowanie i zmienianie napisów, kolejność słownikową, metody substr, find, erase, insert i replace, liczby zapisane jako napisy, a do tego liczniki liter, szyfry, okna i sumy prefiksowe. 10 — Częste błędy

Częste błędy i dobre praktyki

0️⃣
Od 0 do długość − 1
Pierwszy znak to s[0], ostatni — s[s.length() - 1]. C++ nie sprawdza indeksów: s[n] da śmieci albo wysypie program. Gdy coś nie gra, zamień na chwilę s[i] na s.at(i).
➖
int n = s.length();
Długość nie zna liczb ujemnych: dla pustego napisu s.length() - 1 to 18 446 744 073 709 551 615. Zapisz długość w int i używaj n - 1.
↵
Enter po liczbie
Po cin >> n na wejściu zostaje Enter i getline wczyta pusty napis. Między nimi dopisz cin.ignore(); albo użyj getline(cin >> ws, s).
🔤
'a', "a" i a
Znak w apostrofach, napis w cudzysłowie, zmienna bez niczego. s[0] = "p" się nie skompiluje, a 'a' + 'b' to liczba 195, nie napis „ab”.
➕
Plus tylko ze stringiem
"Ala" + " ma" to błąd, s += 5 dokleja niewidzialny znak, a "Wynik: " + x ucina tekst. Liczby zamieniaj przez to_string, a w cout używaj <<.
🔢
toupper daje liczbę
cout << toupper(c) wypisze kod, np. 75. Rzutuj: (char)toupper(c) albo zapisz wynik do char lub s[i]. A wyników isdigit i spółki nie porównuj z 1.
🔍
find i npos
Brak wyniku to string::npos (w int: −1), a znalezisko na początku to 0. Nigdy nie pisz if (s.find(x)) — porównuj z npos albo z −1.
✂️
substr(od, ile)
Druga liczba to długość, nie pozycja końca. Fragment od a do b włącznie: s.substr(a, b - a + 1). Początek większy od długości kończy program błędem.
🔠
Wielkie przed małymi
W porównaniu napisów „Zebra” < „antylopa”, a „10” < „9”. Bez względu na wielkość — porównuj kopie zamienione na małe. Olbrzymy — najpierw długość.
🧩
Ostatni kawałek
Tniesz tekst po przecinkach albo składasz liczby z cyfr? Po pętli zostaje ostatni kawałek, za którym nie było separatora — obsłuż go osobno.
🐢
s += c, nie s = s + c
Sklejanie plusem tworzy kopię całego napisu. W pętli po długim tekście to miliardy operacji. Dokładaj przez +=, a doklejanie z przodu zamień na budowanie od końca i jedno odwrócenie.
🇵🇱
Bez polskich liter
Ą, ę, ł, ó, ś, ż… zajmują po dwa znaki: „żółw” ma długość 7. Testuj programy na tekstach bez ogonków — takie są dane na olimpiadzie i w sprawdzarce.
11 — Idź dalej

Co dalej?

Napisy pojawią się w niemal każdym kolejnym temacie: imiona w tabelach wyników, słowa do posortowania, teksty do policzenia. Następna lekcja to pary — sposób, żeby trzymać razem dwie wartości, na przykład imię i liczbę punktów. Potem przyjdą vector, czyli tablica, która sama rośnie jak napis, i sortowanie, które ułoży słowa w kolejności słownikowej jednym poleceniem.
