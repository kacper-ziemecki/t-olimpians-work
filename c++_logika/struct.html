Struct — własny typ danych

Uczeń ma imię, klasę i punkty. Punkt ma współrzędne x i y. Pociąg ma nazwę, godzinę odjazdu i przyjazdu. Do tej pory każdą taką cechę trzymałeś w osobnej zmiennej albo w osobnej tablicy — i pilnowałeś, żeby się nie rozjechały. struct pozwala zbudować z nich jeden, Twój własny typ: zmienna typu Uczen trzyma w sobie imię, klasę i punkty naraz, a każda cecha ma czytelną nazwę. W tej lekcji poznasz struktury od zera, bardzo powoli: od pierwszej deklaracji, przez kopiowanie całych rekordów, vector struktur i struktury w funkcjach, aż po sortowanie z kilkoma kryteriami, metody, operatory i olimpijskie schematy ze zdarzeniami i przedziałami. Po każdej części czekają ćwiczenia ze sprawdzarką.

01 — Pierwsza struktura

Kilka wartości w jednej zmiennej

Zacznijmy od problemu, który na pewno już znasz. Chcesz zapisać w programie ucznia: jego imię, wiek i ocenę. To trzy wartości różnych typów — więc trzy zmienne. Dla dwóch uczniów — sześć zmiennych.

Problem: jedna rzecz, kilka zmiennych

bez_struktury.cpp
int main() {
    string imie1, imie2;
    int wiek1, wiek2, ocena1, ocena2;
    cin >> imie1 >> wiek1 >> ocena1;
    cin >> imie2 >> wiek2 >> ocena2;
    if (wiek1 > wiek2) cout << imie1 << " jest starszy\n";
    else cout << imie2 << " jest starszy\n";
    return 0;
}

Program działa, ale już przy dwóch uczniach widać kłopot. Dane jednego ucznia są rozrzucone po trzech zmiennych, które łączy tylko cyfra na końcu nazwy: imie1, wiek1, ocena1. Wystarczy raz napisać wiek2 zamiast wiek1 i program porównuje nie te liczby — a kompilator nic nie zauważy.

A co przy trzydziestu uczniach? Dziewięćdziesiąt zmiennych odpada. Zostają trzy osobne tablice: imiona[], wiek[] i oceny[] — i pilnowanie, żeby i-ty element każdej z nich dotyczył tego samego ucznia. Zobaczysz w części 3, jak łatwo to zepsuć.

int main() {

    cout << " lat i ocene " << u.second.second << "\n";

▶ Wyjście

Z lekcji o parach wiesz, że pair skleja dwie wartości w jedną zmienną. Trzy wartości to para, w której druga połówka sama jest parą. Działa — ale spróbuj na pierwszy rzut oka powiedzieć, co oznacza u.second.first. Wiek? Ocena? Trzeba zajrzeć do deklaracji.

Nazwy first i second nic nie mówią. Przy czterech albo pięciu wartościach para par par robi się zupełnie nieczytelna. Potrzebujemy czegoś, co skleja dowolnie wiele wartości i pozwala każdej nadać własną nazwę. To właśnie jest struct.

struct — własny typ z polami

deklaracja.cpp
struct Uczen {
    string imie;
    int wiek;
    int ocena;
};
int main() {
    Uczen a;
    a.imie = "Ala";
    a.wiek = 12;
    a.ocena = 5;
    cout << a.imie << " ma " << a.wiek << " lat i ocene " << a.ocena << "\n";
    return 0;
}
▶ Wyjście
Ala ma 12 lat i ocene 5

Nad main stoi przepis na nowy typ. Słowo struct mówi: „teraz zdefiniuję własny typ”, a Uczen to jego nazwa — wymyślasz ją sam i zwyczajowo zaczynasz wielką literą. W klamrach są pola: każde wygląda jak zwykła deklaracja zmiennej (typ i nazwa) zakończona średnikiem.

Od tej chwili Uczen jest pełnoprawnym typem, takim jak int czy string. Zapis Uczen a; tworzy zmienną a, która ma w środku trzy przegródki: a.imie, a.wiek i a.ocena. Do pola dobierasz się kropką: najpierw nazwa zmiennej, potem kropka, potem nazwa pola.

Zwróć uwagę na średnik po zamykającej klamrze: };. To jedno z niewielu miejsc w C++, gdzie po klamrze stoi średnik — i najczęstszy błąd przy pierwszej strukturze.

Pomyśl o strukturze jak o formularzu. Deklaracja struct Uczen to wzór formularza z pustymi rubrykami „imię”, „wiek”, „ocena”. Dopiero Uczen a; to wypełniony egzemplarz — a każdy egzemplarz ma swoje własne rubryki. Strukturę deklarujesz nad main, tak jak funkcje — wtedy znają ją wszystkie funkcje w programie.

Pole to zwykła zmienna

pole_jak_zmienna.cpp
struct Uczen {
    string imie;
    int wiek;
    int ocena;
};
int main() {
    Uczen a;
    a.imie = "Ala";
    a.wiek = 12;
    a.ocena = 4;
    a.wiek++;
    a.ocena += 1;
    a.imie += " Nowak";
    if (a.ocena == 5) cout << "piatka!\n";
    cout << a.imie << ", " << a.wiek << " lat, ocena " << a.ocena << "\n";
    cout << "za 10 lat: " << a.wiek + 10 << "\n";
    return 0;
}
▶ Wyjście
piatka! Ala Nowak, 13 lat, ocena 5 za 10 lat: 23

a.wiek jest zwykłą zmienną typu int, tylko z dłuższą nazwą. Możesz ją zwiększyć (a.wiek++), dodać do niej coś (a.ocena += 1), sprawdzić w if i użyć w rachunkach (a.wiek + 10). Tak samo a.imie jest zwykłym napisem — działa na nim +=, size(), indeksowanie i wszystko, co znasz z lekcji o napisach.

Zapamiętaj regułę: wszędzie, gdzie mogłaby stać zmienna danego typu, może stać pole tego typu. Kropka to tylko „adres” przegródki w pudełku.

Inicjalizacja klamrami

klamry.cpp
struct Uczen {
    string imie;
    int wiek;
    int ocena;
};
int main() {
    Uczen a = {"Ala", 12, 5};
    Uczen b = {"Bartek", 13};
    Uczen c = {};
    cout << a.imie << " " << a.wiek << " " << a.ocena << "\n";
    cout << b.imie << " " << b.wiek << " " << b.ocena << "\n";
    cout << "[" << c.imie << "] " << c.wiek << " " << c.ocena << "\n";
    a = {"Ola", 11, 6};
    cout << a.imie << " " << a.wiek << " " << a.ocena << "\n";
    return 0;
}
▶ Wyjście
Ala 12 5 Bartek 13 0 [] 0 0 Ola 11 6

Zamiast przypisywać pola po kolei, możesz wypełnić je od razu przy tworzeniu zmiennej: Uczen a = {"Ala", 12, 5};. Wartości w klamrach trafiają do pól w kolejności z deklaracji: pierwsza do imie, druga do wiek, trzecia do ocena.

Gdy podasz mniej wartości, reszta pól dostaje zera (a napisy są puste) — stąd b.ocena równe 0. Puste klamry {} zerują wszystkie pola. Klamry działają też później, w zwykłym przypisaniu: a = {"Ola", 11, 6}; wymienia wszystkie trzy pola naraz.

Uważaj za to na pola tego samego typu. Gdybyś napisał Uczen x = {"Ala", 5, 12};, czyli zamienił wiek z oceną, kompilator nic nie powie — obie liczby pasują do int. Przy klamrach zawsze patrz na kolejność pól w deklaracji.

Na olimpiadzie najczęstsza struktura ma tylko dwa pola: struct Punkt { int x, y; };. Punkt na planszy, kratka w labiryncie, pozycja robota, wektor przesunięcia — wszędzie dwie liczby, które zawsze chodzą razem.

W klamrach możesz wpisywać nie tylko gotowe liczby, ale dowolne wyrażenia: Punkt c = {a.x + b.x, a.y + b.y}; liczy obie współrzędne i od razu tworzy z nich nowy punkt. Odległość „po ulicach” (taksówkowa) to suma różnic współrzędnych z lekcji o wartości bezwzględnej.

Zapamiętaj struct Nazwa { typ pole1; typ pole2; … }; — ze średnikiem po klamrze i nad main — tworzy nowy typ. Nazwa z; tworzy zmienną z kompletem własnych pól, a z.pole to zwykła zmienna, której używasz jak każdej innej. Wczytujesz i wypisujesz pole po polu (cin >> z; się nie skompiluje). Klamry {a, b, c} wypełniają pola w kolejności deklaracji, brakujące pola dostają zera, a {} zeruje wszystko. Pola liczbowe lokalnej zmiennej bez klamer mają śmieci.

Cały rekord naraz

Do tej pory traktowaliśmy strukturę jak worek na pola: wkładaliśmy coś do a.imie, coś do a.wiek. Ale struktura to także jedna wartość, którą można przenosić w całości — jednym przypisaniem skopiować wszystkie pola naraz. Wartość z kilkoma polami nazywa się często rekordem — tak będziemy mówić w tej lekcji.

Przypisanie kopiuje wszystkie pola

kopia.cpp
struct Uczen {
    string imie;
    int ocena;
};
int main() {
    Uczen a = {"Ala", 5};
    Uczen b = a;
    b.ocena = 6;
    cout << a.imie << " " << a.ocena << "\n";
    cout << b.imie << " " << b.ocena << "\n";
    b = {"Bartek", 3};
    a = b;
    cout << a.imie << " " << a.ocena << "\n";
    return 0;
}

Uczen b = a; tworzy nowego ucznia i przepisuje do niego wszystkie pola a: imię i ocenę. To kopia — dwa osobne pudełka z takimi samymi wartościami. Gdy potem zmieniamy b.ocena na 6, a.ocena zostaje 5.

        04 — Struktury w funkcjach
        
Kopia, & i zwracanie struktury

        

            
Struktura jest typem jak każdy inny, więc może być parametrem funkcji i wynikiem funkcji. struct Ulamek {
    long long l, m;
};
long long nwd(long long a, long long b) {
    if (b == 0) return a;
    return nwd(b, a % b);
}
Ulamek skroc(Ulamek u) {
    long long g = nwd(llabs(u.l), u.m);
    return {u.l / g, u.m / g};
}
Ulamek dodaj(Ulamek a, Ulamek b) {
    return skroc({a.l * b.m + b.l * a.m, a.m * b.m});
}
int main() {
    Ulamek x = {1, 6}, y = {1, 3};
    Ulamek s = dodaj(x, y);
    cout << s.l << "/" << s.m << "\n";
    Ulamek z = skroc({-12, 18});

    return 0;
}

Struktura, która coś umie

        

            
Do tej pory struktura tylko przechowywała dane, a wszystko, co z nimi robiliśmy, siedziało w osobnych funkcjach. Funkcję można jednak wpisać do środka struktury — wtedy nazywa się metodą. Znasz to już, choć może nie wiesz: s.size() dla napisu i v.push_back(x) dla vectora to właśnie metody.

        07 — Operatory
        
Struktura, która umie się porównać

        

            
Kilka razy natknęliśmy się na mur: a == b się nie kompiluje, sort bez komparatora też nie, a set<Punkt> czy map<Punkt, int> w ogóle nie działają. Pięć przedziałów i ich suma (na zielono): [1, 5], [6, 10] i [12, 14]. Przedziały [6, 9] i [9, 10] mają wspólny punkt 9, więc też się łączą.

struct Przedzial {
    int a, b;
};
int main() {
    vector<Przedzial> v = {{6, 9}, {1, 3}, {2, 5}, {9, 10}, {12, 14}};
    sort(v.begin(), v.end(), [](const Przedzial &x, const Przedzial &y) {
        return x.a < y.a;
    });
    vector<Przedzial> wynik;
    for (const Przedzial &p : v) {
        if (!wynik.empty() && p.a <= wynik.back().b)
            wynik.back().b = max(wynik.back().b, p.b);
        else
            wynik.push_back(p);
    }
    for (const Przedzial &p : wynik) cout << "[" << p.a << ", " << p.b << "] ";
    cout << "\n";
    return 0;
}

    return {a.x + b.x, a.y + b.y};

Bez & — kopia. Struktura z kilkoma polami to sposób na kilka wyników naraz.

            

            

                
Sortowanie

                
sort(v.begin(), v.end(),
  [](const Uczen &a, const Uczen &b) {
    if (a.punkty != b.punkty)
        return a.punkty > b.punkty;
    return a.imie < b.imie;
});

                
„Czy a stoi przed b?”. Tylko < i >. Remisy: kolejne kryterium albo stable_sort.

            

            

                
Metody i wartości domyślne

                
struct Konto {
    long long saldo = 0;
    void wplac(long long x) { saldo += x; }
    bool pusto() const { return saldo == 0; }
};

                
Metoda widzi pola bez kropki. Metody, które tylko czytają, oznaczaj const.

            

            

                
Operatory

                
bool operator<(const Punkt &o) const {
    if (x != o.x) return x < o.x;
    return y < o.y;
}
set<Punkt> s; map<Punkt, int> ile;

                
Z operator< działa sort bez komparatora, set i map. const obowiązkowe.

            

            

                
Zdarzenia

                
e.push_back({we, +1});
e.push_back({wy, -1});

    teraz += z.zmiana;

Każdy przedział to dwa zdarzenia. Kolejność remisów ustal według treści zadania.

            

            

                
Przedziały i pytania

else w.push_back(p);
// pytania: struct { int x, nr; }

Najwięcej rozłącznych: sort po końcu i zachłannie. Pytania sortuj razem z numerami.

            

        


        

            Jak rozwiązywać zadania ze strukturami
            1) Przeczytaj, jakie rzeczy występują w zadaniu (uczeń, mecz, zlecenie, przedział) i jakie mają cechy — każda rzecz to struktura, każda cecha to pole. 2) Zastanów się, czy wystarczy jeden rekord w pętli (najlepszy, ostatni), czy trzeba zapamiętać wszystkie w vectorze. 3) Jeśli kolejność ma znaczenie — napisz komparator; przy remisach zawsze dodaj kryterium, które je rozstrzyga. 4) Jeśli po przestawieniu trzeba wrócić do kolejności z wejścia — numer w polu. 5) Jeśli szukasz rekordu po nazwie albo zliczasz po kluczu — mapa struktur albo operator< i set/map. 6) Duże struktury do funkcji przez const &, a liczniki w polach z wartością domyślną 0. 7) Zanim wyślesz: sprawdź remisy i wartości graniczne z treści (puste listy, jeden element, równe klucze).

        10 — Częste błędy
        
Częste błędy i dobre praktyki

        

            

                
;

                
Średnik po klamrze

                
Deklaracja struktury kończy się };. Bez średnika kompilator zgłasza expected ';' after struct definition — czasem dopiero w następnej linijce, więc szukaj go nad miejscem błędu.

            

            

                
📍

                
Najpierw deklaracja

                
Strukturę deklaruj nad main i nad funkcjami, które jej używają. Struktura użyta w innej strukturze (Punkt w Odcinek) musi stać wyżej. Inaczej: 'Uczen' was not declared in this scope.

            

            

                
🎲

                
Pola bez wartości to śmieci

                
Pola liczbowe lokalnej zmiennej bez klamer mają przypadkowe wartości — u nas raz 1651076199, raz 1. Twórz zmienne z {} albo daj polom wartości domyślne: int suma = 0;. Globalne zmienne i vector<Nazwa> v(n) mają zera.

            

            

                
🔤

                
Kolejność w klamrach

                
Wartości w klamrach trafiają do pól w kolejności deklaracji. Pomyłkę typów kompilator wyłapie, ale zamienione dwa pola int (wiek z oceną) przejdą bez słowa. Przy klamrach zawsze zerknij na deklarację.

            

            

                
📋

                
Kopia czy oryginał?

                
b = a;, push_back(a), parametr bez & i pętla for (Nazwa x : v) — wszystkie robią kopię. Chcesz zmienić oryginał: &. Chcesz tylko czytać bez kopiowania: const &.

            

            

                
⚖️

                
== i < nie działają same

                
Na strukturach nie skompiluje się a == b, a < b, max(a, b), sort bez komparatora, set ani cout << a. Porównuj pole po polu, podaj komparator albo dopisz operatory.

            

            

                
🏆

                
Rekord w pętli

                
Kopiuj cały rekord: naj = u; — wtedy nie zgubisz żadnego pola. Uważaj na remisy (> zostawia pierwszego, >= bierze ostatniego) i na start: przy dowolnych wartościach zacznij od pierwszego wczytanego rekordu.

            

            

                
🔀

                
W komparatorze tylko < albo >

                
Komparator dla równych elementów musi odpowiedzieć „nie” w obie strony. Z <= sortowanie 200 równych graczy wywróciło program z błędem SIGSEGV. Zawsze ostra nierówność.

            

            

                
🧩

                
Remisy przy sortowaniu

                
sort ustawia elementy równe według komparatora w dowolnej kolejności. Gdy zadanie mówi, co zrobić z remisami, dopisz to kryterium (imię, numer z wejścia) albo użyj stable_sort, który zostawia kolejność z wejścia.

            

            

                
🔢

                
Numer przed sortowaniem

                
Po sortowaniu indeks w vectorze nie mówi już nic o kolejności z wejścia. Zapisz numer w polu (v[i].nr = i;) przed sortowaniem — przyda się do miejsc, odpowiedzi na pytania i rozstrzygania remisów.

            

            

                
🔒

                
const przy metodach

                
Metody i operatory, które tylko czytają, oznaczaj const po nawiasach: bool operator<(const P &o) const. Bez tego set i map się nie skompilują, a metody nie da się wołać na const &.

            

            

                
🚀

                
Duże struktury przez const &

                
Struktura z napisem albo vectorem kopiuje się w całości. U nas 20 000 wywołań funkcji ze strukturą zawierającą 100 000 ocen trwało 196 ms przez wartość i 20 ms przez const &. W komparatorach i funkcjach używaj referencji.
