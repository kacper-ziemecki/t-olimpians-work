01 — Podstawy

Czym jest zmienna?

Zmienna to pudełko na dane, które program trzyma w pamięci komputera. Wkładasz do niego jedną rzecz — liczbę, znak albo tekst — i podpisujesz ją nazwą, żeby móc później po nią sięgnąć. Bez zmiennych komputer zapominałby wszystko, co przed chwilą policzył.

Każde takie pudełko opisują trzy rzeczy:

🏷️

typ

Mówi, co wolno włożyć do pudełka: liczbę całkowitą, ułamek, pojedynczy znak czy tekst. Typ podajesz raz — przy tworzeniu zmiennej — i później już się nie zmienia.

📛

nazwa

Tak wołasz swoje pudełko w kodzie. Wymyślasz ją sam — bez spacji i bez polskich znaków, np. wiek, imie, liczbaPunktow.

📦

wartość

To, co siedzi w pudełku w tej chwili. Możesz ją wypisać na ekran i w każdej chwili podmienić na inną.

zmienna.cpp
typ nazwa = wartość;

// tworzymy pudełko o nazwie wiek
int wiek = 17;
cout << wiek;   // wypisze 17

// podmieniamy zawartość — typ zostaje
wiek = 18;
cout << wiek;   // wypisze 18
▶ Zapamiętaj
Typ piszesz tylko raz — przy tworzeniu zmiennej. Potem wystarczy sama nazwa.
02 — Typy podstawowe

int, float, char, string i bool

Tych pięć typów wystarczy na pierwsze kilkadziesiąt programów. Zanim utworzysz zmienną, zadaj sobie jedno pytanie: co chcę w niej trzymać — liczbę całkowitą, liczbę z przecinkiem, pojedynczy znak, tekst czy odpowiedź „tak/nie”?

🔢

int

Liczby całkowite, czyli bez przecinka: 0, 17, -5. Pułapka: 7 / 2 daje 3, bo w int nie zmieści się połówka — reszta po prostu znika.

🌊

float

Liczby z przecinkiem, np. 4.75f. W C++ piszemy kropkę zamiast przecinka, a na końcu dodajemy literkę f. Tutaj 7 / 2.0 daje już 3.5.

🔤

char

Dokładnie jeden znak, zawsze w apostrofach: 'a', '7', '!'. Uwaga: '7' to narysowana cyfra, a nie liczba 7, którą da się dodawać.

📝

string

Cały tekst, w cudzysłowie: "Kacper". Na górze pliku dopisz #include <string>. Teksty skleja się plusem, a .length() mówi, ile mają znaków.

✅

bool

Odpowiedź „tak/nie” — mieści tylko dwie wartości: true (prawda) i false (fałsz). Poświęcamy mu całą następną sekcję.

typy_podstawowe.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int    wiek    = 17;
    float  srednia = 4.75f;
    char   ocena   = 'A';
    string imie    = "Kacper";
    bool   zdany   = true;

    cout << imie << " ma " << wiek << " lat\n";
    cout << "Srednia: " << srednia << "\n";
    cout << "Ocena:   " << ocena << "\n";
    cout << "Zdany:   " << zdany << "\n";

    return 0;
}
▶ Wyjście programu
Kacper ma 17 lat Srednia: 4.75 Ocena: A Zdany: 1

Spójrz na ostatnią linijkę wyjścia: bool wypisał się jako 1, a nie jako true. Dlaczego tak jest i co z tym zrobić — od razu w następnej sekcji.

03 — Typ bool

bool, czyli prawda albo fałsz

Poprzednie typy trzymały liczby i tekst. bool jest od nich wszystkich prostszy: mieści tylko dwie wartości — true (prawda) i false (fałsz). Nazwa pochodzi od nazwiska matematyka George’a Boole’a, ale w praktyce chodzi o coś bardzo zwyczajnego: o zapamiętanie odpowiedzi na pytanie „tak czy nie”. Czy gracz wygrał? Czy hasło się zgadza? Czy liczba jest większa od stu?

Najważniejsze jest to, że wartość typu bool powstaje sama, gdy coś porównujesz. Zapis wiek >= 18 to nie jest pytanie bez odpowiedzi — to gotowe true albo false, które możesz od razu włożyć do zmiennej.

bool.cpp
bool zdany = true;
bool pada  = false;

// porównanie samo daje true albo false
int wiek = 17;
bool pelnoletni = (wiek >= 18);

cout << zdany << "\n";
cout << pelnoletni;
▶ Wyjście programu
1 0
boolalpha.cpp
// C++ wypisuje bool jako liczbę:
// true to 1, a false to 0
cout << true << " " << false << "\n";

// boolalpha każe pisać słowami
cout << boolalpha;
cout << true << " " << false;
▶ Wyjście programu
1 0 true false

Pod spodem bool jest po prostu liczbą: true to 1, a false to 0. Dlatego cout domyślnie wypisuje cyfry, a nie słowa — i dlatego bool zajmuje w pamięci zaledwie jeden bajt.

Wartości true i false najczęściej powstają z porównań, a potem można je jeszcze łączyć ze sobą. To cała lista zapisów, których będziesz potrzebować:

ZapisCzyta sięDaje true, gdy…Przykład
a == b a równe b obie wartości są takie same 3 == 3 → true
a != b a różne od b wartości się różnią 3 != 5 → true
a < b a mniejsze od b a jest mniejsze (jest też >) 2 < 5 → true
a >= b a większe lub równe b a nie jest mniejsze (jest też <=) 5 >= 5 → true
!x nie x x jest false — odwraca odpowiedź !false → true
x && y x oraz y oba są true true && false → false
x || y x lub y przynajmniej jeden jest true true || false → true

Po co to wszystko? bool jest paliwem dla instrukcji if, którą poznasz w temacie If / Else — to ona pozwala programowi podjąć decyzję. Na razie wystarczy, że zobaczysz, jak to wygląda w praktyce:

decyzja.cpp
#include <iostream>
using namespace std;

int main() {
    int punkty = 85;

    // zmienna bool przechowuje odpowiedź na pytanie
    // "czy punktów jest co najmniej 50?"
    bool zaliczone = (punkty >= 50);

    if (zaliczone) {
        cout << "Zaliczone!";
    } else {
        cout << "Poprawka...";
    }

    return 0;
}
▶ Wyjście programu
Zaliczone!

I jeszcze jedna pułapka, na której potyka się prawie każdy na początku: = to nie to samo co ==. Pojedyncze = wkłada wartość do zmiennej, a podwójne == sprawdza, czy dwie rzeczy są równe. W porównaniach zawsze piszemy ==.

04 — const i auto

Stałe wartości i typ odgadywany przez komputer

const zamyka pudełko na klucz: wartość ustawiasz raz, przy tworzeniu zmiennej, i od tej pory nikt — nawet ty przez pomyłkę — jej nie podmieni. auto działa odwrotnie: nie podajesz typu, tylko każesz komputerowi samemu go rozpoznać po tym, co stoi po prawej stronie znaku =.

const.cpp
const int maksGraczy = 4;
const float PI = 3.14159f;

// maksGraczy = 5;  // BŁĄD kompilacji!
▶ Kiedy używać
Stałe matematyczne, ustawienia, limity — wartości, które nie powinny się zmienić.
auto.cpp
auto liczba = 10;        // int
auto ulamek = 2.5f;     // float
auto znak   = 'x';       // char
▶ Kiedy używać
Gdy typ jest oczywisty lub długi. Na początek warto pisać typy wprost — łatwiej się uczyć.
05 — Zakresy typów

Ile bajtów i jakie wartości mieści każdy typ

Każdy typ zajmuje z góry ustaloną liczbę bajtów, a więc ma też swój limit. Gdy go przekroczysz, program nie zgłosi żadnego błędu — po prostu wypisze bzdurę, często liczbę ujemną. Całej tabeli nie musisz znać na pamięć; na start zapamiętaj dwa wiersze: int i double.

TypRozmiarZakresKiedy używać
bool 1 bajt false / true Odpowiedź „tak/nie”: true albo false
char 1 bajt -128 … 127 Jeden znak: litera, cyfra albo przecinek
short 2 bajty -32 768 … 32 767 Prawie nigdy — int jest wygodniejszy
int 4 bajty -2 147 483 648 … 2 147 483 647 Twój domyślny typ na liczby całkowite
unsigned int 4 bajty 0 … 4 294 967 295 Tylko liczby nieujemne — na start omijaj
long long 8 bajtów -9,22·10^18 … 9,22·10^18 Gdy liczba przekracza 2 miliardy
unsigned long long 8 bajtów 0 … 1,84·10^19 Bardzo duże liczby nieujemne — rzadko potrzebny
float 4 bajty ~7 cyfr znaczących Mało dokładny — lepiej weź double
double 8 bajtów ~15–16 cyfr znaczących Twój domyślny typ na liczby z przecinkiem
long double 16 bajtów ~18–19 cyfr znaczących Gdy double nie wystarcza — rzadkość
string zmienny dowolna długość tekstu Tekst: imię, słowo albo całe zdanie

Zapamiętaj dwie liczby: int kończy się w okolicach 2 miliardów, a long long dopiero w okolicach 9 trylionów (czyli 9 z osiemnastoma zerami). Jeśli wynik może przekroczyć 2 miliardy — na przykład mnożysz przez siebie dwie duże liczby — od razu weź long long. Nic na tym nie tracisz.

06 — Konwersje i rzutowanie

Co się dzieje, gdy typy się mieszają

Gdy w jednym działaniu spotkają się dwa różne typy, C++ po cichu zamienia jeden na drugi. Czasem to wygodne, a czasem właśnie tu gubi się ułamek. Rzutowanie to sposób, żeby zrobić to świadomie: wstawiasz nazwę typu w nawiasie przed wartością, np. (double)a, i mówisz komputerowi „potraktuj to jak liczbę z przecinkiem”. Poniżej wszystkie przypadki, które naprawdę spotkasz na początku.

KonwersjaCo się dziejePrzykład
int → double Automatyczna, bezstratna. double x = 5; daje 5.0
double → int Ucina część ułamkową, nie zaokrągla. (int)2.9 daje 2
int / int Dzielenie całkowite — ułamek przepada. 7 / 2 daje 3
(double)a / b Wystarczy rzutować jedną z dwóch liczb. (double)7 / 2 daje 3.5
int → long long Dzieje się dopiero po obliczeniu — za późno. long long x = a * b; może już przepełnić
1LL * a * b Zmusza C++ do liczenia od razu na long long. Działa nawet dla bardzo dużych a i b
char → int Daje numer znaku w tablicy ASCII. 'a' to 97, c - '0' to cyfra
string → int stoi(s), dla większych stoll(s). stoi("42") daje 42
int → string to_string(x). to_string(42) daje "42"
pulapki.cpp
#include <iostream>
using namespace std;

int main() {
    // 1. dzielenie całkowite tam, gdzie chcieliśmy ułamek
    cout << 7 / 2 << "\n";              // 3   - nie 3.5
    cout << 7 / 2.0 << "\n";            // 3.5 - jeden składnik jako double

    // 2. przepełnienie PRZED przypisaniem
    int a = 100000, b = 100000;
    long long zle = a * b;               // liczone na int -> przepełnienie
    long long dobrze = 1LL * a * b;      // liczone na long long
    cout << zle << " " << dobrze << "\n";

    // 3. unsigned i odejmowanie
    unsigned int u = 3;
    cout << u - 5 << "\n";               // ogromna liczba, nie -2

    // 4. char to liczba
    char c = 'a';
    cout << c << " " << (int)c << "\n";  // a 97

    return 0;
}
▶ Wyjście programu
3 3.5 1410065408 10000000000 4294967294 a 97

Trzeci przypadek zaskakuje najczęściej: odejmowanie na unsigned nigdy nie da wyniku ujemnego — zamiast tego przeskakuje na drugi koniec zakresu i wychodzi ogromna liczba. Dlatego na początku trzymaj się zwykłego int i long long, a unsigned zostaw sobie na później.

07 — Przykładowe zadania

Sprawdź się na zadaniach

Sześć zadań od najprostszego. Pierwsze trzy sprawdzają, czy umiesz tworzyć zmienne i nie gubić ułamków; trzy kolejne — czy dobierasz typ zanim zaczniesz liczyć. Rozwiązania są schowane, więc najpierw spróbuj sam.

Łatwe Wizytówka
Utwórz po jednej zmiennej każdego z pięciu poznanych typów (int, double, char, string, bool), wpisz do nich cokolwiek i wypisz wszystko na ekran.
Jak to ugryźć: To zadanie na rozgrzewkę — sprawdza, czy pamiętasz składnię zapisu wartości: tekst w cudzysłowie, znak w apostrofach, ułamek z kropką, bool jako true albo false.
Pokaż rozwiązanie
wizytowka.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int    wiek    = 14;
    double wzrost  = 1.62;
    char   inicjal = 'K';
    string miasto  = "Krakow";
    bool   uczen   = true;

    cout << "Wiek:    " << wiek << "\n";
    cout << "Wzrost:  " << wzrost << "\n";
    cout << "Inicjal: " << inicjal << "\n";
    cout << "Miasto:  " << miasto << "\n";
    cout << "Uczen:   " << boolalpha << uczen << "\n";

    return 0;
}
Łatwe Zamiana zawartości
Utwórz dwie zmienne a i b z różnymi wartościami, a potem zamień ich zawartość miejscami i wypisz wynik.
Jak to ugryźć: Nie da się zrobić a = b; b = a; — po pierwszej linijce stara wartość a już nie istnieje. Potrzebujesz trzeciej zmiennej, która przechowa ją na chwilę. Dokładnie tak, jak przy przelewaniu wody między dwoma szklankami.
Pokaż rozwiązanie
zamiana.cpp
#include <iostream>
using namespace std;

int main() {
    int a = 3;
    int b = 8;

    cout << "Przed: a=" << a << " b=" << b << "\n";

    int pomocnicza = a;    // odkladamy a na bok
    a = b;                 // do a wchodzi b
    b = pomocnicza;        // do b wraca stare a

    cout << "Po:    a=" << a << " b=" << b << "\n";

    return 0;
}
Łatwe Średnia z trzech ocen
Wczytaj trzy oceny (liczby całkowite) i wypisz ich średnią z dokładnością do dwóch miejsc po przecinku.
Jak to ugryźć: Pułapka jest w dzieleniu: (a + b + c) / 3 na samych int obetnie ułamek. Rzutuj sumę na double albo podziel przez 3.0. Dwa miejsca po przecinku daje cout << fixed << setprecision(2);.
Pokaż rozwiązanie
srednia_ocen.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;

    // dzielenie przez 3.0, a nie przez 3
    double srednia = (a + b + c) / 3.0;

    cout << fixed << setprecision(2);
    cout << srednia;

    return 0;
}
Średnie Który typ wybrać
Wczytaj dwie liczby całkowite a i b (każda do miliarda) i wypisz ich iloczyn oraz iloraz z dokładnością do trzech miejsc po przecinku.
Jak to ugryźć: Miliard razy miliard to liczba z 19 cyframi, a int kończy się na 2 miliardach — potrzebujesz long long. Przy dzieleniu rzutuj na double, inaczej ułamek się zgubi.
Pokaż rozwiązanie
typy_wybor.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;

    cout << a * b << "\n";              // miesci sie w long long

    cout << fixed << setprecision(3);
    cout << (double)a / b;              // rzutowanie przed dzieleniem

    return 0;
}
Średnie Sprawdź, czy suma się zmieści
Wczytaj dwie liczby typu int i sprawdź, czy ich suma zmieści się w int. Wypisz sumę albo słowo ZA DUZO.
Jak to ugryźć: Nie dodawaj najpierw i nie sprawdzaj potem — po przekroczeniu limitu int wynik jest już nie do odratowania. Policz sumę od razu na long long i dopiero ją porównaj z INT_MAX i INT_MIN z nagłówka <climits>.
Pokaż rozwiązanie
przepelnienie.cpp
#include <iostream>
#include <climits>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    // liczymy na szerszym typie, potem sprawdzamy zakres
    long long suma = (long long)a + b;

    if (suma > INT_MAX || suma < INT_MIN) {
        cout << "ZA DUZO";
    } else {
        cout << suma;
    }

    return 0;
}
Trudne Porównywanie ułamków
Wczytaj cztery liczby całkowite a b c d i sprawdź, czy ułamek a/b jest równy c/d. Liczby sięgają miliarda.
Jak to ugryźć: Kuszące jest policzenie (double)a/b == (double)c/d, ale porównywanie double operatorem == zawodzi — ułamki są trzymane w przybliżeniu. Pomnóż na krzyż: a*d == c*b, na long long, bo iloczyn bywa ogromny.
Pokaż rozwiązanie
ulamki.cpp
#include <iostream>
using namespace std;

int main() {
    long long a, b, c, d;
    cin >> a >> b >> c >> d;

    // mnozenie na krzyz zamiast dzielenia -
    // zadnych bledow zaokraglen
    if (a * d == c * b) {
        cout << "ROWNE";
    } else {
        cout << "ROZNE";
    }

    return 0;
}
08 — Porady

Częste błędy i dobre praktyki

➗
Dzielenie int / int
Dzielenie dwóch int zawsze obcina część ułamkową: 7 / 2 to 3. Żeby dostać 3.5, jedna z liczb musi mieć przecinek: 7 / 2.0.
🔤
char vs string
char to pojedynczy znak w apostrofach: 'a'. string to napis w cudzysłowach: "a". Pomylenie ich to częsty błąd kompilacji.
✅
bool wypisuje się jako 1 i 0
cout pokazuje true jako 1, a false jako 0. Żeby zobaczyć słowa, dopisz wcześniej cout << boolalpha;.
⚖️
= to nie jest ==
Pojedyncze = wkłada wartość do zmiennej, a podwójne == sprawdza, czy dwie rzeczy są równe. W porównaniach zawsze piszemy ==.
🎯
Precyzja float
float zapamiętuje tylko 6-7 pierwszych cyfr liczby, więc przy dłuższych ułamkach zaczyna kłamać. Na co dzień używaj double — jest dokładniejszy i nie trzeba dopisywać f.
🔒
const chroni przed błędami
Oznaczanie wartości, które nie powinny się zmieniać, jako const pozwala kompilatorowi wychwycić przypadkowe nadpisanie już na etapie kompilacji.
🤖
auto nie jest osobnym typem
auto to tylko skrót — kompilator i tak zamienia go na konkretny typ (int, float, string...) już podczas kompilacji.
📏
sizeof()
Funkcja sizeof(typ) pokazuje, ile bajtów zajmuje dany typ w pamięci — przydatne przy analizie zużycia pamięci przez program.
