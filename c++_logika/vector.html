Vector — tablica, która rośnie

Tablica ma jedną irytującą wadę: jej rozmiar musisz znać, zanim napiszesz program. Vector tego nie wymaga — rośnie w trakcie i sam pamięta, ile ma elementów.

01 — Podstawy

Czym vector bije zwykłą tablicę

Pamiętasz z tematu o tablicach, że trzeba było deklarować je z zapasem — int t[1000], choć używałeś może dziesięciu pudełek? I że rozmiar trzeba było trzymać w osobnej zmiennej n, bo tablica sama go nie znała? vector załatwia oba te problemy.

tablica.cpp
// tablica: rozmiar z gory, n osobno
int t[1000];
int n = 0;

t[n] = 10;  n++;
t[n] = 20;  n++;
t[n] = 30;  n++;

for (int i = 0; i < n; i++) {
    cout << t[i] << " ";
}
▶ Wyjście programu
10 20 30
vector.cpp
#include <vector>
// vector: rosnie sam, zna swoj rozmiar
vector<int> v;

v.push_back(10);
v.push_back(20);
v.push_back(30);

for (int i = 0; i < v.size(); i++) {
    cout << v[i] << " ";
}
▶ Wyjście programu
10 20 30

Zapis vector<int> czyta się jako „wektor liczb całkowitych”. W nawiasach ostrokątnych podajesz typ elementów — może to być vector<string>, vector<double>, a nawet vector<pair<int,int>>. Nagłówek: #include <vector>.

📦

vector<int> v;

Pusty wektor. Na starcie ma zero elementów.

➕

v.push_back(x)

Dokłada x na koniec. Wektor rośnie o jeden.

📏

v.size()

Ile elementów. Nie musisz trzymać n osobno.

🎯

v[i]

Element na pozycji i, licząc od zera — dokładnie jak w tablicy.

🆕

vector<int> v(n);

Wektor od razu z n zerami. Tu n może być zmienną!

🗑️

v.clear()

Usuwa wszystko. Po tym v.size() to zero.

podstawy.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    // rozmiar z wejscia - w tablicy sie nie da!
    vector<int> v(n);

    for (int i = 0; i < n; i++) {
        cin >> v[i];
    }

    cout << "Elementow: " << v.size() << "\n";

    v.push_back(999);           // dokladamy jeszcze jeden
    cout << "Teraz: " << v.size() << "\n";
    cout << "Ostatni: " << v[v.size() - 1];

    return 0;
}
▶ Wyjście programu
Wejście: 3 10 20 30 Elementow: 3 Teraz: 4 Ostatni: 999

Dostęp przez v[i] jest równie szybki jak w tablicy — elementy leżą w pamięci obok siebie, dokładnie tak samo. Nie tracisz nic na wygodzie, a zyskujesz size(), push_back i rozmiar ustalany w trakcie działania.

02 — Najważniejsze metody

Sześć rzeczy, które będziesz robić

Metody wektora są krótkie i mówią same za siebie. Poniżej te, które wystarczą na pierwsze kilkadziesiąt zadań — reszta i tak przyjdzie z czasem.

dodawanie.cpp
vector<int> v;

v.push_back(5);
v.push_back(3);
v.push_back(8);
cout << v.size() << "\n";      // 3

v.pop_back();                  // usuwa ostatni
cout << v.size() << "\n";      // 2

if (!v.empty()) {
    cout << "cos jest w srodku\n";
}

v.clear();
cout << v.size();              // 0
▶ Wyjście programu
3 2 cos jest w srodku 0
przegladanie.cpp
vector<int> v = {4, 8, 15, 16, 23};

// wersja z indeksem
for (int i = 0; i < v.size(); i++) {
    cout << v[i] << " ";
}
cout << "\n";

// wersja krotsza - gdy indeks nie jest
// do niczego potrzebny
for (int x : v) {
    cout << x << " ";
}
▶ Wyjście programu
4 8 15 16 23 4 8 15 16 23

Zapis for (int x : v) to ta „krótsza pętla”, o której wspominaliśmy przy temacie for. Czyta się go jako „dla każdego x z v”. Używaj go, gdy potrzebujesz tylko wartości; gdy potrzebujesz też numeru pozycji, wróć do pętli z indeksem.

Uwaga: w tej krótszej pętli x jest kopią elementu. Zmiana x nie zmieni tego, co siedzi w wektorze. Żeby naprawdę modyfikować zawartość, napisz for (int& x : v) — ten ampersand znaczy „pracuj na oryginale”.

kopia_czy_oryginal.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3};

    // kopia - wektor sie nie zmieni
    for (int x : v) x = x * 10;
    for (int x : v) cout << x << " ";
    cout << "\n";

    // oryginal - wektor SIE zmieni
    for (int& x : v) x = x * 10;
    for (int x : v) cout << x << " ";

    return 0;
}
▶ Wyjście programu
1 2 3 10 20 30
03 — Vector 2D

Plansza o wymiarach z wejścia

Skoro wektor może trzymać cokolwiek, może też trzymać inne wektory. Tak powstaje tabelka — dokładnie jak tablica dwuwymiarowa, tylko że jej wymiary mogą pochodzić z wejścia.

Zapis wygląda groźnie, ale znaczy prostą rzecz: vector<vector<int>> t(n, vector<int>(m)) to „n wierszy, każdy po m zer”.

plansza.cpp
#include <vector>

int n, m;
cin >> n >> m;

// n wierszy po m zer
vector<vector<int>> t(n, vector<int>(m));

for (int w = 0; w < n; w++) {
    for (int k = 0; k < m; k++) {
        cin >> t[w][k];
    }
}

cout << "Lewy gorny: " << t[0][0] << "\n";
cout << "Prawy dolny: " << t[n-1][m-1];
▶ Wyjście programu
Wejście: 2 3 1 2 3 4 5 6 Lewy gorny: 1 Prawy dolny: 6
wypisanie.cpp
vector<vector<int>> t = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int w = 0; w < t.size(); w++) {
    for (int k = 0; k < t[w].size(); k++) {
        cout << t[w][k] << " ";
    }
    cout << "\n";
}
▶ Wyjście programu
1 2 3 4 5 6

Zwróć uwagę na t[w].size() w prawym przykładzie: każdy wiersz zna swoją długość osobno. Przy zwykłej tablicy musiałbyś pamiętać m w osobnej zmiennej.

Jedna rzecz na koniec, o której warto wiedzieć od początku. Gdy przekazujesz wektor do własnej funkcji, domyślnie zostaje skopiowany — cały, element po elemencie. Dla dziesięciu liczb to nieistotne, dla miliona już zauważysz. Ampersand przy nazwie parametru oznacza „pracuj na oryginale, nie kopiuj”.

funkcje.cpp
#include <iostream>
#include <vector>
using namespace std;

// & = bez kopiowania, mozna zmieniac
void dodajDoWszystkich(vector<int>& v, int ile) {
    for (int& x : v) x += ile;
}

// const & = bez kopiowania, tylko odczyt
int suma(const vector<int>& v) {
    int s = 0;
    for (int x : v) s += x;
    return s;
}

int main() {
    vector<int> v = {1, 2, 3};

    dodajDoWszystkich(v, 10);
    for (int x : v) cout << x << " ";

    cout << "\nSuma: " << suma(v);
    return 0;
}
▶ Wyjście programu
11 12 13 Suma: 36
04 — Ściąga

Wszystko, co robi się z wektorem

Dwanaście zapisów, które pokrywają praktycznie wszystko, co będziesz robić z wektorem przez najbliższe miesiące.

ZapisCo robiUwaga
vector<int> v; Pusty wektor liczb całkowitych. Zero elementów na starcie
vector<int> v(n); Wektor n zer. n może być zmienną
vector<int> v(n, 7); Wektor n siódemek. Drugi argument to wartość startowa
vector<int> v = {1,2,3}; Wektor z gotową zawartością. —
v.push_back(x) Dokłada x na koniec. Wektor rośnie o jeden
v.pop_back() Usuwa ostatni element. Nic nie zwraca
v.size() Liczbę elementów. Nie trzymaj n osobno
v.empty() Prawdę, gdy wektor jest pusty. Czytelniejsze niż size() == 0
v.clear() Usuwa wszystkie elementy. size() spada do zera
v[i] Element na pozycji i. Numerowanie od zera
for (int x : v) Przechodzi po wartościach. x to kopia
for (int& x : v) Przechodzi po oryginałach. Zmiany trafiają do wektora
sort(v.begin(), v.end()) Sortuje rosnąco. Z nagłówka <algorithm>

Dwa ostatnie wiersze to najczęstsze źródło zdziwienia. for (int x : v) daje kopię — zmiany przepadają. for (int& x : v) daje oryginał — zmiany zostają. Jeden znak robi całą różnicę.

05 — Przykładowe zadania

Sprawdź się na zadaniach

Sześć zadań od najprostszego. Wszystkie korzystają z tego, czego tablica nie potrafi: rozmiaru poznanego dopiero w trakcie działania programu. Najpierw spróbuj sam.

Łatwe Wczytaj i wypisz od tyłu
Wczytaj n, potem n liczb, i wypisz je w odwrotnej kolejności.
Jak to ugryźć: Ten sam schemat co przy tablicach, tylko że tu możesz napisać vector<int> v(n); i nie zgadywać maksymalnego rozmiaru.
Pokaż rozwiązanie
od_tylu.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> v(n);
    for (int i = 0; i < n; i++) {
        cin >> v[i];
    }

    for (int i = n - 1; i >= 0; i--) {
        cout << v[i] << " ";
    }

    return 0;
}
Łatwe Tylko parzyste
Wczytuj liczby aż do końca danych. Wypisz najpierw wszystkie parzyste, a potem wszystkie nieparzyste — w kolejności, w jakiej się pojawiły.
Jak to ugryźć: Dwa wektory i push_back do właściwego. Nie musisz z góry wiedzieć, ile będzie jednych i drugich — i to jest cały sens wektora.
Pokaż rozwiązanie
parzyste_nieparzyste.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> parzyste;
    vector<int> nieparzyste;

    int x;
    while (cin >> x) {
        if (x % 2 == 0) parzyste.push_back(x);
        else            nieparzyste.push_back(x);
    }

    for (int y : parzyste)    cout << y << " ";
    cout << "\n";
    for (int y : nieparzyste) cout << y << " ";

    return 0;
}
Łatwe Podwój każdy element
Wczytaj n liczb, pomnóż każdą przez 2 wewnątrz wektora, a dopiero potem wypisz.
Jak to ugryźć: Tu właśnie potrzebny jest ampersand: for (int& x : v) x *= 2;. Bez niego zmieniałbyś kopie i wektor zostałby bez zmian.
Pokaż rozwiązanie
podwoj.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> v(n);
    for (int i = 0; i < n; i++) cin >> v[i];

    for (int& x : v) {
        x *= 2;                // & = zmieniamy oryginal
    }

    for (int x : v) cout << x << " ";
    return 0;
}
Średnie Usuń duplikaty
Wczytaj n liczb i wypisz je bez powtórzeń, zachowując kolejność pierwszych wystąpień.
Jak to ugryźć: Buduj drugi wektor z wynikiem. Dla każdej nowej liczby przejdź pętlą po tym, co już masz, i sprawdź, czy jej tam nie ma. Jeśli nie ma — push_back. Prosto, choć nie najszybciej.
Pokaż rozwiązanie
duplikaty.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> wynik;

    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;

        bool juzJest = false;
        for (int y : wynik) {
            if (y == x) { juzJest = true; break; }
        }

        if (!juzJest) wynik.push_back(x);
    }

    for (int x : wynik) cout << x << " ";
    return 0;
}
Średnie Mediana
Wczytaj n liczb i wypisz medianę, czyli wartość środkową po posortowaniu. Przy parzystej liczbie elementów wypisz średnią dwóch środkowych.
Jak to ugryźć: Posortuj wektor jedną linijką sort(v.begin(), v.end()). Dla nieparzystego n mediana to v[n/2]; dla parzystego średnia z v[n/2 - 1] i v[n/2] — pamiętaj o dzieleniu przez 2.0.
Pokaż rozwiązanie
mediana.cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <iomanip>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> v(n);
    for (int i = 0; i < n; i++) cin >> v[i];

    sort(v.begin(), v.end());

    cout << fixed << setprecision(1);

    if (n % 2 == 1) {
        cout << (double)v[n / 2];
    } else {
        cout << (v[n/2 - 1] + v[n/2]) / 2.0;
    }

    return 0;
}
Trudne Obróć planszę
Wczytaj tabelkę n × m i wypisz ją obróconą: pierwsza kolumna oryginału ma stać się pierwszym wierszem wyniku.
Jak to ugryźć: Wynik ma wymiary m × n — odwrotnie niż wejście. Utwórz drugi wektor dwuwymiarowy o tych wymiarach i przepisz: wynik[k][w] = t[w][k]. Cała sztuka to zamiana indeksów miejscami.
Pokaż rozwiązanie
obroc.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    vector<vector<int>> t(n, vector<int>(m));
    for (int w = 0; w < n; w++)
        for (int k = 0; k < m; k++)
            cin >> t[w][k];

    // uwaga: wymiary odwrotnie!
    vector<vector<int>> wynik(m, vector<int>(n));

    for (int w = 0; w < n; w++)
        for (int k = 0; k < m; k++)
            wynik[k][w] = t[w][k];

    for (int w = 0; w < m; w++) {
        for (int k = 0; k < n; k++) {
            cout << wynik[w][k] << " ";
        }
        cout << "\n";
    }

    return 0;
}
06 — Porady

Częste błędy i dobre praktyki

📏
size() zamiast osobnego n
Wektor sam pamięta swój rozmiar. v.size() zawsze mówi prawdę — nawet po push_back i pop_back.
🚨
v[i] nie sprawdza zakresu
Tak jak w tablicy: sięgnięcie poza koniec nie zgłosi błędu, tylko przeczyta przypadkową pamięć. v[v.size()] już nie istnieje.
➕
push_back dokłada, nie nadpisuje
Żeby zmienić istniejący element, użyj v[i] = x. push_back zawsze dokłada nowy na koniec.
🔗
Ampersand przy funkcjach
void f(vector<int>& v) pracuje na oryginale, void f(vector<int> v) na kopii. Przy dużych danych pierwsza wersja jest wyraźnie szybsza.
🔄
Kopia w krótkiej pętli
for (int x : v) daje kopię elementu — zmiany przepadają. Do modyfikacji potrzebne jest for (int& x : v).
⚠️
Nie dokładaj podczas przechodzenia
push_back w środku pętli po tym samym wektorze potrafi zepsuć przechodzenie albo zapętlić program w nieskończoność.
