Do tej pory każda instrukcja w Twoim programie wykonywała się co najwyżej raz. Co już umiesz i czego się nauczysz

Ta lekcja zakłada, że przerobiłeś lekcje Typy zmiennych, Input / Output i If / Else. Umiesz więc tworzyć zmienne i zmieniać ich wartość (także skrótami i++, i--, suma += x), wczytywać dane przez cin, wypisywać wyniki przez cout i podejmować decyzje instrukcją if. Najważniejsze z tego wszystkiego będą warunki: pętla while używa dokładnie takich samych warunków jak if — porównań <, <=, ==, != i operatorów &&, ||, !.

Różnica jest jedna, ale ogromna: if sprawdza warunek raz i wykonuje swoje klamry co najwyżej jeden raz. while sprawdza warunek wiele razy i wykonuje klamry tak długo, jak warunek jest prawdziwy — może to być 5 razy, milion razy albo ani razu.

Uczymy się tak samo jak poprzednio: przepisuj przykłady do swojego edytora i uruchamiaj je, przy pytaniach „Co wypisze program?” najpierw śledź program w głowie (albo na kartce), a dopiero potem sprawdzaj odpowiedź, i po każdej części rób ćwiczenia w sprawdzarce. Lekcja jest długa — nie przerabiaj jej za jednym razem. Pętle to najważniejszy temat całego początku nauki programowania, więc warto poświęcić mu kilka dni.

01 — Pierwsza pętla

while — powtarzaj, dopóki…

Wyobraź sobie zadanie: wypisz liczby od 1 do 5. Z tym, co już umiesz, napiszesz pięć instrukcji cout. Działa. A gdyby trzeba było wypisać liczby od 1 do 1000? Albo od 1 do n, gdzie n wczytujesz z klawiatury i nie wiesz z góry, ile wyniesie? Tu kończą się możliwości programu, który czyta się od góry do dołu i każdą linijkę wykonuje raz.

Potrzebujemy instrukcji, która mówi: „wykonuj ten kawałek kodu tak długo, jak warunek jest prawdziwy”. To właśnie pętla while (po angielsku „dopóki”, czytaj: „łajl”). W zwykłym języku mówisz tak często: „dopóki talerz nie jest pusty, jedz”, „dopóki nie dojdziesz do końca strony, czytaj”.

bez_petli.cpp
cout << 1 << "\n";
cout << 2 << "\n";
cout << 3 << "\n";
cout << 4 << "\n";
cout << 5 << "\n";
// ...a dla 1000 liczb? 1000 linijek?
▶ Wyjście
1 2 3 4 5
z_petla.cpp
int i = 1;
while (i <= 5) {
    cout << i << "\n";
    i++;
}
// dla 1000 liczb zmieniasz tylko 5 na 1000
▶ Wyjście
1 2 3 4 5

Oba programy wypisują to samo. Ale ten z prawej ma zawsze 5 linijek — niezależnie od tego, czy liczb jest 5, 1000 czy miliard. Zanim zobaczysz, jak dokładnie działa, przyjrzyj się jego budowie.

Jak wygląda pętla while

schemat_while.cpp
while (warunek) {
    // ciało pętli: te instrukcje wykonują się
    // raz za razem, dopóki warunek jest prawdziwy
}
❓

warunek w nawiasie

Dokładnie taki sam jak w if: porównanie, które daje true albo false, np. i <= 5. Program sprawdza go przed każdym obrotem pętli.

🔁

ciało pętli w klamrach

Instrukcje między { a }. Jedno wykonanie ciała nazywamy obrotem pętli (albo iteracją). Po każdym obrocie program wraca na górę, do warunku.

🔢

licznik

Zmienna i liczy obroty. Tworzymy ją przed pętlą, a w ciele zmieniamy (i++), żeby warunek kiedyś przestał być prawdziwy.

🚪

wyjście z pętli

Gdy warunek okaże się fałszywy, program nie wchodzi do klamer, tylko przeskakuje za nie i idzie dalej — tak jak przy fałszywym if.

liczenie.cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;
    while (i <= 5) {
        cout << i << "\n";
        i++;
    }
    cout << "Koniec!\n";
    return 0;
}
▶ Wyjście
1 2 3 4 5 Koniec!
Najważniejsza jest przerywana strzałka: po wykonaniu ciała program nie idzie dalej, tylko wraca do warunku. Wyjść z pętli może jedynie drogą „NIE”.

Prześledźmy pętlę obrót po obrocie

Pętlę rozumie się dopiero wtedy, gdy raz albo dwa razy „wykonasz” ją w głowie — dokładnie tak, jak robi to komputer. Weź kartkę i zapisuj, jaką wartość ma i w chwili sprawdzania warunku, co wychodzi z warunku i co program robi dalej. Dla programu liczenie.cpp wygląda to tak:

Po drugie, po pętli zmienna i ma wartość 6, a nie 5: zwiększyliśmy ją jeszcze w ostatnim obrocie. Po trzecie, Koniec! wypisuje się tylko raz, bo stoi za klamrami pętli.

Zapamiętaj Pętla while działa w kółko według jednego przepisu: sprawdź warunek → jeśli prawdziwy, wykonaj ciało i wróć do sprawdzania → jeśli fałszywy, wyjdź za klamry. To, co jest w klamrach, może wykonać się wiele razy. To, co jest za klamrami, wykonuje się raz — dopiero po zakończeniu pętli.

Odliczanie w dół

Licznik nie musi rosnąć. Gdy zaczniemy od n i będziemy go zmniejszać przez i--, dostaniemy odliczanie. Warunek też się zmienia: kręcimy się, dopóki licznik jest większy od zera:

odliczanie.cpp
int n;
cin >> n;
int i = n;
while (i > 0) {
    cout << i << "... ";
    i--;
}
cout << "Start!\n";

Zamiast tworzyć osobną zmienną i, można też zmniejszać samo n — while (n > 0) { cout << n << " "; n--; }. Działa tak samo, tylko po pętli w n zostaje 0 i pierwotnej wartości już nie mamy. Jeśli będzie potrzebna później, pracuj na kopii.

Powtórz coś n razy

Czasem licznik w ogóle nie jest wypisywany — służy tylko do tego, żeby pętla wykonała się określoną liczbę razy. Taki schemat wygląda zwykle tak: licznik od 0, warunek i < n:

n_razy.cpp
int n;
cin >> n;
int i = 0;
while (i < n) {
    cout << "Hip hip hura!\n";
    i++;
}

Dlaczego to daje dokładnie n obrotów? Licznik przyjmuje po kolei wartości 0, 1, 2, …, n − 1 — to jest właśnie n różnych liczb. Gdy dojdzie do n, warunek i < n przestaje być prawdziwy.

Ten sam efekt da start od 1 i warunek i <= n (wartości 1, 2, …, n). Obie wersje są dobre — ważne, żeby start i warunek do siebie pasowały. Start od 0 z warunkiem i <= n dałby o jeden obrót za dużo. Do tego jeszcze wrócimy.

Pętla i if razem

W klamrach pętli może stać każda instrukcja, którą znasz — także if. Wtedy w każdym obrocie program podejmuje decyzję od nowa. Na przykład: wypisz liczby od 1 do 10, ale przy liczbach parzystych dopisz gwiazdkę:

gwiazdki.cpp
int i = 1;
while (i <= 10) {
    cout << i;
    if (i % 2 == 0) {
        cout << "*";
    }
    cout << " ";
    i++;
}
cout << "\n";

02 — Budowa pętli

Start, warunek i zmiana

Przyjrzyj się jeszcze raz pętlom z poprzedniej części. Każda z nich miała te same trzy elementy, i to nie przypadek — bez któregokolwiek z nich pętla się psuje. Zanim przejdziemy dalej, nauczmy się je rozpoznawać i dobierać.

1️⃣

Start — przed pętlą

Zmienna z warunku musi istnieć i mieć wartość, zanim program pierwszy raz sprawdzi warunek: int i = 1;.

2️⃣

Warunek — w nawiasie

Mówi, kiedy pętla ma się jeszcze kręcić: i <= n. Gdy przestaje być prawdziwy, pętla się kończy.

3️⃣

Zmiana — w ciele

Coś w klamrach musi zmieniać zmienną z warunku tak, żeby warunek kiedyś stał się fałszywy: i++.

trzy_elementy.cpp
int n = 4;
int i = 1;            // 1. start
while (i <= n) {      // 2. warunek
    cout << i << " ";
    i++;              // 3. zmiana
}
▶ Wyjście
1 2 3 4

Ciekawy jest przykład z odliczaniem co trzy. Po liczbie 2 licznik zmienia się na −1 i warunek i > 0 jest fałszywy. Pętla nie trafiła w zero, ale to nie problem: warunek „większe od zera” zatrzymuje ją w dobrym miejscu. Gdyby warunek brzmiał i != 0, licznik przeskoczyłby zero i pętla nigdy by się nie zatrzymała! Dlatego w warunkach pętli wolimy <, <=, >, >= niż !=.

A potęgi dwójki pokazują, że licznik nie musi rosnąć równo: 1, 2, 4, 8, … Po 64 jest 128, a 128 <= 100 to już fałsz.

Ile razy wykona się pętla?

To pytanie zadawaj sobie przy każdej pętli, którą piszesz. Najczęstszy błąd początkujących (i nie tylko) to pętla, która wykonuje się o jeden raz za dużo albo za mało. Ma nawet swoją nazwę: błąd o jeden (po angielsku off-by-one). Popatrz, jak drobna zmiana startu albo warunku zmienia liczbę obrotów:

03 — Licznik, suma i iloczyn

Zmienna, która zbiera wynik

Do tej pory pętle głównie wypisywały. Bardzo często chcemy jednak, żeby pętla coś policzyła i dała jeden wynik na końcu: sumę, liczbę pasujących elementów, iloczyn. Do tego służy zmienna, którą nazwiemy akumulatorem (od „akumulować” — gromadzić). Działa jak skarbonka: przed pętlą jest pusta, w każdym obrocie coś do niej wrzucamy, a po pętli zaglądamy, ile się uzbierało.

Schemat akumulatora Przed pętlą — utwórz zmienną i nadaj jej wartość startową. W pętli — dorzucaj do niej kolejne wartości. Po pętli — wypisz wynik. Ten schemat zobaczysz w setkach zadań.

Suma tylko niektórych liczb

Gdy w ciele pętli postawisz if, możesz dokładać do sumy tylko liczby, które spełniają jakiś warunek. Pętla przechodzi po wszystkich, ale skarbonka dostaje tylko wybrane:

Uwaga na miejsce i++: stoi poza klamrami if, więc wykonuje się w każdym obrocie. Gdyby wpadło do środka if, licznik zatrzymałby się na pierwszej nieparzystej liczbie i pętla kręciłaby się bez końca.

Tu akurat da się prościej — licznik od 2 i i += 2 — ale schemat „pętla po wszystkich + if” działa dla każdego warunku, także takiego, którego nie da się zastąpić sprytnym krokiem.

Licznik warunkowy: ile jest takich liczb?

Licznik to też akumulator, tylko zamiast dokładać liczbę, dokładasz jedynkę — za każdym razem, gdy warunek jest spełniony. Ile liczb od 1 do n dzieli się przez 7 albo kończy się cyfrą 7?

int n;

    if (i % 7 == 0 || i % 10 == 7) {
        ile++;
    }
    i++;
}
cout << ile << "\n";

▶ Wyjście

Gdybyś napisał dwa osobne if-y, każdy z własnym ile++, siódemka zostałaby policzona dwa razy i wyszłoby 7. Przy licznikach zawsze zastanów się, czy jeden element może pasować do kilku warunków.

04 — Wczytywanie w pętli

Wiele danych, jedna zmienna

Największa liczba — rekord

Jak znaleźć największą z n liczb, nie pamiętając ich wszystkich? Tak samo jak sędzia na zawodach w skoku w dal: trzyma w głowie dotychczasowy rekord. Po każdym skoku porównuje: jeśli nowy skok jest dłuższy, rekord się zmienia. Po ostatnim skoku rekord jest wynikiem całych zawodów.

Jedno pytanie: od czego zacząć rekord? Najbezpieczniej od pierwszej wczytanej liczby — ona na pewno jest w danych. Wczytujemy ją przed pętlą, a pętla przechodzi po pozostałych n − 1 liczbach:

Najwygodniejszy przypadek: nie ma n, nie ma zera na końcu — liczby po prostu się kończą. Wtedy używamy specjalnego warunku while (cin >> x). W sprawdzarce dane są zapisane w pliku i naprawdę się kończą. Gdy uruchamiasz taki program u siebie i wpisujesz liczby z klawiatury, program czeka na kolejne bez końca. Koniec danych zgłaszasz kombinacją Ctrl + Z, a potem Enter (Windows) albo Ctrl + D (Linux, macOS).

Trzy sposoby wczytywania w pętli — który kiedy? Jest n na początku → licznik od 0 do n i cin >> x w ciele. Dane kończą się umówioną wartością → wczytaj przed pętlą i na końcu obrotu, warunek x != 0. 06 — Aż do skutku

Pętla, która sama wie, kiedy skończyć

07 — Sterowanie pętlą

Zwykła pętla while sprawdza warunek tylko w jednym miejscu — na górze, przed każdym obrotem. 08 — Pętla w pętli

Pętla w pętli: wiersze i kolumny

W ciele pętli może stać dowolna instrukcja — także druga pętla. Mówimy wtedy o pętli zewnętrznej i wewnętrznej (albo o pętlach zagnieżdżonych). Działa to jak zegar: wskazówka minutowa robi pełne okrążenie, zanim godzinowa przesunie się o jedną kreskę. Tu: wewnętrzna pętla wykonuje wszystkie swoje obroty w każdym jednym obrocie zewnętrznej.

Najłatwiej zobaczyć to na rysunkach z gwiazdek. Zewnętrzna pętla liczy wiersze, a wewnętrzna — gwiazdki w wierszu, czyli kolumny.

        k++;

Choinka — dwie wewnętrzne pętle po kolei

W jednym obrocie zewnętrznej pętli możesz mieć kilka wewnętrznych, jedna po drugiej. Choinka o wysokości n: w wierszu w najpierw n − w spacji (żeby przesunąć gwiazdki na środek), a potem 2 · w − 1 gwiazdek. Rozpisz sobie wiersze dla n = 4: (3 spacje, 1 gwiazdka), (2, 3), (1, 5), (0, 7).

        k++;

        k++;

Czas sprawdzić je na zadaniach, które łączą kilka z nich naraz. Zadania są ułożone od najłatwiejszego do najtrudniejszego: najpierw rozgrzewka z jedną pętlą, potem zadania średnie — symulacje, rekordy, liczby pierwsze, system dwójkowy — a na końcu trudne, z rozkładem na czynniki, trójkątem Pascala i wielkim finałem, w którym przydaje się wszystko naraz.

Przy każdym zadaniu widać, jakich zagadnień używa — także tych z poprzednich lekcji, jak long long, setprecision, dane typu 12:30 czy else if. Jeśli coś brzmi obco, wróć do odpowiedniej części — mapa lekcji jest na górze strony.

Jak rozwiązywać zadania z pętlami 1) Przeczytaj opis wejścia: czy jest n, czy dane kończą się umówioną wartością, czy po prostu się kończą? To wybiera rodzaj pętli. 2) Ustal, co ma przetrwać między obrotami (licznik, suma, rekord, poprzednia liczba) — te zmienne tworzysz przed pętlą. 3) Opisz słowami jeden obrót: co wczytuję, co sprawdzam, co zmieniam. 4) Zastanów się, kiedy pętla ma się skończyć, i sprawdź pierwszy i ostatni obrót na małym przykładzie. 5) Przetestuj skrajności: najmniejsze dane, największe dane (zakres typów!), liczby ujemne. Wskazówka przy każdym zadaniu pomoże, gdy utkniesz.

10 — Częste błędy

Częste błędy i dobre praktyki

♾️
Program „wisi”
Warunek nigdy nie staje się fałszywy: brak zmiany licznika, zmiana w złą stronę albo licznik przeskakujący wartość z !=. Ctrl + C przerywa program.
🚫
Bez średnika po while
while (i <= n); to pusta pętla, która kręci się w nieskończoność. Po nawiasie od razu otwierasz klamrę.
1️⃣
Błąd o jeden
Ustal pierwszą i ostatnią wartość licznika. i = 0; i < n i i = 1; i <= n dają n obrotów, ale i = 0; i <= n — już n + 1.
📦
Akumulator przed pętlą
Suma i licznik od 0, iloczyn od 1 — ustawione przed pętlą. Utworzone w klamrach znikają i zerują się w każdym obrocie.
🖨️
Wynik po pętli
Jeśli zadanie chce jednej liczby, cout stoi za klamrami pętli. W środku wypisałbyś wszystkie wyniki pośrednie.
🏆
Maksimum od pierwszej liczby
Rekord zaczynaj od pierwszej wczytanej liczby, a nie od 0 — dla samych liczb ujemnych 0 byłoby złą odpowiedzią.
📏
long long w pętlach
Sumy, iloczyny, silnie i potęgi szybko przekraczają 2 miliardy. Zastanów się, jak duży może być wynik, a także d * d w warunku.
🧬
Kopia przed rozbieraniem
Pętla n /= 10 zostawia w n zero. Jeśli oryginał będzie potrzebny później (palindrom!), pracuj na kopii.
⏭️
continue a licznik
W while instrukcja continue przeskakuje resztę ciała — także i++ na jego końcu. Zwiększaj licznik na początku obrotu.
🔁
Zeruj wewnętrzny licznik
W pętli w pętli licznik wewnętrznej ustawiasz na start wewnątrz zewnętrznej, tuż przed wewnętrzną — inaczej drugi wiersz będzie pusty.
📥
while (cin >> x)
Gdy nie wiesz, ile będzie danych, czytaj do końca wejścia. Na swoim komputerze zakończysz wpisywanie klawiszami Ctrl + Z i Enter (Windows) albo Ctrl + D.
🧪
Testuj skrajności
Sprawdź program dla n = 0, n = 1, dla największych danych z treści i dla liczb ujemnych. Tam wychodzą błędy o jeden, przepełnienia i pętle bez końca.
