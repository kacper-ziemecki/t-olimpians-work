Pętla while w C++

Komputer nie nudzi się powtarzaniem. while pozwala mu wykonać ten sam kod setki razy — tak długo, jak warunek jest prawdziwy.

01 — Podstawy

Po co komu pętla?

Wyobraź sobie, że chcesz wypisać liczby od 1 do 100. Da się to zrobić setką linijek cout — tylko po co, skoro komputer potrafi powtarzać? Pętla to instrukcja, która mówi: „wykonaj ten kawałek kodu jeszcze raz, i jeszcze raz, dopóki…”.

Pętla while sprawdza warunek przed każdym obrotem. Prawda → wykonuje kod w klamrach i wraca do sprawdzenia. Fałsz → kończy pętlę i program leci dalej. Warunek budujesz dokładnie tak samo jak w if.

bez_petli.cpp
// tak sie NIE robi
cout << 1 << " ";
cout << 2 << " ";
cout << 3 << " ";
cout << 4 << " ";
cout << 5 << " ";

// ...i tak jeszcze 95 razy
▶ Wyjście programu
1 2 3 4 5
z_petla.cpp
// to samo w trzech linijkach
int i = 1;

while (i <= 5) {
    cout << i << " ";
    i++;              // i rosnie o 1
}
▶ Wyjście programu
1 2 3 4 5

Prześledź drugi program palcem po linijkach. i startuje z jedynką. Warunek i <= 5 jest prawdziwy, więc program wypisuje 1 i zwiększa i do dwójki. Sprawdza warunek jeszcze raz — nadal prawda — wypisuje 2… Przy i równym 6 warunek staje się fałszywy i pętla się kończy. Kod wykonał się pięć razy.

02 — Budowa pętli

Trzy rzeczy, bez których pętla się zepsuje

Każda działająca pętla while ma te same trzy elementy. Zapomnienie o którymkolwiek kończy się albo pętlą, która kręci się w nieskończoność, albo taką, która nie wykona się ani razu.

1️⃣

Start przed pętlą

Zmienna z warunku musi istnieć i mieć wartość zanim zaczniesz pętlę. int i = 1; — to jest ten start.

2️⃣

Warunek w nawiasie

Zwykłe porównanie, jak w if. Dopóki jest prawdziwe, pętla się kręci.

3️⃣

Zmiana w środku

Coś w ciele pętli musi przybliżać warunek do fałszu — najczęściej i++. Bez tego program zawiśnie.

🚨

Pętla nieskończona

Gdy program „wisi” i nic nie wypisuje, w 9 na 10 przypadków zapomniałeś o punkcie trzecim. Przerwij go klawiszami Ctrl + C.

odliczanie.cpp
#include <iostream>
using namespace std;

int main() {
    int i = 5;              // 1. start

    while (i > 0) {         // 2. warunek
        cout << i << " ";
        i--;                // 3. zmiana
    }

    cout << "\nStart!";
    return 0;
}
▶ Wyjście programu
5 4 3 2 1 Start!

Zapis i++ to skrót od i = i + 1, a i-- od i = i - 1. Zobaczysz je w niemal każdej pętli, jaką napiszesz.

03 — Licznik i suma

Dwa wzorce, które zobaczysz wszędzie

Większość pętli, jakie napiszesz na początku, robi jedną z dwóch rzeczy: liczy, ile razy coś zaszło, albo sumuje kolejne wartości. Oba wzorce wyglądają tak samo: zmienna ustawiona na zero przed pętlą i zmieniana w środku.

licznik.cpp
// ile liczb podal uzytkownik?
int ile = 0;              // licznik startuje od 0
int x;

while (cin >> x) {
    ile++;                // +1 za kazda liczbe
}

cout << "Podales " << ile << " liczb";
▶ Wyjście programu
Wejście: 4 8 15 16 Podales 4 liczb
suma.cpp
// ile to razem?
int suma = 0;             // suma startuje od 0
int x;

while (cin >> x) {
    suma += x;            // dokladamy wartosc
}

cout << "Razem: " << suma;
▶ Wyjście programu
Wejście: 4 8 15 16 Razem: 43

Zapis suma += x to skrót od suma = suma + x. Najważniejsze jest ustawienie zmiennej na zero przed pętlą — gdybyś tego nie zrobił, dokładałbyś do losowej wartości, która akurat leżała w pamięci.

Warunek while (cin >> x) czyta się jako „dopóki udaje się wczytać kolejną liczbę”. Pętla zatrzyma się sama, gdy dane się skończą — nie musisz z góry wiedzieć, ile ich będzie.

licznik_i_suma.cpp
#include <iostream>
using namespace std;

int main() {
    int ile = 0;
    int suma = 0;
    int x;

    while (cin >> x) {
        ile++;
        suma += x;
    }

    cout << "Liczb:   " << ile << "\n";
    cout << "Suma:    " << suma << "\n";
    cout << "Srednia: " << (double)suma / ile << "\n";

    return 0;
}
▶ Wyjście programu
Wejście: 4 8 15 16 Liczb: 4 Suma: 43 Srednia: 10.75
04 — do-while, break i continue

Trzy przydatne warianty

Wariant do-while sprawdza warunek po wykonaniu ciała, więc kod w klamrach wykona się co najmniej raz. Idealny do pytania użytkownika: najpierw pytasz, a dopiero potem sprawdzasz, czy odpowiedź ma sens.

do_while.cpp
int liczba;

do {
    cout << "Podaj liczbe 1-10: ";
    cin >> liczba;
} while (liczba < 1 || liczba > 10);

cout << "Dziekuje!";
▶ Wyjście programu
Podaj liczbe 1-10: 42 Podaj liczbe 1-10: 7 Dziekuje!
break_continue.cpp
int x;

while (true) {           // niby w nieskonczonosc
    cin >> x;

    if (x == 0) break;       // 0 konczy petle
    if (x < 0) continue;     // ujemne pomijamy

    cout << x * x << " ";
}
▶ Wyjście programu
Wejście: 3 -5 4 0 9 16

break przerywa pętlę natychmiast i wyskakuje poza nią. continue pomija resztę bieżącego obrotu i wraca na górę, do sprawdzenia warunku. Zapis while (true) tworzy pętlę bez końca, którą musisz przerwać break-iem ze środka.

Uwaga na jedną pułapkę: w pętli while instrukcja continue wraca na górę bez zwiększania licznika. Jeśli zwiększasz go na końcu ciała, continue ten krok pominie i program zawiśnie. Zwiększaj licznik przed continue albo użyj pętli for, która robi to sama.

05 — Typowe wzorce

Gotowe pętle do przepisania

Prawie każda pętla, jaką napiszesz na początku, jest jedną z poniższych. Nie ucz się ich na pamięć — po prostu wracaj tu, gdy nie wiesz, od czego zacząć.

WzorzecCo robiKiedy tego użyjesz
int i = 0; while (i < n) Wykonuje kod dokładnie n razy. Powtórz coś ustaloną liczbę razy
while (i > 0) i-- Odlicza w dół, aż dojdzie do zera. Odliczanie, wypisywanie od końca
while (cin >> x) Czyta dane, dopóki jakieś są. Kończy się sama. Nie wiesz, ile będzie liczb
while (x != 0) Kręci się, aż użytkownik poda umówioną wartość. Menu, wczytywanie do znaku końca
while (n > 0) { n % 10; n /= 10; } Odcina liczbę cyfra po cyfrze, od prawej. Suma cyfr, odwracanie liczby
while (true) { ... break; } Kręci się bez końca, dopóki coś jej nie przerwie. Gdy warunek wyjścia jest w środku
do { ... } while (w) To samo co while, ale ciało wykona się raz na pewno. Pytanie użytkownika i sprawdzenie odpowiedzi
pętla w pętli Zagnieżdżone while — każdy obrót zewnętrznej uruchamia całą wewnętrzną. Tabelki, wiersze i kolumny

Zwróć uwagę na przedostatni wiersz: do-while różni się od zwykłego while jedną rzeczą — sprawdza warunek dopiero na końcu, więc ciało wykona się co najmniej raz. To dokładnie to, czego chcesz, gdy prosisz użytkownika o dane.

06 — Przykładowe zadania

Sprawdź się na zadaniach

Sześć zadań ułożonych od najprostszego. Pierwsze trzy to czyste ćwiczenie z licznika, kolejne łączą pętlę z warunkiem. Rozwiązania są schowane — zajrzyj do nich dopiero po własnej próbie.

Łatwe Odliczanie
Wczytaj liczbę n i wypisz wszystkie liczby od n w dół do 1, oddzielone spacjami. Na końcu dopisz Start!
Jak to ugryźć: Zmienna startuje od n, warunek to n > 0, a w ciele pętli zmniejszaj ją przez n--.
Pokaż rozwiązanie
odliczanie.cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    while (n > 0) {
        cout << n << " ";
        n--;
    }

    cout << "\nStart!";
    return 0;
}
Łatwe Suma od 1 do n
Wczytaj n i policz sumę wszystkich liczb od 1 do n. Dla n = 5 odpowiedzią jest 15.
Jak to ugryźć: Dwie zmienne: licznik i startujący od 1 i suma startująca od 0. W ciele pętli dokładaj suma += i i zwiększaj i.
Pokaż rozwiązanie
suma_do_n.cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int suma = 0;
    int i = 1;

    while (i <= n) {
        suma += i;
        i++;
    }

    cout << suma;
    return 0;
}
Łatwe Ile liczb dodatnich
Wczytuj liczby aż do końca danych i policz, ile z nich było dodatnich, a ile ujemnych. Zera pomijaj.
Jak to ugryźć: Dwa liczniki ustawione na zero przed pętlą i if w środku, który decyduje, który z nich zwiększyć. Pętla while (cin >> x) zatrzyma się sama.
Pokaż rozwiązanie
dodatnie_ujemne.cpp
#include <iostream>
using namespace std;

int main() {
    int dodatnie = 0;
    int ujemne = 0;
    int x;

    while (cin >> x) {
        if (x > 0) dodatnie++;
        else if (x < 0) ujemne++;
        // zero pomijamy
    }

    cout << "Dodatnie: " << dodatnie << "\n";
    cout << "Ujemne:   " << ujemne << "\n";
    return 0;
}
Średnie Suma cyfr liczby
Wczytaj liczbę naturalną n i wypisz sumę jej cyfr. Dla 4821 odpowiedzią jest 15.
Jak to ugryźć: Ostatnią cyfrę daje n % 10, a n /= 10 ją obcina. Powtarzaj oba kroki, dopóki n jest większe od zera. Weź long long, żeby zmieściły się też duże liczby.
Pokaż rozwiązanie
suma_cyfr.cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;

    int suma = 0;
    while (n > 0) {
        suma += n % 10;    // ostatnia cyfra
        n /= 10;           // obcinamy ja
    }

    cout << suma;
    return 0;
}
Średnie Odwrócenie liczby
Wypisz liczbę n zapisaną od tyłu. Dla 1234 odpowiedzią jest 4321.
Jak to ugryźć: Buduj wynik cyfra po cyfrze: odwrocona = odwrocona * 10 + n % 10. Mnożenie przez 10 robi miejsce na nową cyfrę z końca.
Pokaż rozwiązanie
odwroc.cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;

    long long odwrocona = 0;
    while (n > 0) {
        odwrocona = odwrocona * 10 + n % 10;
        n /= 10;
    }

    cout << odwrocona;
    return 0;
}
Trudne Zgadywanka
Program myśli o liczbie 42. Pytaj użytkownika o kolejne strzały tak długo, aż trafi. Po każdym błędnym podpowiedz za malo albo za duzo, a na koniec napisz, za którym razem zgadł.
Jak to ugryźć: Tu pasuje do-while: najpierw musisz zapytać, dopiero potem sprawdzić odpowiedź. Licznik prób zwiększaj w każdym obrocie.
Pokaż rozwiązanie
zgadywanka.cpp
#include <iostream>
using namespace std;

int main() {
    const int SEKRET = 42;
    int strzal;
    int proby = 0;

    do {
        cout << "Zgadnij liczbe: ";
        cin >> strzal;
        proby++;

        if (strzal < SEKRET) cout << "za malo\n";
        else if (strzal > SEKRET) cout << "za duzo\n";

    } while (strzal != SEKRET);

    cout << "Trafione za " << proby << " razem!";
    return 0;
}
07 — Porady

Częste błędy i dobre praktyki

♾️
Program „wisi”
Najczęstszy błąd: zapomniana zmiana zmiennej w ciele pętli. Jeśli program nic nie wypisuje i nie kończy się, sprawdź, czy warunek ma w ogóle szansę stać się fałszywy. Ctrl + C przerywa.
🚫
Średnik po while
while (i < n); — ten średnik tworzy pustą pętlę, która zawiesza program. Kompilator nie zgłosi błędu, więc szuka się tego godzinami.
🔢
Zmienna przed pętlą
Zmienna z warunku musi istnieć i mieć wartość przed pętlą. Niezainicjalizowany int ma w środku losowe śmieci.
⏭️
continue a licznik
W while instrukcja continue nie zwiększa licznika automatycznie — łatwo o zawieszenie programu.
📥
while (cin >> x)
Czytanie do końca danych zapisujemy jako while (cin >> x). Pętla kończy się sama, gdy danych zabraknie.
🔁
while czy for?
Znasz z góry liczbę powtórzeń — bierz for. Kręcisz „aż do skutku” — bierz while. Obie robią to samo, chodzi tylko o czytelność.
