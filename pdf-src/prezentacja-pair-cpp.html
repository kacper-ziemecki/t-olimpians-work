Dwie wartości, które są razem

Często dwie liczby należą do siebie i nie ma sensu trzymać ich osobno:

Punkt na kratce
(x, y) — np. (3, 5)
Data
(dzień, miesiąc) — np. (24, 10)
Wynik zawodnika
(numer, punkty) — np. (7, 95)
do tej pory
int x = 3;    // te dwie zmienneint y = 5;    // opisują JEDEN punkt

Działa, ale przy 10 punktach mamy już 20 osobnych zmiennych: x1, y1, x2, y2, … Łatwo pomylić, które x pasuje do którego y.

Wniosek: potrzebujemy jednej zmiennej, która trzyma dwie wartości naraz. To jest para — po angielsku pair.

Para = pudełko z dwiema przegródkami

Para to jedna zmienna z dwiema przegródkami. Pierwsza przegródka nazywa się first (pierwszy), druga — second (drugi).

punkt
3
5
first
second
  1. Cała para ma jedną nazwę — tutaj punkt.
  2. W środku są dokładnie dwie wartości — nie mniej i nie więcej.
  3. Przegródki nie mają numerów jak szufladki w tablicy — mają nazwy: first i second.
  4. Każda przegródka może mieć inny typ, np. litera i liczba — o tym w rozdziale 08.

Szablon programu z parą

szablon każdego programu
#include <iostream>    // cin i cout#include <utility>     // tu mieszka pairusing namespace std;   // pair zamiast std::pair int main(){    // <- tu wpisujemy kod z parami}

Para jest w bibliotece utility. Dopisujemy ją na górze, obok iostream.

W praktyce para często działa już z samym iostream, ale pewniej jest dopisać #include <utility>.

Na kolejnych slajdach często pokazujemy tylko środek main — reszta programu jest zawsze taka sama jak tutaj.

Budowa linijki, która tworzy parę

Rozłóżmy na części linijkę z notatek. Każdy kawałek ma swoje zadanie:

pair1<int, int>2 zmienna3;4
1pair„to będzie para”
2<int, int>w nawiasach ostrych: jakie typy przechowuje para — pierwszy typ dla first, drugi dla second
3zmiennanazwa — wymyślamy ją sami (np. para1, punkt, wynik)
4;średnik na końcu — jak po każdym poleceniu
Razem pair<int, int> to typ — tak jak int. Dalej jest jak przy zwykłej zmiennej: typ, nazwa, średnik.

Para bez wartości — co jest w środku?

strefa globalna — poza main
#include <iostream>#include <utility>using namespace std; pair<int, int> para1;     // globalna int main(){
strefa lokalna — w klamrach main
pair<int, int> para2;  // lokalna
}

Tak jak przy tablicach, parę można stworzyć globalnie (poza main) albo lokalnie (w main). Nie podajemy żadnych wartości.

Pamiętasz tablice? Tablica bez listy miała zera globalnie, a śmieci lokalnie.

Jak dostać się do jednej przegródki?

nazwa.first   nazwa.second

Piszemy nazwę pary, potem kropkę, a potem first albo second. Kropkę czytamy jak „w środku”: para1.first = „first w środku para1”.

para1.second   // drugi element pary

W nawiasach ostrych < > piszemy, jakie typy przechowuje nasza para. Pierwszy typ jest dla first, drugi — dla second.

Najczęstsze błędy (1/2)

  1. cout << para; — nie da się wypisać pary jednym cout (błąd kompilacji). Wypisz first i second osobno.
  2. para[0], para[1] — para to nie tablica, nie ma indeksów. Używamy .first i .second.
  3. Trzy wartości. pair<int, int> p = {1, 2, 3}; — błąd. Para ma zawsze dokładnie dwa elementy; nie ma też .third.
  4. Zła kolejność wartości. pair<char, int> p = {123, 'c'}; — first to „{”, second to 99. Kolejność wartości = kolejność typów.

Najczęstsze błędy (2/2)

  1. Brak kropki albo wielka litera. para1first, para1.First — C++ rozróżnia wielkość liter. Poprawnie: para1.first.
  2. Kolejność w tablicy par. lista.first[1] zamiast lista[1].first — najpierw indeks w nawiasach, potem kropka.
  3. Złe nawiasy przy typach. pair(int, int) albo pair[int, int] — typy pary piszemy w nawiasach ostrych: pair<int, int>.
  4. Zmiana obu bez klamer. para1 = 3, 7; — błąd. Poprawnie: para1 = {3, 7}; albo para1 = make_pair(3, 7);.
