Backtracking — próbuj i wycofuj się

Idziesz przez labirynt z kredą. Na każdym skrzyżowaniu wybierasz jedną drogę i zaznaczasz ją kredą. Gdy trafisz na ślepy zaułek, wracasz do ostatniego skrzyżowania i próbujesz innej drogi.

Tak działa backtracking: próbuj, a gdy się nie da — wycofaj się i spróbuj inaczej.

Schemat backtrackingu

void szukaj(stan) {    if (stan jest rozwiązaniem) {        zapisz / wypisz / policz;        return;    }    for (każdy możliwy ruch) {        if (ruch jest niedozwolony) continue;        wykonaj ruch;        szukaj(nowy stan);        cofnij ruch;    }}

To ten sam schemat wybierz → zejdź → cofnij co w części 4. Różnica: w części 4 prawie każda gałąź dawała wynik (każdy ciąg, każdy podzbiór). Tutaj większość gałęzi to ślepe zaułki.

Klucz do szybkiego backtrackingu: sprawdzać „czy ruch jest dozwolony” jak najwcześniej — zanim zejdziemy głębiej.

Kogo bije hetman?

H

Hetman (królowa) w szachach bije wszystkie pola w swoim wierszu, w swojej kolumnie i na obu swoich przekątnych — na dowolną odległość.

Na planszy obok hetman stoi w wierszu 2, kolumnie 2 (liczymy od 0). Pomarańczowe pola są przez niego bite.

Problem n hetmanów

Ustaw n hetmanów na szachownicy n × n tak, żeby żadne dwa się nie biły. Ile jest takich ustawień? Jak wygląda pierwsze z nich?

  1. W każdym wierszu musi stać dokładnie jeden hetman (dwa w jednym wierszu by się biły).
  2. Więc decyzja dla wiersza w to: w której kolumnie postawić hetmana?
  3. Zapamiętamy to w tablicy kol[w].

Całe szukanie jako drzewo

Węzeł to ustawienie kilku pierwszych wierszy (kol). Wyblakłe węzły z przerywaną ramką to ślepe zaułki — tam w kolejnym wierszu nie było wolnej kolumny.

Gałęzie zaczynające się od 2 i 3 dają drugie rozwiązanie {2, 0, 3, 1} — lustrzane odbicie pierwszego.

Czy pole jest bezpieczne?

int n, kol[20]; bool bezpieczny(int w, int k) {    for (int i = 0; i < w; i++) {        if (kol[i] == k) return false;        if (abs(kol[i] - k) == w - i) return false;    }    return true;}

Hetman w polu (w, k) jest bezpieczny, jeśli żaden hetman z wcześniejszych wierszy i = 0, …, w − 1 go nie bije:

  1. ta sama kolumna: kol[i] == k,
  2. ta sama przekątna: odległość w poziomie równa odległości w pionie — abs(kol[i] - k) == w - i.
Wierszy sprawdzać nie trzeba — z budowy rozwiązania każdy hetman stoi w innym wierszu.

Hetmany — liczymy wszystkie ustawienia

int licznik = 0; void ustaw(int w) {    if (w == n) {        licznik++;        return;    }    for (int k = 0; k < n; k++) {        if (!bezpieczny(w, k)) continue;        kol[w] = k;        ustaw(w + 1);    }}

Gdy w == n, hetmany stoją we wszystkich wierszach — mamy rozwiązanie.

Cofanie jest tu „ukryte”: kol[w] zostanie po prostu nadpisane przy następnej kolumnie, a wiersze poniżej w i tak sprawdzamy tylko do w − 1. Dlatego nie trzeba nic czyścić.

bool ustaw(int w) {    if (w == n) return true;    for (int k = 0; k < n; k++) {        if (!bezpieczny(w, k)) continue;        kol[w] = k;        if (ustaw(w + 1)) return true;    }    return false;}

Ile dróg przez labirynt?

Idziemy z lewego górnego rogu do prawego dolnego: w górę, w dół, w lewo, w prawo, bez ścian i bez odwiedzania pola dwa razy. Ile jest dróg?

Uwaga: Tym razem wolno chodzić we wszystkie strony, więc memoizacja z części 3 nie zadziała: liczba dróg z pola zależy od tego, które pola są już zajęte.

Labirynt — kod

bool odw[6][6];long long licznik = 0; void idz(int i, int j) {    if (i < 0 || j < 0 || i >= n || j >= m) return;    if (g[i][j] == '#' || odw[i][j]) return;    if (i == n - 1 && j == m - 1) {        licznik++;        return;    }    odw[i][j] = true;    idz(i + 1, j); idz(i - 1, j);    idz(i, j + 1); idz(i, j - 1);    odw[i][j] = false;}
  1. poza planszą, ściana albo pole już na drodze — ślepy zaułek,
  2. meta — jeszcze jedna droga,
  3. zaznacz pole, idź w cztery strony, odznacz pole.
Odznaczenie to cofnięcie wyboru: inne drogi mogą to pole odwiedzić — po swojemu.

Droga w trakcie szukania

Fioletowe pola są zaznaczone (odw = true) — leżą na obecnej drodze i na stosie. Z pola (1, 3) w dół jest ściana (2, 3), w lewo — ściana (1, 2). W górę — pole już odwiedzone.

Ślepy zaułek: funkcja dla (1, 3) kończy się, odznacza pole i wraca do (0, 3), które próbuje kolejnych kierunków.

Czy cyfra pasuje?

int g[9][9]; bool pasuje(int w, int k, int d) {    for (int i = 0; i < 9; i++) {        if (g[w][i] == d) return false;   // wiersz        if (g[i][k] == d) return false;   // kolumna    }    int bw = w - w % 3, bk = k - k % 3;   // róg kwadratu    for (int a = 0; a < 3; a++)        for (int b = 0; b < 3; b++)            if (g[bw + a][bk + b] == d) return false;    return true;}

Lewy górny róg kwadratu 3 × 3, w którym leży pole (w, k), to (w - w % 3, k - k % 3).

Sudoku — rozwiązywanie

bool rozwiaz(int p) {          // p = 0 … 80    if (p == 81) return true;    int w = p / 9, k = p % 9;    if (g[w][k] != 0) return rozwiaz(p + 1);    for (int d = 1; d <= 9; d++) {        if (!pasuje(w, k, d)) continue;        g[w][k] = d;        if (rozwiaz(p + 1)) return true;        g[w][k] = 0;    }    return false;}

Pola numerujemy od 0 do 80: wiersz to p / 9, kolumna p % 9. Pole już wypełnione przeskakujemy.

Gdy rozwiązanie się znajdzie, true wraca w górę przez wszystkie wywołania i plansza zostaje wypełniona. Gdy cyfra prowadzi w ślepy zaułek — g[w][k] = 0 czyści pole przed następną próbą.

Kolorowanie mapy

Państwa to kółka, kreska oznacza, że dwa państwa sąsiadują. Pomaluj każde państwo jednym z k kolorów tak, żeby sąsiedzi mieli różne kolory. Na ile sposobów?

Koloruj państwa po kolei: państwu v nadaj kolor, którego nie ma żaden już pokolorowany sąsiad, i przejdź do v + 1.

Kolorowanie — kod

vector<int> sas[11];int kolor[11];          // 0 = jeszcze bez kolorulong long licznik = 0; void koloruj(int v) {    if (v > n) { licznik++; return; }    for (int c = 1; c <= k; c++) {        bool wolny = true;        for (int u : sas[v])            if (kolor[u] == c) wolny = false;        if (!wolny) continue;        kolor[v] = c;        koloruj(v + 1);        kolor[v] = 0;    }}

Podział na palindromy

Potnij słowo na kawałki tak, żeby każdy kawałek był palindromem. Wypisz wszystkie sposoby. Dla „aab”: a a b oraz aa b.

Funkcja tnij(i) wybiera pierwszy kawałek zaczynający się na pozycji i: najpierw najkrótszy, potem coraz dłuższe. Kawałek, który nie jest palindromem, to ślepy zaułek.

Przykład: plecak — sprawdź wszystko, ale mądrze

void pakuj(int i, long long waga, long long wartosc) {    if (waga > W) return;           // obcinanie    if (i == n) {        najlepsza = max(najlepsza, wartosc);        return;    }    pakuj(i + 1, waga, wartosc);    pakuj(i + 1, waga + w[i], wartosc + v[i]);}

Bierz / nie bierz z części 4 + zapamiętywanie najlepszego wyniku. Dla n ≤ 20 to najwyżej ok. 2 miliony wywołań.

Gdy wag jest dużo i są małe, plecak rozwiązuje się programowaniem dynamicznym — w kompendium temat „Plecak 0-1”. Backtracking wygrywa, gdy przedmiotów jest mało, a wagi są ogromne.
