Problem: dużo liczb naraz

Do tej pory każdą liczbę trzymaliśmy w osobnej zmiennej. Gdy liczby są trzy — da się wytrzymać:

3 liczby — 3 zmienne
int a = 4;int b = 7;int c = 1;

A gdyby liczb było 5? 100? 1000? Wymyślanie tysiąca nazw i pisanie tysiąca linijek nie ma sensu.

1000 liczb — 1000 zmiennych?
int a1 = 4;int a2 = 7;int a3 = 1;int a4 = 9;int a5 = 2;// ... i tak dalej ...int a1000 = 6;   // 1000 linijek?!
Wniosek: Potrzebujemy jednej nazwy na wiele liczb. Do tego służy tablica.

Gdzie jest „globalnie”, a gdzie „lokalnie”?

strefa globalna — poza main
#include <iostream>using namespace std; int lista1[5];      // globalna int main(){

}
Globalna
stworzona poza main, poza innymi funkcjami, poza klamrami { }. Zwykle na górze pliku, nad main.
Lokalna
stworzona wewnątrz main albo innej funkcji — czyli w środku klamer { }.
Podpowiedź: Patrz na klamry. Jeśli tablica stoi w środku klamer jakiejś funkcji — jest lokalna.
