Szablon programu z vectorem

szablon każdego programu
#include <iostream>    // cin i cout#include <vector>      // tu mieszka vectorusing namespace std;   // vector zamiast std::vector int main(){    // <- tu wpisujemy kod z vectorami}

vector jest w bibliotece vector. Dopisujemy ją na górze, obok iostream.

Bez #include <vector> program się nie skompiluje — kompilator nie będzie wiedział, co to jest vector.

Na kolejnych slajdach często pokazujemy tylko środek main — reszta jest zawsze taka sama.

Najczęstsze błędy (1/2)

  1. Indeks w pustym vectorze. vector<int> lista; lista[0] = 5; — szufladki 0 nie ma. Użyj push_back albo vector<int> lista(n);.
  2. Nawiasy. vector<int> a(5, 0); to pięć zer, a vector<int> a = {5, 0}; — dwa elementy: 5 i 0.
  3. cout << lista; — błąd kompilacji. Wypisuj pętlą.
  4. Brak & przy wczytywaniu. for(auto e : lista) cin >> e; — liczby trafiają do kopii, lista zostaje pełna zer.

Najczęstsze błędy (2/2)

  1. Indeks poza zakresem. lista[lista.size()] nie istnieje — ostatni element to lista[lista.size() - 1] albo lista.back().

  4. Kolejność w 2D. m[wiersz][kolumna]. vector<vector<int>> m(3, vector<int>(2)); to 3 wiersze po 2 kolumny — nie odwrotnie.
