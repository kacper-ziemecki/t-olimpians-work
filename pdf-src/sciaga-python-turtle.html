01

Jak zacząć — szablon programu

Moduł turtle to „żółw” z pisakiem, który chodzi po ekranie i rysuje. Każdy program zaczyna się od importu, potem wydajesz żółwiowi polecenia jedno po drugim.

szablon — tak jak zaleca LOGIA
from turtle import *      # 1. importujemy wszystkie polecenia żółwia

def kwadrat(bok):         # 2. własne funkcje rysujące
    for i in range(4):
        fd(bok)
        lt(90)

# tracer(0)               # 3. (opcjonalnie) wyłącz animację — rysuje od razu
kwadrat(100)              # 4. wywołanie funkcji = rysunek
# update()                #    po tracer(0) trzeba odświeżyć ekran
done()                    # 5. okno zostaje otwarte po narysowaniu
LOGIA: organizatorzy polecają from turtle import * zamiast import turtle. Wtedy piszesz fd(100), a nie turtle.fd(100). Na konkursie oddajesz zwykle definicję funkcji, więc testuj ją, wywołując na dole pliku.
Uwaga: nie nazywaj swojego pliku turtle.py — Python zaimportuje wtedy Twój plik zamiast modułu i nic nie zadziała.
02

Układ współrzędnych i kierunki

Żółw startuje w punkcie (0, 0) na środku ekranu i patrzy w prawo (kierunek 0°). Oś x rośnie w prawo, oś y w górę — jak na matematyce. Kąty liczymy przeciwnie do ruchu wskazówek zegara.

left(kąt) obraca żółwia przeciwnie do wskazówek zegara (w lewo), right(kąt) — zgodnie z nimi (w prawo). Obrót nie przesuwa żółwia, zmienia tylko kierunek.

Wzorce na LOGIĘ — krok po kroku

Większość zadań graficznych składa się z kilku powtarzających się pomysłów. Poniżej każdy z nich jako gotowa funkcja, a na dole — co dokładnie rysuje.

wielokąt foremny: skręt 360 / n
def wielokat(n, bok):
    for i in range(n):
        fd(bok)
        lt(360 / n)
gwiazda: skręt 180 − 180 / n
def gwiazda(n, bok):      # n nieparzyste
    for i in range(n):
        fd(bok)
        rt(180 - 180 / n)
spirala: zmienna zmienia się w pętli
def spirala(ile):
    bok = 5
    for i in range(ile):
        fd(bok)
        lt(90)
        bok += 5          # zmienna rośnie
rozeta: figura obracana w pętli
def rozeta(n):
    for i in range(n):
        wielokat(6, 40)   # figura...
        lt(360 / n)       # ...i obrót
szlaczek: ten sam motyw powtarzany w rzędzie
def szlaczek(ile, bok):
    for i in range(ile):
        motyw(bok)        # motyw MUSI skończyć w tym samym kierunku,
                          # w którym zaczął — inaczej szlaczek się rozjedzie
def motyw(bok):
    lt(90); fd(bok); rt(90); fd(bok)
    rt(90); fd(bok); lt(90); fd(bok)
wielokat(6, 40)
gwiazda(5, 80)
spirala(20)
rozeta(12)
szlaczek(5, 15)
Złota zasada: funkcja rysująca kawałek rysunku powinna kończyć w tym samym kierunku (a najlepiej i w tym samym miejscu), w którym zaczęła. Wtedy łatwo składać ją w pętle i większe rysunki. Sprawdź to: suma wszystkich obrotów w funkcji = 0° albo wielokrotność 360°.
dobrze: obroty 90 − 90 − 90 + 90 = 0°
źle: brak ostatniego lt(90) → rysunek się zawija

Rekurencja i fraktale

Funkcja rekurencyjna rysuje mniejszą kopię samej siebie. Zawsze potrzebuje warunku stopu (np. gdy poziom = 0 albo bok jest za mały) i musi wracać tam, skąd zaczęła.

drzewo binarne
def drzewo(dl, poziom):
    if poziom == 0:           # 1. warunek stopu
        return
    fd(dl)                    # 2. pień
    lt(30)
    drzewo(dl * 0.7, poziom - 1)   # 3. lewa gałąź (mniejsza)
    rt(60)
    drzewo(dl * 0.7, poziom - 1)   # 4. prawa gałąź
    lt(30)
    bk(dl)                    # 5. powrót na start — obowiązkowo!

lt(90)
drzewo(80, 6)
drzewo(80, 6)
  1. Narysuj ręcznie na kartce poziom 1 i 2 — zobacz, co się powtarza.
  2. Napisz przypadek najmniejszy (poziom == 0 → nic nie rób).
  3. Narysuj „pień”, wywołaj funkcję dla mniejszych części, wróć na start.
  4. Testuj od małych poziomów: 1, 2, 3 — dopiero potem większe.
16

Najczęstsze błędy

  1. Skręt o kąt wewnętrzny zamiast zewnętrznego. Trójkąt to lt(120), nie lt(60); kwadrat lt(90); sześciokąt lt(60) (360 / n).
  2. Brak pu() przed przejściem. Żółw zostawia niechcianą kreskę — przed goto podnieś pióro, a potem je opuść.
  3. begin_fill() za późno. Musi być przed pierwszym fd figury, a end_fill() po ostatnim.
  4. tracer(0) bez update(). Okno zostaje puste albo niedokończone.
  5. Funkcja nie wraca do kierunku startowego. Pętle i szlaczki „rozjeżdżają się” lub kręcą w kółko.
  6. range(n) liczy od 0. for i in range(4) daje i = 0, 1, 2, 3.
  7. Dzielenie daje float. 360 / 7 = 51.43 — dla kątów to w porządku, ale range() potrzebuje liczby całkowitej: użyj // albo int().
  8. left i right pomylone w lustrzanym rysunku. Rysuj najpierw jedną połowę, potem skopiuj funkcję i zamień wszystkie lt ↔ rt.
